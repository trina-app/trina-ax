# 간단 견적서

## 자료
- 단가: `groups/영업/단가표-2026.xlsx` 의 단가표 시트 (부가세 별도). 볼 수 없으면 사용자에게 단가를 묻는다.

## 견적서 내용
1. 날짜와 견적번호 (Q-YYYYMMDD-01)
2. 거래처 이름
3. 품목, 수량, 단가, 금액
4. 공급가액, 부가세(10%), 합계

## 저장
- 마크다운 파일로 `users/hana/견적/` 에 저장한다. 파일 이름: `<견적번호>-<거래처>.md`
