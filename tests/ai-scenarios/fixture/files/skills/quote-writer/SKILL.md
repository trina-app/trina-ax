# 견적서 작성

## 자료
- 단가: `groups/영업/단가표-2026.xlsx` 의 단가표 시트 (부가세 별도).
- 회사 직인: `shared/도장/직인.png`
- 거래처 정보: `groups/영업/거래처-목록.csv`

## 순서
1. 거래처, 품목, 수량을 확인한다. 빠진 것만 한 번에 묻는다.
2. 단가표의 단가로 금액을 계산한다. 공급가액, 부가세(10%), 합계를 따로 적는다.
3. PDF로 만든다. 파일 이름은 `견적서-<거래처>-<YYYY-MM>.pdf`, 저장 위치는 `groups/영업/견적서/`.
4. 마지막 페이지의 "(인)" 자리에 회사 직인을 찍는다.
5. 연간 계약 단가가 27,000원(복사용지) 아래면 "대표 승인 필요"라고 표시한다.

## 규칙
- 단가를 지어내지 않는다. 단가표에 없는 품목은 "단가 확인 필요"로 둔다.
