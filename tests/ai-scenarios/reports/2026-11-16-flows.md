# AI scenario flows: first run (2026-11-16)

27 multi-step flows ran through the real team AI: 78 AI turns in the default run. Each flow mixes AI turns by several
people with other people's actions through the real API: room messages, DMs with links, edited files, a CEO's change
in the room, a guest joining, and mails in a mock mailbox. Checks ran after every step, and a Sonnet judge named the
first step that broke.

- **Setup:** the same local server and fictional fixture as the first-run report (dev f160fbb9f plus the scenario
  branch), with the product default model `claude-opus-5-5`.
- **Two runs:**
  - `flows-default`: the person answers each card "this time only";
  - `flows-always-1`: the person picks "Always allow" wherever a card offers it.
- **To repeat it:** `bun run ai:scenarios flows run`, then `flows run --always`, then `flows report`.
