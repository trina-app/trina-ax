## Setting fixed: the server must know its own address

A dev server learns its public exit address only from its local relay (`server/src/main.ts`), and the first runs
started without one (`--no-relay`). So every web address the AI opened got the card "AI가 이 주소를 열려고 해요. 내부
네트워크의 기기(공유기, 프린터 등)로 가는 주소가 아닌지 확인해 주세요". A real install doesn't show that card once it knows
its address.

says which. **The earlier counts this distorted**, one extra card each:
