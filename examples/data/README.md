# Fictional inputs

Every name, company, amount and date here is invented for evaluation. No credentials or customer files are included. Upload the chosen files to `shared/demo/` for the basic walkthrough; production HR/finance sources belong in appropriately restricted folders instead.

`example-result.md` is a human-prepared illustrative output, **not an observed AI response**. Keep that label if you copy it. The skill catalog in [examples](../README.md) lists inputs and review requirements.
