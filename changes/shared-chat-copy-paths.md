- In a chat shared with its files, asking the AI to change one of those files now always saves a new version of the
  chat's copy, for everyone in the chat, the person who shared it too. Before, the AI sometimes followed the link to
  the original in the sharer's My files, could not open it and made a separate new file instead.
- The Share dialog now ticks **Share the files too** by default when every listed file is safe to share (the chat's
  own outputs, nothing the people being added can't open). It stays unticked when a file was made from something they
  can't open.
