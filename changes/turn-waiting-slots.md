- An answer that waits for you (a question, a confirmation, saving to a room) no longer takes one of the team's answer
  places while it waits. Questions queued behind it start at once; when you answer, it goes on as soon as a place is
  free, before anything queued after it, and the chat says "Waiting for a free place" meanwhile.
- A chat whose earlier answer is still being ended now says "Waiting for the earlier answer to finish. Other chats work
  as usual." instead of refusing a new message without a word.
