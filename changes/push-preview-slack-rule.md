- Phone notifications now show who wrote, where, and the message, like other messengers: for messages in chats shared
  with people, project chats and chat threads too (before, those only said "You have a new message"), with the whole
  message instead of its first line, and "Sent a photo" or "Sent a file: report.pdf" for a message with only files.
  Turn it off in Settings › Notifications › **Show message preview in notifications**. A message that looks like it
  holds a password, a key or a one-time code never shows its text. No app update needed.
