- Removing pages from a PDF also removes those pages' pictures from the file. When the AI took pages out of a PDF
  (remove or keep pages, split, or merge or insert with a page list), a picture of a removed page could stay inside the
  saved file in some PDFs, and so could a removed page that another page linked to. The saved file now holds only
  what its own pages use; a link that led to a removed page is removed with it.
