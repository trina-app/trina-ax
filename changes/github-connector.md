- **GitHub** is in Settings › Connectors: press Connect, sign in at GitHub, and the AI can work with your repositories,
  issues and pull requests (GitHub's own MCP server). No token to make or paste. It signs in through the GitHub App your
  server holds; you choose which repositories it may see on GitHub ("Choose on GitHub" on its page). Reading needs no
  card; anything it changes asks first, as for every connector. On a server without the GitHub App the card says "Not
  set up yet".
