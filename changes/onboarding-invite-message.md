- **Invite your team** (the last getting-started step, and Admin › Members): the message to send with the team link now introduces the team. It greets from you, adds the team's one-line intro from **About the company**, says in one plain line what the team uses Trina for, says which skill you set up for the team and puts the link on its own line. It is written in the team's language, and you can change it in place before **Copy message**. The line under it now says people who join see the skill in the team's skills.
