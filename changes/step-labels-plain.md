- The step list under an answer no longer shows raw shell commands such as "cd $TRINA_WORK/… && export …". A
  dev-environment step reads as a short plain phrase in your language ("영상 프레임 만들기", "프로그램 설치",
  "파일 확인"); open the step to see the exact command. Older answers read the same way.
- Permission cards for a command or a file change ask in plain words ("파일 수정", "파일 바꾸기"); the command or the
  file's new content (an SVG, a page) is behind "자세히". Scripts, settings files and skill files stay open.
- Step lines and cards no longer show "chat:files/<id>/…", "chat:work/…" or "$TRINA_WORK": they say "이 채팅 ›" or
  "작업 폴더 ›" instead.
- A copy saved when two people changed a file at the same time is now named "… (동시에 고친 사본 - 이름 날짜).확장자"
  ("edited at the same time" in English) instead of "충돌 사본" / "conflict copy". Older copies keep their names.
