- Promo videos can now be downloaded as an MP4 on Linux team servers too (hosted teams and `install-linux.sh` servers),
  by the person who made the video and by everyone the chat is shared with. The AI can save and send the video file
  there. Where a server cannot make the file (still being updated, too little memory), the video panel says so instead
  of hiding the button. Docker images get it with `--build-arg TRINA_AX_PACKAGE_GROUPS="fonts browser video"`.
