- **Save to team folder** is more careful with personal files. An employment contract, a salary contract, an HR record, a
  CV, a payslip or payroll sheet, a health check-up, a medical certificate or a transcript (in any of the app's
  languages), and an HR file named after a person ("인사평가_김민수.xlsx"), no longer get a folder picked for them. One
  personal file in a message no longer takes the suggestion away from the other files: they keep theirs, and the
  personal one starts unticked.
- **Save to team folder** finds the right folder more often: a weekly minutes file goes to "Meeting notes" or "회의록",
  a quote to "Quotes" or "견적", and the same for contracts, invoices, reports, design and marketing folders, whatever
  language the folder is named in. "Recent" is used only when no folder name fits.
- Two identical files in one message are saved once, and the sheet and the note after saving say so ("Same file as
  above"). Saving the same file again later finds the copy that is already there instead of adding another numbered copy.
