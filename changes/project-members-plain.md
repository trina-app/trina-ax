  you move into a team project arrives private: the move window no longer has a share switch, and you share it from
  the project page's "chats only you see" line or the chat's menu. Before a chat is shared, material that others can't
  see is shown as a warning, and Cancel is the default button.

  "Share with project members" for every share button, and Trina's name instead of "the AI" in project texts. The
  instructions editor has the same hint as the project page.
