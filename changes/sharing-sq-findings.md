- In a chat shared with people, asking the AI about "my folder" now works: a search that names your own folder asks you
  on the card first and then runs. Before, the AI was refused and sent you to a menu item by a made-up name. The AI now
  quotes the "Continue in a chat only you see" item exactly and says it is in the menu under the chat's title.
- The Share dialog no longer warns that a chat "also used Direct messages and private channels" when the AI only made a
  file in it. The warning names only the people being added who can't open something.
- **Make it a project** now moves the files you sent from your own folder (also when the AI posted them for you), like
  your uploads. The dialog says each reason a file stays in its own line: not everyone can see it, it is a copy from a
  folder, or it can only be downloaded.
- A notice of a chat that is no longer shared with you now says whose chat it was ("A chat from Mina …"). Sharing the
  chat with you again gives a new notice.
- A Mentions & threads row for a message with text and a file now shows the file's name under the text.
- A guest whose AI can't answer sees one calm line and no **Try again**. The step line about a turned-off AI reads
  plainly: "The AI picked for this chat is turned off, so your team's usual AI is answering."
- In a chat shared with people, a file the AI makes (a deck, a report, a PDF) is now always attached to the chat, where
  everyone in it can open it, unless you ask for it in a folder of your own. Before, it often landed in the asker's own
  folder and the others got a link that didn't open.
- Attaching a file from **My files** in a chat shared with people now adds a copy to the chat, so everyone there can
  open it and ask for changes. The box says so before you send.
- Sharing a chat whose AI ran commands for you now says so before you share; people you add later see those answers
  too. When some earlier answers stay hidden from someone you add, the Share dialog says how many.
- The Share dialog's warning now names the files the new person can't open and where they are, and says the new
  person will see what those answers say. When the chat's files were made from such files, **Share without files** is
  the main button.
- Helper files the AI used to make a document (a draft .md or .html) are no longer offered with the chat's files.
- When the AI can't find a folder in a shared chat, it now says that it only looks where everyone in the chat can open,
  and asks for the folder's path or offers a chat only you see.
- A video or file the AI made with commands in a private chat (and saved to your files) is now offered under **Share
  the files from this chat too?** when you share the chat, like the files the AI wrote. If you shared without it, the
  other person sees "Only <you> can add this file to the chat" with **Ask to add it**, instead of a Download button that
  didn't work.
