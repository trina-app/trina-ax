- The AI remembers what it did in earlier answers of the same chat: which tools it called, with which files, pages and
  addresses, and what came back. Before, after some answers (another engine, an edited message, or a shared chat that
  read something not everyone there may see) it got only the earlier answers' text and could not say how it had done
  something. In a shared chat it gets only its own steps for the person asking, and only what everyone there may see.
