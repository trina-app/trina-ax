- **Connect every browser profile from the desktop app.** Settings › Browser now lists the Chrome, Edge and Brave
  profiles on this computer. Press Connect next to one (or Connect all): the app opens that profile and links it, with
  no sign-in there and no code to type. Profiles without the extension open its store page first. New profiles show up
  in the list by themselves, and a quiet notice with Undo says when one connected.
- Linked profiles are named after the browser's own profile name and show their Google account, so you and the AI can
  tell them apart. Rename one in Settings › Browser or in the extension's popup.
- Without the desktop app, connecting from inside the profile works as before; Settings › Browser now says that each
  profile connects once and links to the Chrome Web Store.
