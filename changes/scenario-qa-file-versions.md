- **Restore** in a chat file's Versions list now works for every file type (PowerPoint, Word, PDF and others), not
  only text files, so anyone in a shared chat can undo a change the AI made. Open shows an older version in the same
  viewer.
- Asking the AI to change a PDF in a shared chat ("change the date to December 5") now saves a new version of the same
  PDF, as Word and PowerPoint files already did, instead of a second "(2)" copy beside it.
- When the AI cannot make a change to a chat file, it now says that nothing was saved and which version the file is,
  and it no longer saves a "test" change to see whether something works.
- Text the AI draws in pictures and videos (for example a title in an MP4) now shows Korean, Japanese and Chinese
  letters instead of empty boxes, and the AI is told to say what it actually sees when it checks its own work.
- Steps under an answer show a chat's files by name ("This chat › quote.pdf"), never an internal path or file id.
