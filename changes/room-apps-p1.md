- Rooms can now get messages from other services: Sentry, GitHub, Google Forms or anything that can send to a web address posts to a room's private address, and each update shows as a card from that app ("Sentry · App"), with repeats of the same issue, pull request or form response in one thread. Owners and admins manage them in team rooms and the everyone room; in 1:1 and group chats any member can. This release adds the server side; the screens to add an app come next.
