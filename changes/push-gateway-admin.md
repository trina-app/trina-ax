- Owners and admins can now choose where the team's phone notifications go, in **Settings › Notifications › Phone**: Trina push (the default), Off, or Custom, the address of your own push service for your own build of the phone app. A custom address is saved only after it answers as a push service. When the server's own settings (`MYCEL_PUSH_GATEWAY` or `push.gatewayUrl`) name it, the row shows that value and says where it is set.
- In a browser, Settings › Notifications › This device now says **Browser notifications**, so "not set up" there is no longer read as phone notifications being off.
