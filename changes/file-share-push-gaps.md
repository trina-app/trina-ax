- When someone asks to open one of your files, your phone and browser now tell you ("Someone asked to open a file.",
  never the file's name or who asked). Tapping it opens the request, where you can Share or Decline. If someone else
  answers it first, or you can no longer share the file, no notification comes.
- **Settings › Notifications › File sharing** turns these notifications off, together with the one for a file shared
  with you by name. It is on by default; the rows in Activity stay either way.
