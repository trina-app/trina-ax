- Trina can now change existing PDFs: remove, extract, reorder, rotate or insert pages, join several PDFs into one,
  split one into parts, put a seal, signature or logo on a page (a PNG keeps its transparent background), add a line
  of text such as a date, a watermark such as "DRAFT", or page numbers. The result is always a new file next to the
  original; the original is replaced only when you ask for that. Scanned PDFs work too. A PDF locked with a password
  can't be changed, and Trina says so plainly.
