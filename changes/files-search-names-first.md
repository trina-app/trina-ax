- The Files search finds files and folders by name first ("로고" finds 로고.png, a quotation PDF by its file name, a
  Korean name saved on a Mac too), then the lines that contain the text. It searched only inside files.
- A line found in an HTML file shows its text, not its markup (`<!doctype html>…`); a line where the word is only in a
  tag, an attribute, a comment, a script or a style is left out (a page's title and text it hides are still found).
  While new words are being searched, the names found for the previous words are dimmed and cannot be clicked.
