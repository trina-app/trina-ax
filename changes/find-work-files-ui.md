- In the desktop app (Windows, and the Mac app from the website), My files has a quiet line **Find work files on this
  computer**. After you agree in the app's own window, it looks through Documents, Desktop and Downloads and lists what
  looks like work. Nothing is ticked; you choose. Files that may be personal sit apart and are never sent to the AI. The
  files you add go to My files › From this computer, where only you see them, and **Undo** moves just those to the trash.
  Members get the AI's picks too, as their own AI turn.
- In Getting started › Team files on the desktop app, the owner can start with the same look; the files still go to the
  team's home folder.
- The list of personal-looking file names now knows all six app languages and phrases such as "tax return" and
  "declaración de la renta".
