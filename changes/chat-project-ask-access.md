- **Ask for access to a chat or project.** A teammate who opens the link of a chat or project they can't see now gets
  **Ask for access** (with an optional note) instead of "can't be opened", and the button then reads **Requested**. The
  page shows nothing of the chat or project. The person who made the chat, or whoever changes the project's members,
  gets the request in **Activity** with **Share** (a project: **Add**) and **Decline**, and a phone or browser
  notification, with the same limits as requests to open a file. Where no request is possible, the page says only that.
  **Settings › Notifications › File sharing** is now called **Sharing**, since it covers these requests too.
