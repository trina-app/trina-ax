- The company profile draft (회사 소개) now reads websites that draw their pages with scripts, such as many Vite,
  React and Next.js sites. Before, it found only the page title, and products and customers said "not found". Now the
  server draws the page in its locked-down browser. If it cannot, the draft uses what the page's code says about it
  (its description and structured data) and the pages listed in the site's sitemap.
- When the AI reads a web page in a chat and the page shows almost no text, it now also gets the page's description
  and structured data.
