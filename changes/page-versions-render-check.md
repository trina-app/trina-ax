- Asking the AI to change a web page it made ("make the text bigger", "change the place"), also one made for someone
  else in a shared chat, now saves a new version of the same page instead of a second page card. The panel shows who
  asked for each version, and **Restore this version** brings an earlier one back as the newest; nothing is deleted.
  The AI can also show or bring back an earlier version when asked ("show the version before Junho's change").
- When the AI makes or changes a web page, the server now opens it in a browser first and tells the AI about errors
  (for example a script that stops the page) or a blank page, so the AI fixes them before saying it is done. If the page
  cannot be checked within a few seconds, the AI is told it was not checked.
