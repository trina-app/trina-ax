- A file sent in a department's channel now goes into the department folder's Chat attachments folder, so the team's
  files are in one place. The channel's top shows the folder with the department's name, and the file says where it
  went ("Sales › Chat attachments"). When the folder is shared with more people than the department, or someone in the
  channel can't open Chat attachments, the file stays in the channel, marked "Only in this conversation", and the
  channel's Files list shows it. Files sent before this update stay in the channel.
- Deleting a message in a department's channel deletes only the message; the confirm says the file stays in the
  department's Chat attachments.
- Admins can open a department room's new uploads in its folder, as they can open every team folder, even when they are
  not in the department. They still don't see the conversation.
- Admin notes, going back to an older version: files sent to a department folder after this update stay there and open
  in Files; in the channel, the older version shows them as unavailable.
