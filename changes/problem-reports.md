- **Report a problem.** Settings › About has a "Report a problem" button, and every finished AI answer has a 👎. Both
  open one small sheet: write what went wrong and press Send. The Trina AX team (Potenlab) reads it; on a self-installed
  server the sheet says the report leaves the server. From 👎 you can tick "Send this answer and question with it" (only
  in your own chat, not in shared, project or side chats). Nothing else from your chats, files or names is sent: only the
  app and server versions, the platform, the kind of screen and, from 👎, the answer's id, failure code and the names of
  the tools it used. Owners and admins can turn it off in Admin › Team settings ("Members can report problems").
