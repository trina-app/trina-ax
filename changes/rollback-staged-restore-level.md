- Linux: going back to the version before an update (docs/BACKUP-RESTORE.md) works again when the update raised the database level. `sudo mycel-ctl update --version <old>` now checks the level of the staged database copy, which the old version opens, not the level of the database the new version changed. It refused every time (QA TC-2859). This works when you go back from 0.5.9 or later.
- Linux: `sudo mycel-ctl auto-update on|off` now returns only when the restarted server answers again (or says that it does not answer yet). A database restore staged while the server was still starting was taken by the starting version and changed again.
