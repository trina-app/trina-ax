- **Hands-on demo build** (`bun run build:demo`): the real web app with a scripted backend that runs entirely in the
  browser, for a try-it-yourself demo on the website. It can be hosted as static files, needs no account, server, AI or
  database, and every visitor gets a fresh copy in their own tab. The story ("Mina's first day") is a content file;
  a guide line in the corner shows the next step, and "Start over" or a reload begins again. The normal build is
  unchanged.
