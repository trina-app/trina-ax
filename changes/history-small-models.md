- Teams that use their own AI model (for example a local Ollama or LM Studio model) no longer get "This conversation got too long" or answers that ignore the team's instructions because the chat history did not fit the model. Trina now learns how much the model can read at once and sends only what fits, with a summary of the older part when one can be made.
- When the model is the reason the AI remembers only the recent part, the note under the answer now says so. A model too small for Trina's instructions gets a plain message asking the admin for a larger model or a larger context length.
