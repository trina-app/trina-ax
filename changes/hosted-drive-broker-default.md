- Google Drive (and the Google apps) can now be connected on a new Trina Cloud team right away. The team needed a setting nobody could make, so onboarding said "Google Drive isn't set up on this server yet".
- If Google Drive is not ready on a hosted team, its card in Connectors now says so in plain words and to contact hosting support, instead of sending the admin to a setup page that has nothing to set up. The setup's Tools step no longer shows a Google Drive that can't be connected.
- The setup's Tools step is shorter: Google Drive (when it can be connected), Notion, and "Connect another tool", which opens the full list in Settings › Connectors; closing it brings you back to the step. Linear, Atlassian, Canva and Figma are in that list.
