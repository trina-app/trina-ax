- In a chat shared with people or a shared project chat, the AI can now make scheduled tasks and videos. A task made
  there runs as the person who made it and posts each result in that chat; a run skips places some people in the chat
  can't open. The task page says where it posts.
- Scheduled tasks can now repeat every few minutes or hours, on several days of the week, on the last day of the month,
  or on any cron schedule. Settings › Scheduled tasks › Edit has these options.
