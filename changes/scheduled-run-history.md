- **Scheduled tasks** have a run history: a task's page lists every run under **Runs**, newest first, with how it
  went, when, how long it took and why one did not work, and **Open** goes to that run's chat (10 at first, then
  **Show more**). A run that is going on now is the first row.
- The runs of one scheduled task are now **one row in Recent** (and in a project's chat list): the task's name with a
  clock, the newest run's time and a red dot when it failed, bold while a run is unread. It opens the task's page. The
  run chats are still in Search.
