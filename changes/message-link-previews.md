- Rooms, DMs and threads: **Copy link** in a message's menu copies the message's address (on the team address, so it
  opens for the others too, also when copied in the desktop app on the office network). Paste it in a conversation and
  it shows as the conversation's name with a speech bubble, and the message shows under it as a card (who, when, where,
  its words, its files); a click opens the message, centred and marked. Each person sees the card only when they can see
  that message; for everyone else it stays a plain link, the same as a link to nothing.
- When some people in a conversation can't see a linked message, the box says so before you send, with **Only show
  link** (chosen) or **Show message**. Show message shares a copy of the message (made by the server from what you can
  see) marked "Shared by" you; it never covers an AI answer, an app's card or a shared answer, and it goes when the
  original is deleted. The sender can remove a card with ✕ or **Remove preview** (no "edited" mark).
