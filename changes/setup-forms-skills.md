- After setup's **팀 파일** step sorts your files, it asks whether the Excel, Word and Hangul forms it put in **양식**
  should become team skills ("견적서 양식, 주간보고 양식을 스킬로 만들어둘까요?"). Press **만들기** to see each skill's name,
  what teammates are asked and the form it uses, then **팀에 공유**. When a teammate asks for one (for example "견적서
  만들어줘"), the AI fills a copy of the team's newest form and saves it as a new file. The form itself is never changed.
- Files whose names include a customer's or company's name are not offered as forms.
- The dev environment now comes with the Python libraries for Excel and Word files (openpyxl, python-docx).
