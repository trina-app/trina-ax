- Server updates now wait for running work before restarting, for up to 30 minutes. This includes the dev server's automatic installs and app-only updates, which used to restart at once. While an update waits, Admin › System shows "An update is waiting for N running tasks to finish". Scheduled runs and long commands start after the update. If tasks are running, **Update now** asks whether to wait or update anyway.
- Work that an update still cuts off says so. The interrupted step shows as stopped, not failed, and the answer explains that a running command or render was stopped, with **Try again**.
