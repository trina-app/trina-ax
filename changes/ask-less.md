- Trina asks less. A clear request ("30초 세로 홍보 영상 만들어줘", "보고서 워드로 만들어줘", "웹페이지 하나 만들어줘")
  is now done right away with sensible defaults or a sample, and the answer says in one line what was assumed and any
  tool limit ("영상 도구는 18.5초 고정이라 18.5초로 만들었어요"). Trina asks first only when a choice can't be undone,
  reaches other people, or has no sensible default, and never asks again what you already answered. Numbers, dates and
  names nobody gave still show as blanks to fill in.
- A question card with one choice is answered with one press on the option; Send is only for a typed answer.
- A waiting question shows on its card and as the chat's mark only: the "Waiting for you" group in the chat list and
  the "Your message will answer…" line over the message box are gone.
- When a confirmation card got no answer in time, Trina no longer asks the same thing again in words.
- Moving files that only you can open to the trash asks nothing; the "moved to the trash · Undo" message stays.
- The Share dialog of a chat has **Stop sharing**: one press, with Undo. The dialog no longer shows the "this link is
  this computer's address" note unless you copy such a link, says a finding once, and no longer talks about "commands
  in the dev environment".
- The move card's people count and Trina's answer use the same number, and the "Always allow" line under move and
  room-post cards says what it covers for that action.
