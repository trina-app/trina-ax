- In a chat shared with people, everyone in the chat can now fix its text files (Markdown, text, CSV, HTML, JSON)
  right in the file panel. Each save is a new version, so nothing is overwritten: the file shows "Updated by <name>"
  (or "Updated by Trina for <name>"), and **Versions** lists who saved each one and when, opens an earlier one and
  restores it as the newest. The last 20 versions are kept. Sharing a chat again after its file changed adds the
  change as a new version of the same file instead of a second copy. A project chat's files stay read-only there: its
  project folder is where they are saved.
