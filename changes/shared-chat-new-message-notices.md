- In a chat shared with people, a teammate's new message now tells everyone else in the chat, as a group chat does: an
  unread number on the chat in the Trina list, the app icon and tab count, a phone notification and, in the desktop app, a
  notification with the conversation sound. Several messages in a row each count, grouped under the chat. Tapping the
  notification opens the chat at that message. Trina's answer to someone else adds to the number but never rings; the
  person who asked still gets the "finished" notice.
- "Mute this chat" in a shared chat's ··· menu stops these notices for you (Unmute brings them back).
- You can @mention people in a shared chat's message box: type "@" and pick someone who can see the chat. They are told
  even if they muted the chat, and the chat shows "@" for them.
