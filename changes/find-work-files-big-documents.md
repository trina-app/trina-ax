- Find work files in the desktop app finds ordinary office files in a big Documents folder. The look now goes through
  folders level by level, takes a fair share from each folder (office files first), skips folders that programs fill
  (caches, game saves, code projects), and goes six folders deep. On Windows, Documents, Desktop and Downloads are always
  looked through, even when Windows Search knows only a few of their files. After a look, a quiet "Choose a folder…"
  link lets you point the app at one folder it missed; its files show right away.
