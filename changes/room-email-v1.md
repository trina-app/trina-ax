- **Email into rooms (off by default).** An owner or admin turns on **Let rooms get email** in Admin › Team settings.
  Then a conversation can add **Email** in Add an app: it gets its own email address. Mail forwarded there (for example
  with a Gmail or Outlook filter) shows as a card: the sender (always marked unverified), the subject, the first lines,
  and the attachments by name (not kept yet). Replies in the same mail chain go into the card's thread. Gmail's
  forwarding confirmation code shows in the app's settings for the people who manage the app. **Get a new address**
  stops the old one at once. The server needs the Trina mail service (not set up yet): without it Email says it is not
  available.
