- **Chats in a team project are shared with its members.** A new chat started in a team project is seen and continued
  by the project's members; turn on **Only me** next to the box before the first message to keep that chat to yourself
  (your apps and memories work there). The next new chat starts shared again. The project setting "Share this project's
  chats with its members" is gone. Chats you had before stay yours, and chats you bring in or move in arrive private: a
  line on the project page lists them, and **Share with project members…** shares one at a time. Personal projects do
  not change; while your team's security settings are on, new chats stay yours and the box says why.
- A chat link that can't be opened now says why in plain words (only its creator sees it, it was deleted, or it is in a
  project you're not in) and what to ask for. Copying the link of a chat only you see says nobody else can open it, with
  **Share with members**. The Projects list counts the shared chats of a project too, not only yours.
- In a shared chat, asking for something personal (your email, memories, the browser, schedules) gets a plain answer
  that it is not available there, and **Continue in a chat only you see** in the chat's menu asks again in a private chat
  of the same project.
