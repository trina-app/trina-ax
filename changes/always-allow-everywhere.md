- **Always allow on every card**: every confirmation card Trina shows now offers **Always allow** on the first try: changes after reading conversations, remembering, saving where more people can see, posting to a conversation, reading in a shared chat, moving files, skills, deleting files, project members, AI videos and very large downloads. Pick it once and Trina stops asking about that kind of change. Your choices are listed in Settings › Allowed for Trina, where you can delete any of them. Admins can turn the option off for the team.
- **Connectors**: "Always allow" on a connector now holds after Trina has read web pages, files or conversations in the chat too.
- **Desktop browser**: "Allow all websites" also opens every public website in the desktop app's browser, and the browser's own card offers it on the first site.
