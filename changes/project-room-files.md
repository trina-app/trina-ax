- A file sent in a project's chat room is saved in the project's Chat attachments folder, so it shows in Files with the
  project's other files. The room keeps no copy of its own. A file picked from Files stays where it is and is linked.
- Deleting a message in a project's chat room deletes only the message. Its file stays in the project folder; delete it
  in Files if you want it gone. A file put in the trash in Files shows "File deleted" in its message, and restoring it
  brings it back. A file that was moved or renamed in Files is still found.
- Someone who cannot open a project file (a folder that was narrowed, or the file moved somewhere they cannot see) sees
  it as unavailable in the room.
- "Files you sent" no longer lists project chat room files: they are project files, managed in Files. They count as
  team files in storage, not as conversation files.
- The project's shared AI chats can now read the project's own chat room ("what did we decide in the chat room?"), and
  no other room. They only use what everyone in the chat can see there and say when something was left out.
- Admin notes: the team export names project chat room files by their place in the team folder instead of copying them
  a second time.
- Admin notes, going back to an older version: files sent in project chat rooms after this update stay in the
  project's Chat attachments folder and open in Files. In the room, the older version lists them to every member by
  the name and size they were sent with (without checking who may open the file), and opening one there says it cannot
  be found.
