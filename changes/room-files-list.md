- Every channel, 1:1 and group chat has a **Files** list: the header's Files button opens the files sent there, newest
  first, with who sent each, when and its size. Click a file to preview it. On a phone the list fills the screen. In a
  group's room the group's folder is now at the top of this list. A project's chat room has the project's button
  instead, because its files are in the project.
- Search (⌘K) shows **Recent files** before you type: the five newest files from your conversations. Click one to
  preview it.
