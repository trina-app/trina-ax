- **An app on your computer** (desktop app, macOS first): Settings › Connectors › Discover › An app on your computer lets the AI use a program on your own computer, such as Aside, ego lite or another AI-ready program (Playwright, Chrome DevTools). The desktop app asks once in its own window before the program runs, and again only if the command changes. It works only when you write from the desktop app on that computer; from the web or the phone the AI says so. Asking before changes works as for any connection (Send once, Always allow). Settings the program needs stay on your computer. The connection's page shows whether it runs and has Stop.
- Admin › Team settings has a new switch, **Apps on your computer** (on by default), to turn this off for the team.
- When the AI wants to run a script in an app on your computer (ego lite), the card shows the script as readable code, exactly as it will run. What the script prints reaches the AI also when the program writes it as messages (ego lite), and very long output is cut with a note.
