- **Sharing a chat now offers its files.** When you share a chat (or open Share on one you shared before) and Trina
  made files in your own folder in it, Share asks "Share the files from this chat too?". **Share with files** adds
  copies to the chat so everyone in it can open them; your originals stay in My files. Inside the chat, the file links
  open the chat's copy for everyone.
- **A file you can't open in a shared chat is no longer a dead end.** If Trina made it in the chat creator's own
  files, the side panel says only they can add it and offers **Ask to add it**; they see the request in Activity and
  add it with **Add to the chat**.
