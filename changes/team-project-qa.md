- A team project restored from the trash turns its members' scheduled tasks back on when they were paused only
  because the project was in the trash (a task someone turned off stays off), and its shared chats come back into
  everyone's chat list without a reload.
- Two people editing a project's instructions at the same time: the second save no longer silently replaces the
  first. It says someone else changed the project, shows their version, and keeps your text so you can save again.
- A team project in the trash says only "in the trash" (not "No members left"), on its card and in the phone's
  project list, where its row also has a trash icon.
- An older project a member made on a folder an admin set up no longer offers its creator a Delete that the server
  refuses; only an admin can delete it.
