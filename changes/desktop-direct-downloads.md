- Desktop app: **Download** no longer opens the "Save As" window. The file goes straight into your computer's
  Downloads folder, like in a browser, and a notice says **Saved to Downloads** with **Show in folder**. A file with
  the same name is never replaced: the new one is saved as "name (1)", "name (2)". A download that fails says so.
  This covers files in rooms and chats, Files, previews, the image viewer, saved artifacts and "Save image" in the
  right-click menu. The Mac App Store app keeps the save window.
