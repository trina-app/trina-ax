- When a file the AI made was moved to another folder, the AI now says where it went and changes it there as a new
  version. Before, it made a new copy, or said someone had deleted the file. If the person can't open the new place,
  the AI says that the file was moved.
- A chat link to a file that was moved now says where it went, with an **Open** button. Before, it said the file
  could not be found. A file moved to the trash says so too.
- Moving a file out of a project or group folder into a folder more people can see now asks first, the same as a move
  out of your personal folder.
- Uploading a file whose name is already in the folder now asks first: **Replace** (the old file is kept as a
  version) or **Keep both**. Before, the upload became "name (2)" without asking.
