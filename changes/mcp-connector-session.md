- Claude, Claude Code and other apps connected through Trina AX MCP stay connected until you disconnect them. Signing out of the browser where you allowed the app no longer ends it; it ends after 90 days without use, when you change your password, are signed out everywhere or lose access to the team.
- A connected app that sends the same sign-in renewal twice is no longer disconnected, as long as it has not used the new sign-in yet (for example, when the first answer was lost on the network). If the app already used the new sign-in and then sends the old one again, the connection still ends, as a safety measure.
