- You can share a folder in **My files** with teammates or groups, like a folder in Google Drive's My Drive: **Files ›
  a folder's ⋯ › Share** opens the same Share dialog as for a file. They can view everything in it, including files
  you add later, and change nothing. A shared folder says **Shared** in Files, and a file inside it **Shared through
  <folder>**. **Stop sharing** first lists what stays shared on its own, and offers **Undo**. Your personal folder itself
  and the places Trina keeps there can't be shared. (Folder sharing turns on with a later update; until then nothing
  of it shows.)
- People you share a folder with find it in **Files › Shared with me** and open it like a folder, one level at a time,
  with each file to view or download. They never see the folders above it.
- The link page of a file or folder you can't open right now says so in one line ("You can't open this right now").
- Admins: the team switch is now **Members can share files and folders they own**, and **Remove all file shares**
  counts files and folders apart. Admin › Home says once that members can now share folders.
