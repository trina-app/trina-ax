- The AI can change words inside an existing PDF, such as a name, a date or an amount. The old words are removed from the page text, not covered, and the new ones are written in the same place, size and colour. It is not a redaction tool: the AI says where else in the file the old words still are (document properties, bookmarks, comments), and that words in a picture (a scanned page) can't be changed.
- Excel files the AI makes can have link formulas (HYPERLINK) to web pages, written-out email addresses and places in the same workbook. Links to files or network folders are still refused, because opening one could send a coworker's Windows sign-in to another computer.
