- A used-up usage limit now stops an answer while it is still working (before its next step), not only before it starts: the answer ends with the usual "You have used up … AI usage limit" message. This also covers a Claude Code sign-in and the team's API engine, which until now only counted their use when the answer ended. An answer that has already finished is never turned into an error: its use is counted and the next question is refused. A Codex sign-in reports its use only when its answer ends, and a dollar-only limit on a Claude Code sign-in gets its price only then, so for those the next attempt or the next question is refused.
- Several answers of one person at the same time now see each other's use, so together they stop near the limit instead of each going on past it. An answer that is cut off keeps the use it already had.
