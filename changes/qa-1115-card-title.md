- Apps in rooms: an app card's headline now changes with its status. A merged pull request reads "Pull request merged", not "Pull request opened". A resolved Sentry issue reads "Resolved by …". A Jira work item that moved, an updated Zendesk ticket and a cancelled, paid or fulfilled Shopify order no longer say "New …". A Stripe, Toss Payments or PortOne payment shows its current state, for example "Refunded" or "Payment cancelled".
