- Teams on the API engine (OpenRouter, Ollama, LM Studio and other OpenAI-compatible keys): the AI now sees pictures and
  PDF pages when the model takes images. The app finds this out from the model's server; when the server does not say,
  an admin can set "Reads pictures" in AI providers. A model that reads text only gets a plain note instead.
- Writing through a connected service now takes up to 10,000,000 characters in one go (it stopped at 100,000). The card
  shows the start, and "Show all" opens the whole text before you say yes.
- The AI can delete files in a chat that read room messages or a shared file: it asks on the card every time. Delete,
  member and folder access cards no longer stop after 2 or 3 in one answer, and several folder access changes come on
  one card.
