- Trina can now make a zip: "zip this folder" or "put these files in one zip" saves a .zip with the folders and names
  kept, next to the folder by default. Only files you can open go in, and Trina asks first when more people can see
  the place you save it to.
- Trina can save the attachments of an email file (.eml or Outlook .msg) as files, next to the email: "save the PDF
  from this email".
- Trina can download Word, Excel, PowerPoint, Hangul, CSV and ZIP files from the web into the team folder, and read
  the text of Office files and CSV tables on the web. Programs and installers are still refused.
- On an Office Mac (and any server that turns speech into text itself) the speech model now downloads on its own after
  the server starts. When someone asks about a recording while it is still downloading, Trina waits for it and no
  longer asks you to "use voice input once" first.
