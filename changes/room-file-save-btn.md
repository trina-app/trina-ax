- Files sent in a conversation, a 1:1 or a thread can now be kept in the team folder in one step. Point at a file (or
  long-press it on a phone, or right-click a picture) and choose **Save to team folder**: a small window asks "Where
  should this go?" with a folder already picked from the file's name and the conversation, and tells you when people
  outside the conversation can see that folder. Once saved, the file shows **In team folder** with a link to it.
  Nothing pops up by itself, and a file that looks like an ID or bank document gets no suggestion. Guests can't save to
  the team folder.
