- A server no longer tries to install a release that can't open its data. This happened when a server on a development build was on the stable channel: the stable release of the same number counts as newer, but the development build had already updated the database further. The update then failed, rolled back, and tried again after every wait. Now Admin › Home and Admin › System say "Version … can't open this server's data yet. Waiting for a newer version.", with no install button, and the next release that can open the data installs as usual.
