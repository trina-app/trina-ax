- **Trina history is grouped by project**, like the Claude Code desktop app: each project's chats sit together under
  its name, the newest work first, and chats in no project come last under "Other chats". Next to the conversations a
  computer shows the five latest projects with three chats each ("N more" for the rest); the phone's ☰ menu and "Show
  all" show everything. ▾ folds a project (remembered), and a folded project still shows "?" when a chat inside waits
  for you. + at the right of a project's header starts a new chat in it. Without any chat in a project the list looks as before.
