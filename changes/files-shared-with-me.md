- **Files › Shared with me** lists the files people shared with you, newest first, with who shared it and when. It
  follows changes as they happen (a file you lose access to leaves the list). A file you can already open in its folder
  shows there only when someone added you by name. Opening a file from the list offers **‹ Shared with me** back.
- Opening a shared file now marks its notice in **Activity** as read (also the "shared 5 files with you" notice when you
  open one of those files).
