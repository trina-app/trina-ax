- Google Drive on a server without a public internet address is no longer a dead end. In Admin › Connected apps ›
  Google Drive the owner reads what the address is for, who turns it on and where it shows (with a link to System);
  an admin is told to ask the owner. In Connected apps an owner or admin no longer reads "Your admin needs to turn this
  on" for Drive that is not set up: they get **Set it up**, which opens its page in Admin.
