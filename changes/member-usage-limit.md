- **Admin › Members** can set a person's usage limit right in their row: **…** › **Usage limit…** opens the same limit
  dialog as Team settings, already for that person. If they have a limit, it opens with what they have and how much of
  it they used; the Period switches between their day and month limits, and **Remove limit** takes one away. A person
  with a limit shows it in one quiet line under their name ("50,000 tokens a month"), with **Over limit** once it is
  used up. On a phone, the person's page has a **Usage limit** row. Team and group limits stay in Team settings ›
  Usage limits.
- Editing a usage limit set in dollars only no longer adds a 1,000,000-token limit to it, and an emptied token field
  means no token limit (it saved 0 tokens, which blocks at once).
