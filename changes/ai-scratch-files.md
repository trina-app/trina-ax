- In a project chat the AI now keeps its downloads, git clones, installed tools and previews in the chat's own work
  folder, and puts only the finished files (the deck, the PDF) in the project folder. Before, a downloaded GitHub repo
  could land in the project folder as thousands of team files.
- When one answer would add more than 500 files or 200 MB to a project folder, you are asked whether to keep them there
  or move them to the chat's work folder. "Always allow" keeps them without asking.
- The "files saved" card under an answer lists the first 100 files and counts the rest by folder.
- The AI can now move files it made itself in a chat to the trash without asking, also in a shared project chat.
  Other people's files still need your yes on the card.
