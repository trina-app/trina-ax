- **Create a channel** has a **Make it a project** option under the channel name. Ticked, the people you pick get a shared project at once (a shared folder and Trina for them) and you land in its chat room, instead of making a channel and then choosing ⋯ › Make it a project. The dialog says when another project already has the name and which folder ("-2") the new one gets. Guests follow the project rules: a guest who is already in another project can't be picked. Shown to whoever may make team projects.
