- On a phone, only Markdown and `.txt` files offer **고치기** in a file's ⋯ sheet. Code and settings files such as `.json`
  or `.yml` offered it too. Computers keep the pencil for every file kind they could edit.
- A Hangul (HWP) file whose preview cannot work here (no HWP renderer on this server, a locked, damaged or too large
  document) no longer shows **다시 시도**, only the download; trying again could only fail again. A timeout, a busy
  preview and a lost connection still offer it. The same in Files and in a room's file viewer.
