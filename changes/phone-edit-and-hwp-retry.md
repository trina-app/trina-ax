- On a phone, only Markdown and `.txt` files offer **고치기** in a file's ⋯ sheet. Code and settings files such as `.json`
  or `.yml` offered it too. Computers keep the pencil for every file kind they could edit.
- A Hangul (HWP) file whose preview cannot work here no longer shows **다시 시도**, only the download: no HWP renderer
  or no safe isolation on this server, or a locked, distribution-only, damaged, unsupported, too large or lossy
  document. Trying again could only fail again. A timeout, a busy or cancelled preview, a changed file, a preview that
  is turned off and a lost connection still offer it. The same in Files and in a room's file viewer.
