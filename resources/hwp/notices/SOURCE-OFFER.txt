HWP Preview plugin: where the source of this package comes from

The package ships third-party software only, unchanged. Every licence in it is permissive and none of them requires a
source offer; this file names the exact sources so that anyone can audit or rebuild them.

Noto Sans KR Regular (OFL-1.1)
  rhwp commit above, ttfs/opensource/NotoSansKR-Regular.ttf, unchanged: a weight-400 static instance of Google Fonts
  ofl/notosanskr/NotoSansKR[wght].ttf (upstream assets/fonts/FONTS.md). Internal family, PostScript name, weight and
  SHA-256 are checked at startup. No system, customer, proprietary, GUST or vaguely licensed optional font is shipped.
  The misnamed Noto Serif KR Regular WOFF2 (internally ExtraLight) is excluded.

Trina AX
  The recipes and adapter are part of Trina AX's corresponding source (AGPL-3.0-only), offered through the
  application's Source Code link at the exact release commit: scripts/hwp-bundle.ts (download and pin check),
  scripts/plugins/build-hwp.ts (package), scripts/plugins/hwp-notices.ts (Rust notices), resources/hwp/ (pins, font,
  notices), server/src/files/hwp-*.ts (adapter, preflight, limits, isolation). The renderer does not relicense the
  application or the documents it renders.

Open
  rhwp compiles in font metric tables (src/renderer/font_metrics_generated.rs, font_metrics_overlays.rs): advance
  widths for 595 font names, including proprietary fonts, taken from font files and from measurements of Hancom Office
  output. No font program or glyph outline is included, and rhwp distributes the tables under MIT, but the upstream
  file says that item-level source-font provenance is not verified. A per-entry lineage record and a statement from the
  rhwp author are still to be obtained. Public release of the plugin is a separate decision recorded in Trina AX
  resources/hwp/clearance.json.
