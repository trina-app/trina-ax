Public Suffix List

The Trina AX server uses the tldts package (MIT, https://github.com/remusao/tldts) to tell the site of a web address
from its name ("allow this site in this conversation"; server/src/tools/url-gate.ts). tldts carries a compiled copy
of the Public Suffix List inside its code (src/data/trie.ts and the built files under dist/). Trina AX ships it as
tldts packages it, unchanged.

Public License, version 2.0 (MPL-2.0). The list's own notice:

The full licence text is in MPL-2.0.txt next to this file.

Source of the list (its Source Code Form): https://publicsuffix.org/list/ (the file public_suffix_list.dat)
The copy shipped is the one in the tldts version named under "embeddedData" in licenses/manifest.json.
