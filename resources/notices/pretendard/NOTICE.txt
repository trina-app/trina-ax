Pretendard

Trina AX ships four font files of Pretendard 1.3.9, unchanged:

- PretendardVariable.woff2 (every weight from 45 to 930 in one variable font): the typeface of the promo video
  templates (server/src/promo-video/) and of the intro deck's preview (server/src/intro-deck/). The team server serves
  it to the chat's pages (/vendor/fonts/), and the promo video's MP4 render uses the same file. The repository keeps it
  in resources/promo-video/fonts/.
- Pretendard-Regular.ttf, Pretendard-Bold.ttf, Pretendard-ExtraBold.ttf (the static TrueType builds): the intro deck's
  PDF is drawn with them (typst, which embeds the characters it uses), and its PowerPoint file embeds them whole so the
  person who gets the file can edit the text. The repository keeps them in resources/fonts/pretendard/; every Linux
  server bundle carries them in fonts/. Embedding a font in a document is allowed by the licence (OFL FAQ 1.12, 1.13,
  1.15); the fonts' fsType is 0 (installable).
