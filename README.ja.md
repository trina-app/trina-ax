# Trina AX — 自社専用のAIワークスペース

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Español](README.es.md)

会社の資料、チームの業務手順、フォルダーのアクセス権限を一か所に。メンバーはブラウザーから質問し、文書の下書きを作り、社内の仕事の進め方を共有できます。「スキル」は繰り返し使える作業指示であり、モデルの学習や権限の追加ではありません。

**[ホスティング・料金の相談](https://ax.trina.app/#pricing)** · **[自社運用：IT担当者向けガイド（英語）](docs/for-admins.md)**

## 同じ質問でも、権限によって回答が変わります

「入社時の手続きを要約して」と尋ねた場合、人事フォルダーの閲覧権限がある担当者はその資料を使えます。権限のない営業担当者は、ファイルツールからその資料を読めません。サーバーが質問した人の権限をファイル要求ごとに確認します。スキルにもフォルダー権限が適用されます。

2026年10月30日確認：**Starter 月額$39（最大5名）、Team $69（15名）、Business $129（40名）**。米ドル・税別、AI利用料は別途です。自社運用のソフトウェアは無料ですが、設備・運用・AIの費用は利用者側で負担します。[最新料金](https://ax.trina.app/#pricing)をご確認ください。ホスティングは相談後の導入で、即時登録型の無料トライアルではありません。

## 最初の一週間

チームオーナーのアカウントを作成し、**権限設定 → AI接続 → メンバー招待 → 最初のスキル → 最初のバックアップ**の順に進めます。少数の資料と一つの定型業務から始めてください。[チームリーダー向けチェックリスト（英語）](docs/for-teams.md) · [サンプル（英語）](examples/README.md)。

管理型の接続では、利用可能な個人接続を優先し、個人指定、グループ指定、チーム全体の順で選択します。新規チームではサブスクリプション共有が初期設定で有効です。保存済みの設定は維持され、接続ごとの同意も必要です。**この設定はAnthropicやOpenAIの利用規約上の許可を与えるものではありません。** 用途に合った利用権限のあるアカウント・プランを使用してください。開発・オフィスのlocal-login方式は動作が異なります。[接続FAQ（英語）](docs/FAQ.md)。

## お約束できないこと

- 自社運用でもAI処理が完全にオフラインになるわけではありません。選択された文脈はAI提供元に、外部連携の要求は接続先に送信されます。
- サーバー運用者は保存済みのファイルやチャットを読めます。ホスティングではTrinaの運用者も含みます。アプリ管理者向けに全員の個人会話を閲覧する画面はありません。
- 権限を取り消しても過去の回答は消えません。共有範囲を広げる際の確認は、あらゆる情報流出を防ぐ機能ではありません。
- セキュリティ認証、完全な回答、削減額、法務・経理・人事判断の自動化は保証しません。成果物と運用上の境界を確認してください。
- AI は写真やスキャンした PDF のページを画像として見ます（管理者がオフにできます）。ただし Linux サーバーは文字認識（OCR）を行わないため、スキャン文書や写真はテキスト検索できません。
- HWP/HWPXのテキスト抽出に対応しています。実験的な[表示プレビュー](resources/hwp/README.md)はソースに含まれていますが、**初期設定では無効**で、実行用ツールも標準の配布物には含まれません。Debian 12では表示プレビューを**利用できません**。テキスト抽出と元ファイルのダウンロードは引き続き利用できます。複雑なレイアウトや変換には制約があります。

## 開発者・運用担当者へ

AIツールはチームのサーバー上で動き、ログインした人のファイル権限を検査します。Linuxと役割別アカウントを使うMac構成は、専用エンジンアカウントとOSの分離を追加します。オフィスモードはログイン中のMacユーザーで動作し、開発デモは本番の分離を検証する環境ではありません。MCP（Model Context Protocol）は外部ツールを接続する規格で、最初の体験には不要です。
