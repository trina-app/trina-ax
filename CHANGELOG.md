# Changelog

Published artifacts and authoritative release notes are in [GitHub Releases](https://github.com/trina-app/trina-ax/releases).
This file summarizes user-visible changes; it is not a list of every commit.

## Unreleased

- Who can edit team skills is now on the Team skills page instead of in two admin tables. The owner and admins see one line under the heading, "고칠 수 있는 사람: 팀장·관리자, 영업팀 3명, Bob 님 [바꾸기]". It names the same people Folder permissions names for `skills/`, so it includes people who can edit through a group, an everyone rule or a rule on the whole team folder. Folders inside it that have editors of their own (anyone given write there: a person, a group or everyone) are counted at the end ("폴더별로 맡긴 곳 2개"). If that part cannot load, the line still names who it knows, without "only"; if the line itself cannot load, it says so with a retry. **바꾸기** opens one window. It lists the people and groups who can edit (with the folder when their rule is on a subfolder) and lets you remove one. You can also find a person or group, read the warning, and let them edit all of `skills/`. To hand over one folder only, use Folder permissions. The "팀 스킬 관리" column is gone from Admin › Members and Admin › Groups. Permissions do not change: earlier grants stay, and members do not see the line.
- One list of system packages for every install path. A self-hosted Linux server installed with `install-linux.sh` now gets the same packages as a hosted server: besides what it installed before, CJK fonts, the dev environment's tools (python3, git, build tools, Debian's chromium …; nothing is turned on, `install-srt.sh` still does that) and a pinned headless browser for HTML to PDF (Chrome for Testing `chrome-headless-shell` 157.0.8103.38, SHA-256 checked) in `/opt/trina/chrome-headless-shell`, named by `MYCEL_HTML_PDF_BROWSER` in `/etc/default/mycel`. `--minimal` installs only what it installed before (kept for repair and update; `--no-minimal` turns it back). An office Mac downloads the same browser into `~/TeamAX/browser` (about 105 MB, once per browser version). The list is `scripts/system/packages.json`, shipped in the kit as `root/packages.json` (its Linux part only: a change of only the office Mac's download is no root update): a release that changes it is a root update, and after the root files and the app `mycel-ctl update` starts a sync in a unit of its own (`<id>-packages-sync.service`; the update returns at once, so a slow download never counts in its time or fails it) that installs what is missing and moves the browser to the new version once it starts (the one before stays until the next switch). The sync record names the system (`/etc/os-release` and the machine-id), so a server reimaged with its data disk kept syncs again; every server syncs once after this change, because older records have no system name. `sudo mycel-ctl status` and Admin › System › Diagnostics ("System packages") show where that stands. A self-hosted server installed before this release is not changed by apt unattended: it shows what is missing until `sudo ./install-linux.sh repair`. A hosted server (`"hosted": true` in its install.json) may run apt unattended. A bad browser pin can be rolled back: the list pins the good version again and names the bad one in `"revoked"`, and the sync switches back even though the bad one is newer. CI warns when the pin is behind Chrome for Testing Stable and fails when it is two or more major versions behind; the trina-ax maintainers bump it. If the fonts, tools or browser cannot be installed, the installer warns and goes on; on an office Mac the browser is downloaded before the server stops, and a failure never fails or rolls back an update. The Docker image keeps the packages it had (its installer runs with `--minimal`), now read from the kit's list; `--build-arg TRINA_AX_PACKAGE_GROUPS="fonts browser"` adds the CJK fonts and the browser for HTML to PDF. The image builds stop when the kit's list is not the checkout's. `scripts/linux/deps.txt` is gone (its minimum versions are in the list).
