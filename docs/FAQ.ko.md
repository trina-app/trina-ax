# 자주 묻는 질문

[English](FAQ.md) · [지원](../SUPPORT.md)

## 개발자용 제품인가요?

팀이 회사 자료와 업무 지침을 함께 쓰는 AI 공간입니다. 팀원은 브라우저를 쓰고 직접 설치 시 IT가 서버를 운영합니다. 공통 자료·반복 지침·사람별 폴더 권한이 개인 채팅과 다른 점입니다. [팀장 안내](for-teams.ko.md).

## 비용은 얼마인가요?

직접 설치 소프트웨어는 무료이며 장비·운영·AI 비용은 별도입니다. 2026-11-02 기준 AWS 서울 호스팅은 무료(최대 3명, 자리 한정), Starter 월 $39/최대 5명, Team $69/15명, Business $129/40명이고, 40명이 넘으면 견적입니다. USD·세금·AI 비용 별도입니다. [현재 요금](https://ax.trina.app/#pricing)을 확인하세요.

## AI 계정 없이 체험할 수 있나요?

[로컬 체험](QUICKSTART.ko.md)은 가상 파일을 넣고 AI를 비활성화합니다. 운영 설치나 모델 품질 시험이 아닙니다.

## AI 연결은 어떻게 되나요?

관리형 설치는 운영 설정·제공사 약관에 따라 Claude 구독/Anthropic API, ChatGPT/OpenAI API 연결을 사용할 수 있습니다. 사용 가능한 개인 → 사람 지정 → 그룹 지정 → 팀 전체 순으로 고릅니다. 다른 사람의 개인 연결을 대신 쓰지 않습니다.

새 트리나 팀은 회사 연결 하나를 팀 전체가 쓰는 설정이 기본 켜짐이며, 사람마다 자기 계정을 연결할 수도 있습니다. 기존에 저장한 선택은 유지됩니다. 설정이 이미 켜져 있어도 새 연결의 동의는 별도입니다. 이 기능이 Anthropic·OpenAI 약관상 허가를 주는 것은 아닙니다. 허용된 계정·요금제만 사용하고 개인 구독 하나가 회사 전체 사용을 허용한다고 가정하지 마세요. 제공사 한도·요금은 별도입니다.

개발·사무실 local-login은 서버 OS 사용자의 CLI 로그인을 사용하므로 관리형 선택기와 다릅니다. 한 명령 데모는 엔진을 아예 끕니다. 사무실 모드는 Claude 전용이며 관리형 연결 기능이 필요하면 Linux 방식을 검토하세요.

## 관리자가 모든 대화를 볼 수 있나요?

앱 관리자에게 모든 개인 대화를 보는 화면은 없습니다. 서버·저장소 운영자는 저장 파일·채팅을 읽을 수 있으며 호스팅 운영자도 포함됩니다. 문맥은 AI 제공사로 전송되고 권한 회수로 이전 답변이 지워지지 않습니다. [보안·권한](security-and-permissions.ko.md).

## 문서와 클라이언트는 무엇을 지원하나요?

텍스트·Markdown과 지원되는 Office/PDF 읽기·생성은 설치된 변환 도구에 따라 다릅니다. HWP/HWPX 텍스트 추출·검색·원본 다운로드는 어느 팀이든 됩니다. 선택 플러그인 '한글 문서 미리보기'를 설치하고 켜면(관리 > 플러그인) AI가 새 .hwpx 문서도 만들고(제목은 개요 수준, 문단·굵게·기울임·목록·간단한 표·쪽 나눔, skills/의 팀 서식) 이미 있는 .hwp와 .hwpx도 채웁니다(edit_hwp: 자리표시자, 정확한 글 바꾸기, 표의 빈칸, 한 행을 본뜬 표 행 추가). 바꾼 부분만 고치고 같은 형식의 새 버전이나 새 파일로 저장합니다. 플러그인이 없으면 AI에게 두 기능이 보이지 않습니다. 만들기·채우기는 미리보기 렌더러를 쓰지 않아서, 플러그인이 켜져 있으면 미리보기가 돌지 못하는 서버에서도 됩니다. 새 .hwp는 만들 수 없고, 새 스타일·그림·표는 넣지 않습니다. 배포용·암호·전자 서명 문서와 매크로(스크립트)나 OLE 개체가 든 문서는 고치지 않습니다. 시각 미리보기도 같은 플러그인으로 됩니다(공식 목록에서 설치). 기본 릴리스에는 실행 도구가 포함되지 않습니다. Debian 12에는 이 플러그인을 설치할 수 없어서(glibc 2.36, 고정 렌더러는 2.39 필요) 시각 미리보기도, 한글 문서 만들기·채우기도 쓸 수 없습니다. 원본 다운로드와 텍스트 추출은 유지됩니다. [런타임 한계](../resources/hwp/README.md)를 확인하세요. 복잡한 레이아웃 보존을 보장하지 않습니다.

PC·휴대폰 브라우저와 Windows 설치 파일을 사용합니다. Mac 사무실 ZIP은 서버용이며 데스크톱 DMG는 미배포입니다. 네이티브 모바일 소스가 앱스토어 출시를 뜻하지 않습니다. 현재 소스는 앱 전체에 EN/KO/ID/JA/ES를 지원합니다. 배포된 버전의 지원 여부는 릴리스 설명에서 확인하세요.

## 큰 미디어 파일은 프로젝트에 어떻게 넣나요?

웹 앱에서 올립니다. 파일 화면에서 프로젝트 폴더를 열고 "폴더 올리기"를 쓰거나 폴더를 화면에 끌어다 놓습니다. 하위 폴더는 그대로 유지됩니다. 파일은 한 번에 3개씩, 파일 하나당 최대 20 GB까지 올라갑니다. 연결이 끊겨도 큰 파일은 서버가 받은 조각 다음부터 이어서 올립니다. SSH는 필요 없습니다. 휴대폰은 폴더를 고를 수 없으니 컴퓨터 브라우저에서 여세요.

올리기가 끝났다고 표시될 때까지 페이지를 열어 두세요. 파일 하나가 실패해도 나머지는 계속 올라가고, "다시 시도"를 누르면 실패한 파일만 다시 보냅니다. 저장 공간이나 서버 디스크에 자리가 없으면 올리기가 멈추고 이유를 알려 줍니다. 공간을 비운 뒤 "다시 시도"를 누르세요. 웹 페이지는 링크와 파일을 구분할 수 없어서, 폴더 선택 창으로 올리면 링크가 가리키는 파일의 내용이 올라갈 수 있습니다. 문제가 된다면 링크를 먼저 지우세요. 이름이 같은 파일은 새 이름을 받으므로, 같은 폴더를 다시 올리면 사본이 생깁니다.

연결된 폴더와 Google Drive로는 프로젝트 폴더를 채울 수 없습니다. 연결된 폴더는 서버 폴더를 `connected/<이름>`에 읽기 전용으로 복사한 것이고, 파일당 100 MB까지입니다. Google Drive는 AI가 개인 Drive를 읽게 할 뿐, 프로젝트 폴더에 파일을 넣지 않습니다.

## 업데이트·백업은 있나요?

버전은 [최신 릴리스](https://github.com/trina-app/trina-ax/releases/latest)에서 확인하세요. `https://updates.trina.app` 피드가 서명된 Linux·사무실 업데이트를 제공합니다. 업데이트 전 릴리스 설명을 읽고 백업하세요. 앱 롤백은 데이터 롤백이 아닙니다. [백업·복원](BACKUP-RESTORE.md).

## Docker·오프라인 사용·문의는요?

공식 운영 Docker 이미지는 약속하지 않습니다. Linux 설치는 systemd·cgroup v2가 필요합니다. 직접 설치해도 클라우드 모델은 오프라인이 아닙니다. [문제 해결](TROUBLESHOOTING.md) · [지원·커뮤니티](../SUPPORT.md).
