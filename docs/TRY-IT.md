### 언어 (기본은 영어)
새로 설치한 팀은 **영어가 기본**입니다. 데모 팀은 한국어 팀이고, 데모 계정 넷은 각자 "한국어"를 고른 상태라 그대로 한국어로 보입니다.
- [ ] **개인 설정**: 왼쪽 아래 이름 → 설정 → 언어. "팀 기본값 (한국어)" / English / 한국어 / Bahasa Indonesia 중 하나. "팀 기본값"을 고르면 관리자가 팀 언어를 바꿀 때 같이 바뀜
- [ ] **팀 기본 언어**(dion 또는 admin1): 관리자 → 팀 설정 → 팀 기본 언어. 자기 언어를 고르지 않은 사람(이후 초대·추가하는 사람은 모두 처음엔 "팀 기본값")이 이 언어로 봄
- [ ] **로그인 전**: 로그인·초대·비밀번호 재설정 화면 아래의 언어 선택. 이 브라우저에만 기억하고, 고르지 않으면 팀 기본 언어로 보임(브라우저 언어는 상관없음). 자기 언어가 없는 사람이 여기서 고르고 로그인하면(초대 화면도) 그 사람의 언어로 저장됨
- [ ] **다른 사람의 언어**(관리자): 관리자 → 구성원 → 편집 → 언어. 바꾸면 그 사람의 열린 창이 바로 바뀜. 팀 기본 언어를 바꿀 때도 "팀 기본값"인 사람의 열린 창이 새로 고침 없이 바뀜
- [ ] 언어를 바꾸면 예전 채팅의 작업 단계("파일 읽기 · …", "기억함: …")도 새 언어로 보임

## 개발 서버 멈추기·다시 켜기

`bun run dev`(서버 + 중계)는 사용자 LaunchAgent **`app.team-ax.dev`** 로 백그라운드에서 돕니다. 죽으면 다시 뜨고, 맥을 다시 켜고 로그인하면 자동으로 켜집니다.
저장소 폴더(`/Users/me/treesoop/team-ax`)에서:

```sh
bun run dev:service status      # 돌고 있는지, 두 주소가 답하는지
bun run dev:service logs        # 최근 로그 (전체: ~/Library/Logs/team-ax-dev/dev.log)
bun run dev:service restart     # git pull 뒤 등 (웹 화면이 바뀌었으면 시작할 때 다시 빌드함)
bun run dev:service stop        # 멈춤 (start 할 때까지, 재부팅 뒤에도 꺼진 채로)
bun run dev:service start
bun run dev:service uninstall   # LaunchAgent 제거 (데이터는 남음)
```

터미널에서 직접 보고 싶으면 `bun run dev:service stop` 후 `bun run dev`(Ctrl-C로 끔).

**처음부터 다시**: `bun run dev:service stop` → `mv ~/.team-ax-dev ~/.team-ax-dev.old` → `bun run dev:service start` → 10초쯤 뒤 `bun run demo:seed`.
`demo:seed`는 다시 돌려도 안전합니다(이미 있는 것은 두고 빠진 것만 채움).

데이터 위치: `~/.team-ax-dev` (팀 폴더 `team/`, DB·세션 `data/`, 중계 등록 `relay/`).
이전 개발 데이터(스모크 시험용 owner `boss`)는 `~/.team-ax-dev.bak-20261021-boss`로 옮겨 두었습니다. 필요 없으면 지워도 됩니다.

## 알려진 한계 (이번 데모)

- **개발 모드입니다.** AI 엔진이 Dion 맥 사용자 계정으로 돌고, OS 격리(전용 `_axagent` 계정·샌드박스·pf)는 없습니다. 팀 파일 접근은 권한 함수 + 엔진 잠금 + 도구 관문으로 막지만, 운영 모드의 세 번째 겹(OS)이 빠진 상태입니다. 또 이 모드에서는 Claude Code가 매 턴 문맥에 Dion의 Claude 계정 이메일을 넣습니다(끌 방법 없음). 운영 모드로 바꾸는 법은 [OWNER-TODO.md](OWNER-TODO.md).
- 사용량은 Dion의 Claude 구독과 ChatGPT 구독에서 나갑니다. 관리자 화면에서 정한 사용 한도는 이 모드에서도 적용됩니다.
- 원격 주소는 이 맥 안의 중계 서버(`demo.localhost`)뿐입니다. 다른 컴퓨터·휴대폰에서는 아직 못 들어옵니다(운영 중계 서버와 `*.treesoop.com` DNS 필요). 휴대폰 PWA는 그 뒤에 시험할 수 있습니다.
- 메일이 없습니다. 초대·비밀번호 재설정은 링크를 복사해서 전합니다(의도된 설계).
- 데스크톱 앱은 서명·공증이 없어서 처음 열 때 위 절차가 필요하고, 자동 업데이트도 없습니다. 윈도우용은 서명 없는 설치 파일만 만들 수 있습니다.
- 앱 안 브라우저 도구는 데스크톱 앱에서만 됩니다(웹 브라우저에서 채팅하면 AI에게 브라우저 도구가 주어지지 않음).
- 음성 입력은 처음 한 번 모델(약 490MB)을 내려받습니다.
- 알림(종 아이콘)·알림 목록은 아직 없습니다. 새로 고친 뒤에는 "답변 필요" 표시가 그 채팅을 열기 전까지 보이지 않습니다.
- GitHub Actions가 결제 문제로 시작되지 않습니다. 시험은 로컬에서 돌렸습니다(README "Build and test").
