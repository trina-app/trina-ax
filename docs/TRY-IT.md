# 써 보기 (Trina AX 데모)

이 문서는 합성 데모 팀의 기능별 점검표입니다. 누군가의 맥에서 서버가 이미 실행 중이라고 가정하지 않습니다.
새로 시작하려면 Git·Bun 1.3.12·Go 1.27+와 네이티브 빌드 도구를 준비하고 다음을 실행하세요:

```sh
git clone https://github.com/trina-app/trina-ax.git
cd trina-ax
bun install --frozen-lockfile
bun run demo --port 19700 --locale ko
```

http://127.0.0.1:19700 에서 아래 가상 계정으로 로그인합니다. 이 명령은 새 데이터 폴더에 시드·스킬을 자동으로 넣고 **AI와 중계는 끕니다**. 파일·권한·스킬 목록 점검에 사용하세요. 준비된 Mac에서 약 10분을 잡고 Linux 소스 체험은 별도 확인하세요. Windows에서는 준비된 서버에 브라우저로 접속합니다.

아래 AI 체크리스트에는 별도 개발 환경과 허용된 AI 계정이 필요합니다. 데모를 Ctrl-C로 멈추고 Claude Code 또는 Codex CLI를 설치·로그인한 뒤, 새 폴더로 실행합니다:

```sh
TEAM_AX_DEV_DIR="$HOME/.trina-ai-check-new" TEAM_AX_DEV_PORT=19701 TEAM_AX_DEV_RELAY_PORT=19702 bun run dev
# 두 번째 터미널, 같은 저장소에서 (직접 팀을 만들기 전에):
TEAM_AX_DEV_DIR="$HOME/.trina-ai-check-new" bun run demo:seed --base http://127.0.0.1:19701
```

개발 모드에는 운영 OS 격리가 없고 AI 요청에 제공사 비용·약관이 적용됩니다. 가상 자료만 사용하고 외부로 노출하지 마세요. 중계 시험에는 Node 24+가 필요하며 `--no-relay`로 생략할 수 있습니다. 아래 표는 개발 기본 주소이며 이 예시에서는 각각 19701·19702로 바꿔 씁니다. 전체 설치는 [INSTALL.md](INSTALL.md), 빠른 체험은 [QUICKSTART.md](QUICKSTART.md)입니다.

## 주소

| 주소 | 무엇 |
|---|---|
| **http://localhost:19100** | 팀 서버에 바로 연결 (사무실 안 직접 연결에 해당) |
| **http://demo.localhost:19161** | 중계 서버를 거친 연결 (나중의 `팀이름.trina.app`에 해당. 지금은 이 맥 안의 중계 서버) |

두 주소는 같은 팀, 같은 데이터입니다. 화면 맨 위의 노란 띠 "개발 모드: OS 격리 없음…"은 개발 모드라서 늘 보입니다(아래 "알려진 한계").
다른 체크아웃의 `bun run dev`를 옆에 같이 띄우려면 데이터 폴더와 두 포트를 바꿉니다: `TEAM_AX_DEV_DIR=~/.team-ax-dev2 TEAM_AX_DEV_PORT=19200 TEAM_AX_DEV_RELAY_PORT=19261 bun run dev`(`--vite`는 19140 고정이라 한쪽에서만).

  - `groups/마케팅/2026-10-14-마케팅-회의록.md`, `groups/마케팅/가을-캠페인-2차-기획안.docx`

- 시드 자체는 AI 채팅을 만들거나 모델을 호출하지 않습니다. 아래 채팅 예제는 엔진을 연결한 뒤 직접 실행합니다.

AI 연결 상태는 실행한 맥의 설치·로그인에 따라 달라요. 개발 모드는 그 맥 사용자의 Claude Code·Codex CLI 로그인을 쓰며,
AI를 호출하면 해당 계정의 사용량이 나가요. 파일 화면과 권한은 모델 호출 없이 확인할 수 있어요.

### 언어 (다섯 언어 지원)
새 팀의 언어는 브라우저 제안을 확인해 선택하고 관리자에서 바꿉니다. 데모 팀은 한국어 팀이고, 데모 계정 넷은 각자 "한국어"를 고른 상태라 그대로 한국어로 보입니다.
- [ ] **개인 설정**: 왼쪽 아래 이름 → 설정 → 언어. "팀 기본값 (한국어)" / English / 한국어 / Bahasa Indonesia / 日本語 / Español 중 하나. "팀 기본값"을 고르면 관리자가 팀 언어를 바꿀 때 같이 바뀜
- [ ] **팀 기본 언어**(dion 또는 admin1): 관리자 → 팀 설정 → 팀 기본 언어. 자기 언어를 고르지 않은 사람(이후 초대·추가하는 사람은 모두 처음엔 "팀 기본값")이 이 언어로 봄
- [ ] **로그인 전**: 로그인·초대·비밀번호 재설정 화면 아래의 언어 선택. 이 브라우저에만 기억하고, 고르지 않으면 팀 기본 언어로 보임(브라우저 언어 제안도 확인). 자기 언어가 없는 사람이 여기서 고르고 로그인하면(초대 화면도) 그 사람의 언어로 저장됨
- [ ] **다른 사람의 언어**(관리자): 관리자 → 구성원 → 편집 → 언어. 바꾸면 그 사람의 열린 창이 바로 바뀜. 팀 기본 언어를 바꿀 때도 "팀 기본값"인 사람의 열린 창이 새로 고침 없이 바뀜
- [ ] 언어를 바꾸면 예전 채팅의 작업 단계("파일 읽기 · …", "기억함: …")도 새 언어로 보임
- [ ] **데스크톱 앱**: 팀 페이지의 언어를 따라감(메뉴·브라우저 패널·사이트 허용 질문). 팀 목록 화면 아래에서도 고를 수 있음. 처음 설치 시 언어 설정 확인
- [ ] 메뉴바 앱은 팀 기본 언어를 따름(서버가 꺼져 있으면 마지막으로 본 팀 언어, 처음엔 영어)

### 팀 스킬 (skills/의 작업 절차)
`skills/` 아래 md 파일 중 맨 위에 `---` / `name: …` / `description: …` / `---` 머리말이 있는 것이 **스킬**입니다(머리말이 없는 md는 지금처럼 매 턴 읽는 팀 규칙). 하위 폴더도 되고, 누가 쓸 수 있는지는 폴더 권한을 따릅니다.
- [ ] dion: "'고객 문의 답장' 팀 스킬을 만들어 줘: 공감 한 문장 → 해결 방법 → 다음 단계, 존댓말 5문장 이내" → `skills/`에 머리말이 있는 md가 생김
- [ ] alice: 입력창에 `/` → 쓸 수 있는 스킬 목록, ↑↓·Enter로 고르면 `/<이름> `이 들어감 → 뒤에 입력(예: "마케팅 관련만")을 붙여 보내면 그 스킬의 절차대로 답함
- [ ] alice: `/` 없이 "이번 주 주간 보고서 만들어 줘" → AI가 맞는 스킬을 골라 쓰고 어떤 스킬인지 말함
- [ ] 폴더 권한에서 `skills/재무`에 "재무 그룹: 읽기"와 "모두: 권한 없음" → bob의 `/` 목록에는 있고 alice에게는 없음(alice가 `/월말 결산`을 쳐도 스킬이 들어가지 않음)

**누가 스킬을 바꾸나 (팀 스킬 관리)**: `skills/`에 쓰기 권한이 있는 사람이 "스킬 관리자"입니다. owner·관리자는 항상, 다른 사람은 관리자가 켜 줄 때만. 팀 스킬과 팀 규칙은 팀 전체 AI가 따르므로, 바뀐 것은 모두 기록되고 owner·관리자에게 알림이 갑니다.
- [ ] dion: 관리자 > 멤버 → bob 줄의 **팀 스킬 관리** 스위치 → 경고("…팀 전체 AI가 따릅니다") 확인 → 관리할 범위 `skills/재무/` → **팀 스킬 관리 켜기** → 줄에 `skills/재무/`가 보임
- [ ] dion: 관리자 > 폴더 권한 → `skills/재무`에 "Bob: 읽기·쓰기 · 팀 스킬 관리"가 같은 규칙으로 보임(여기서 바꿔도 멤버 화면에 그대로 반영)

## 데스크톱 앱

- 파일: 직접 빌드한 `desktop/release/Trina-AX-<version>-mac-universal.dmg` (Apple Silicon·Intel, 서명·공증 없음). Mac DMG는 아직 배포하지 않으며 Windows 릴리스 이름은 `Trina-AX-Setup-<version>-win-x64.exe`입니다
- 열어서 Trina AX를 응용 프로그램 폴더로 끌어 놓습니다.
- 이 맥에서 빌드한 파일이라 그대로 열릴 가능성이 높습니다. "확인되지 않은 개발자" 경고가 나오면:
  1. Finder에서 Trina AX를 **오른쪽 클릭(control+클릭) → 열기 → 열기**
  2. 그래도 막히면(macOS 15 이후): 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "Trina AX이(가) 차단되었습니다" 옆 **그래도 열기**
  3. 다른 맥으로 옮긴 파일이면 터미널에서 `xattr -dr com.apple.quarantine "/Applications/Trina AX.app"`
- 첫 화면에 팀 주소를 넣습니다: `localhost:19100` 또는 `demo.localhost:19161` (`*.localhost`만 http 허용).
- 다시 만들기: `cd desktop && bun run dist:mac` (윈도우용 서명 없는 설치 파일은 `bun run dist:win`).

## 개발 서버 멈추기·다시 켜기

`bun run demo`와 `bun run dev`는 기본적으로 전경 실행입니다. 시작한 터미널에서 Ctrl-C로 멈추면 자신의 자식 프로세스가 종료됩니다. Mac에서 선택적으로 `bun run dev:service install`을 실행했을 때만 LaunchAgent `app.team-ax.dev`로 로그인 시 시작합니다. 서비스 이름은 고정이므로 다른 체크아웃의 서비스를 덮어쓰지 마세요. 직접 설치한 서비스만 아래 명령으로 관리합니다:

```sh
bun run dev:service status      # 돌고 있는지, 두 주소가 답하는지
bun run dev:service logs        # 최근 로그 (전체: ~/Library/Logs/team-ax-dev/dev.log)
bun run dev:service restart     # git pull 뒤 등 (웹 화면이 바뀌었으면 시작할 때 다시 빌드함)
bun run dev:service stop        # 현재 실행만 멈춤 (다음 로그인 때 돌아올 수 있음)
bun run dev:service start
bun run dev:service uninstall   # LaunchAgent 제거 (데이터는 남음)
```

터미널에서 직접 보고 싶으면 `bun run dev:service stop` 후 `bun run dev`(Ctrl-C로 끔).

**처음부터 다시**: 시작한 전경 프로세스를 Ctrl-C로 멈추고 새 데이터 경로로 시작합니다. 데이터는 남아 있으므로 삭제가 필요하면 자신이 만든 가상 체험 폴더만 확인해 지우세요. 운영 팀이나 다른 체크아웃의 데이터는 건드리지 마세요. `demo:seed`는 같은 가상 팀의 빠진 것만 채우며 다른 owner의 팀은 거부합니다.

**문제 해결**: 포트가 사용 중이면 다른 빈 포트를 골라 실행·시드 주소에 일관되게 적용하세요. Mac 소켓 경로 오류는 홈 아래 짧은 데이터 경로를 사용하고 `/tmp`는 피하세요. AI가 없어도 파일은 볼 수 있습니다. 실 모델 시험 실패는 CLI 설치·로그인·버전과 native 빌드를 확인하세요. 초대 토큰·AI 키·실제 자료는 이슈에 붙이지 마세요.

## 알려진 한계 (이번 데모)

- **개발 모드입니다.** AI 엔진이 맥의 현재 사용자 계정으로 돌고, OS 격리(전용 `_axagent` 계정·샌드박스·pf)는 없습니다. 팀 파일 접근은 권한 함수 + 엔진 잠금 + 도구 관문으로 막지만, 운영 모드의 세 번째 겹(OS)이 빠진 상태입니다. 또 이 모드에서는 Claude Code가 매 턴 문맥에 그 맥 사용자의 Claude 계정 이메일을 넣습니다(끌 방법 없음). 운영 모드로 바꾸는 법은 [INSTALL.md](INSTALL.md) 2장.
- 사용량은 그 맥 사용자의 Claude 구독과 ChatGPT 구독에서 나갑니다. 관리자 화면에서 정한 사용 한도는 이 모드에서도 적용됩니다.
- 원격 주소는 이 맥 안의 중계 서버(`demo.localhost`)뿐입니다. 이 개발 주소는 다른 컴퓨터·휴대폰에서 접근할 수 없습니다. 운영 서버는 설정된 공인 HTTPS 주소나 검증한 사무실 LAN 주소를 사용합니다.
- 메일이 없습니다. 초대·비밀번호 재설정은 링크를 복사해서 전합니다(의도된 설계).
- 데스크톱 앱은 서명·공증이 없어서 처음 열 때 위 절차가 필요하고, Windows 배포 앱은 팀 서버의 업데이트 경로를 사용합니다. 직접 빌드한 앱의 업데이트·서명 상태는 별도로 확인합니다.
- 앱 안 브라우저 도구는 데스크톱 앱에서만 됩니다(웹 브라우저에서 채팅하면 AI에게 브라우저 도구가 주어지지 않음).
- 음성 입력은 기본 꺼짐입니다. 관리자가 OpenRouter 또는 서버 whisper를 선택하며 서버 방식만 처음 모델(약 490MB)을 내려받습니다.
- 알림과 팀 스킬 변경 내역은 앱의 알림·최근 변경에서 확인합니다.
