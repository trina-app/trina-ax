---
name: meeting-summary
description: Summarize a meeting note into decisions, action items and open questions, with references to the source.
---

Ask for the meeting-note path if it was not provided. Read it using the available file tools and the asking
person's permissions. If it cannot be read, explain that and ask for a permitted source.

Return:

1. A short meeting summary with the source path.
2. Decisions explicitly recorded in the note.
3. An action table with task, owner and due date. Write "not specified" where the note has no owner or date.
4. Open questions and uncertainties.

Do not invent people, dates, decisions or figures. Do not send the note to an external service or save a copy
unless the person asks. Follow the server's access checks and confirmation requests.
