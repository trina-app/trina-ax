시작 전에

10분

Team AX는 사무실 맥 한 대(이하 서버 맥)에서 팀 서버와 AI 엔진(Claude Code, 선택으로 Codex)을 돌리고, 팀원은 웹 브라우저로 그 맥에 들어와서 써요. AI 사용량은 팀장의 Claude 구독에서 나가요.

준비물

무엇설명
늘 켜 둘 맥 한 대애플 실리콘(M1 이후)을 권해요. 인텔 맥도 되지만 빌드할 때 한 단계가 더 있어요(1장). 전원에 꽂아 두고, 잠자기에 들지 않게 둬요. 정식 설치는 잠자기를 알아서 꺼요.
macOS이 가이드는 macOS 26.3.1에서 확인했어요. 메뉴바 앱은 macOS 13 이상이 필요해요.
Claude 구독Claude Pro 또는 Max 계정. 팀 전체의 AI 답변이 이 구독 하나에서 나가서, 팀원 모두가 이 구독의 사용 한도를 함께 써요. 한도에 닿으면 풀릴 때까지 모두의 AI 답변이 멈춰요. 사람이 많으면 Max를 권해요. 정식 설치에서는 이 계정으로 1년짜리 토큰(claude setup-token)을 한 번 만들어요. API 키는 필요 없어요.
ChatGPT 구독 (선택)두 번째 엔진 Codex를 쓰려면 필요해요. 없어도 Claude만으로 동작해요. 정식 설치에서는 아직 베타예요.
맥 관리자 계정·암호개발 모드도 1-1의 Homebrew 설치가 한 번 물어요. 정식 설치(2장)는 sudo가 들어간 명령마다 물어요.

인터넷·저장 공간도구와 앱을 내려받아요. 음성 입력을 쓰면 처음 한 번 약 490MB 모델을 더 받아요.

빠르게 써 보기

개발 모드 · 도구 설치 포함 1시간 안팎

맥 한 대에 Team AX를 개발 모드로 띄워요. AI 엔진은 지금 로그인한 맥 사용자로, 그 사람의 Claude 로그인으로 돌아요. 가장 빨리 써 보는 방법이고, 관리자 암호는 1-1의 Homebrew 설치에서만 물어요. 실제 팀은 2장의 정식 설치로 써요.

1-1필요한 도구 설치 (30분~1시간)

애플의 개발 도구와 Homebrew(맥용 설치 도구)부터 설치해요. 이미 있으면 건너뛰어요.

xcode-select --install

개발자 도구를 설치할지 묻는 창이 뜨면 설치를 누르고 끝날 때까지 기다려요(10~20분). “already installed”가 나오면 이미 있는 거예요. 그다음 Homebrew:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

맥 로그인 암호를 묻고(관리자 계정이어야 해요), Return을 한 번 더 누르라고 해요. 끝나면 마지막에 이런 안내가 나와요. “Next steps” 아래 들여 쓴 명령 줄을 모두 그대로 복사해 실행하고, 터미널을 닫았다가 다시 열어요.

- Run these commands in your terminal to add Homebrew to your PATH:
    echo >> /Users/나/.zprofile

curl -fsSL https://bun.sh/install | bash -s "bun-v1.3.12"

GoAI 엔진을 지키는 작은 프로그램(도구 관문·실행기)을 빌드해요.

시험을 맞춰 둔 버전(2.1.305)으로 설치해요.

curl -fsSL https://claude.ai/install.sh | bash -s 2.1.305

claude를 처음 실행하면 브라우저가 열려요. Claude Pro/Max 계정으로 로그인하고 승인한 뒤, 터미널로 돌아와 control + C를 두 번 눌러 닫아요. Claude Code는 스스로 새 버전으로 업데이트할 수 있어요. 그러면 1-6의 AI 엔진 카드가 “검증하지 않은 버전”으로 보이지만 채팅은 돼요.

Codex(선택): Homebrew로 설치하고 ChatGPT 계정으로 로그인해요. 이 가이드는 0.163.0으로 확인했어요. npm으로 설치한 Codex는 2장의 정식 설치가 받지 않아요.

brew install --cask codex
codex login
확인claude --version → 2.1.305 (Claude Code). Codex를 넣었으면 codex --version에도 버전이 나와요. 로그인 여부는 1-6에서 Team AX 화면으로 확인해요.
1-3내려받고 빌드하기

공개 저장소에서 내려받아요. GitHub 로그인은 필요하지 않아요.

cd ~
git clone https://github.com/trina-app/trina-ax.git
cd trina-ax
bun install --frozen-lockfile
bun run build

앞으로 나오는 명령은 이 ~/trina-ax 폴더에서 실행해요. 처음 온 분은 빠른 체험 안내(영문)에서 별도 데이터 폴더와 19720 포트를 쓰는 절차를 볼 수 있어요.

인텔 맥이라면

빌드 도구가 기본으로 애플 실리콘용만 만들어요. bun run build 다음에 ARCHS=amd64 bun run build:native를 한 번 더 실행하세요. 안 하면 채팅이 “엔진을 쓸 수 없음”으로 끝나요.

확인bun install --frozen-lockfile과 bun run build가 오류 없이 끝나야 해요. 설치 개수와 시간은 환경에 따라 달라요.

정식 설치

서버 맥 · 관리자 암호 필요 · 약 1시간

정식 설치는 서버와 AI 엔진을 숨은 전용 계정(_axserver, _axagent)으로 돌리고, AI를 샌드박스와 방화벽 규칙 안에 가둬요. 엔진 계정은 이 맥 안의 모델 프록시에만 연결할 수 있고, 팀장의 Claude 토큰은 프록시가 붙여 보내서 엔진은 진짜 토큰을 보지 못해요. 맥이 켜지면 아무도 로그인하지 않아도 시작해요.

이 장의 순서와 지금 상태
  • 순서: 준비 → 시험 설치(권장) → 묶음 만들기 → 검사 → 설치 → Claude 토큰 → Codex 로그인(선택) → 팀 만들기 → 첫 채팅으로 확인.
  • 확인 전 Claude 채팅까지 코드와 시험은 끝났지만, 실제 숨은 전용 계정으로는 아직 한 번도 돌려 보지 않았고, 진짜 토큰으로 Anthropic의 답을 받아 본 적도 없어요. 그래서 2-2의 시험 설치를 먼저 해요(스스로 지워져서 실제 설치와 섞이지 않아요).
  • 준비 중 남은 것: 서명(--allow-unsigned 필요), 공개 팀 주소, 메뉴바 앱의 토큰 넣기, Codex 실제 로그인 확인(베타).
  • 개발 모드의 팀·파일은 정식 설치로 옮겨지지 않아요. 정식 설치에서는 팀을 새로 만들어요.
2-1준비: 도구, 터미널 권한, 개발 서버
  • 1장의 1-1 ~ 1-3(도구 설치, Claude Code 설치, 내려받기와 빌드)을 먼저 끝내요. Claude Code는 설치 스크립트가 엔진으로 복사하고, 2-6의 토큰도 이것으로 만들어요. claude 로그인(1-2의 브라우저 승인)은 정식 설치에는 필요 없어요.
  • 시스템 설정 → 개인정보 보호 및 보안 → 전체 디스크 접근 권한에서 터미널을 켜요. 목록에 없으면 +를 눌러 응용 프로그램 → 유틸리티 → 터미널을 추가해요. 켠 뒤에는 터미널을 완전히 종료(⌘ + Q)했다가 다시 열어야 적용돼요. 없으면 설치는 되지만 타임머신 제외·예약 작업 차단을 못 해서 경고가 나와요.
  • 개발 서비스(1-7)를 등록했다면 끄는 것을 권해요. 포트(정식 47820·47821·8443, 개발 19100·19161)는 겹치지 않아서 같이 돌아도 되지만, 팀이 둘이면 헷갈려요.
cd ~/team-ax
bun run dev:service uninstall     # 데이터 ~/.team-ax-dev 는 남아요

    cd ~/team-ax

  • 엔진(--engine)과 Claude 토큰, 팀 데이터는 그대로 남아요.

  • 번호를 올리지 않고 같은 번호로 다시 설치하면 그 버전을 제자리에서 바꿔서, 되돌릴 이전 버전이 남지 않아요. 고장 난 설치를 고칠 때만 그렇게 해요.

백업은 같은 디스크에 있어요

맥이 고장 나면 백업도 같이 잃어요. 가끔 다른 곳(외장 디스크 등)에 복사하세요.

개발 모드: 서비스를 멈추고(bun run dev:service stop) ~/.team-ax-dev 폴더를 통째로 외장 디스크에 복사한 뒤 다시 켜요(start).

정식 설치: 서버 계정으로 데이터베이스와 팀 파일을 담은 암호화 파일을 하나 만들어요.

B="/Library/Application Support/mycel"
cd / && sudo -u _axserver env MYCEL_MODE=prod HOME="$B/data" \
     "$B/app/current/bin/bun" "$B/app/current/server/src/admin.js" \
     archive --out /Users/Shared/teamax-backup.tar.zst.age --password-stdin

관리자 암호 다음에 이 파일용 암호(8자 이상)를 입력하고 Return, 이어서 control + D를 눌러요. 입력한 암호가 화면에 보이니 주변을 확인하고, 암호는 따로 잘 적어 두세요(잃으면 풀 수 없어요). 끝나면 {"file":"/Users/Shared/teamax-backup.tar.zst.age",…,"encrypted":true,"files":파일 수}가 나와요. 이 파일은 서버 계정 것이라 외장 디스크로 옮길 때도 sudo cp /Users/Shared/teamax-backup.tar.zst.age /Volumes/외장 디스크 이름/처럼 sudo를 붙여요.

이 파일은 맥이 고장 났을 때 새 폴더에 풀어 내용을 꺼내는 용도예요(restore-archive --in 파일 --to 새 폴더, 방법은 영문 docs/INSTALL.md). 풀어 낸 폴더로 서버를 바로 되살리는 기능은 아직 없어요 준비 중.

알려진 문제

Team AX를 받은 곳에 물어볼 때 이 번호를 같이 알려 주면 빨라요.

  1. 정식 설치의 Claude 채팅은 실제 맥에서 아직 확인 전이에요. 숨은 전용 계정으로 돌린 적이 없고(2-2 시험 대기), 진짜 토큰으로 Anthropic의 답을 받아 본 적도 없어요.
  2. 정식 설치의 Codex는 베타예요. 실제 ChatGPT 로그인으로 방화벽을 켠 상태의 연결·토큰 갱신·웹 검색은 확인 전이에요. codex 파일 하나만 복사되고, 팀장 말고 다른 사람에게 열어 주는 화면이 없어요.
  3. 메뉴바 앱에 Claude 토큰 넣기·설정 마법사·방화벽 복구·설치 다시 하기·제거가 없어요. 그런데 진단 문구 몇 개는 아직 “메뉴바 앱의 …”를 하라고 해요(5장의 “설치 다시 하기”로 해요).
  4. 모델 프록시가 요청을 보낸 프로그램을 확인하는 방법이 아직 단순해요(더 꼼꼼한 확인은 다음 작업).
  5. 공개 중계 서버가 없어서 다른 컴퓨터의 데스크톱 앱이 연결되지 않아요. 새 버전 알림 주소가 없어 관리자 화면의 업데이트는 되돌리기만 돼요.
  6. 설치 스크립트가 Claude Code 버전이 고정 버전(2.1.305)과 달라도 알려 주지 않아요. Codex 경로가 비어 있을 때의 메시지(engine codex:  not found)도 알아보기 어려워요.
  7. 토큰 저장 도구는 붙여 넣은 내용의 첫 줄만 읽어요. 2-6처럼 tr -d '[:space:]'를 거치면 괜찮아요.
