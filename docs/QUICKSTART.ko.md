# 로컬에서 트리나 AX 체험하기

[English](QUICKSTART.md) · [팀장 안내](for-teams.ko.md)

가상 자료로 파일·스킬·앱 권한을 확인하는 체험입니다. **운영 설치가 아니며 AI는 비활성화됩니다.** AI 계정 없이 시작할 수 있습니다. 답변 품질이나 운영 격리를 검증하는 환경은 아닙니다.

## 준비물과 실행

Mac 또는 Linux, Git, Bun 1.3.12(CI 고정 버전), Go 1.27 이상, 네이티브 빌드 도구가 필요합니다. Mac에는 Xcode 명령줄 도구가 필요합니다. 준비된 장비에서는 약 10분을 잡으세요. 도구 설치와 다운로드 시간은 별도입니다. 이 절차는 macOS에서 실행 확인했으며 Linux 개발 체험은 해당 장비에서 확인해야 합니다. Windows 서버용 절차는 제공하지 않습니다.

```sh
git clone https://github.com/trina-app/trina-ax.git
cd trina-ax
bun install --frozen-lockfile
bun run demo --locale ko
```

마지막 한 명령이 빌드·서버 실행·가상 자료·스킬 6개·설명용 결과 파일 입력을 수행합니다. **http://127.0.0.1:19760**으로 접속하세요. loopback으로만 열고 중계와 AI 엔진은 끕니다. 이 컴퓨터에 기존 AI 로그인이 있어도 사용하지 않습니다. 인터넷에 공개하거나 실제 자료를 넣지 마세요.

```sh
bun run demo --port 19761 --data "$HOME/.trina-evaluation-new" --locale ko
```

`--data` 경로는 **아직 없어야 합니다**. 기존 폴더는 데모 여부와 관계없이 거절합니다. Mac에서는 `/tmp` 밖의 짧은 경로를 쓰세요. 포트가 사용 중이면 자료를 입력하기 전에 멈춥니다. 기본 실행은 매번 새 폴더를 만듭니다.

## 첫 결과 확인

1. `alice` / `teamax-demo-1`로 로그인합니다. 공개된 가상 체험 계정입니다.
2. **파일 → shared → 팀-용어집.md**를 열어 용어 표를 확인합니다.
3. 별도 브라우저 프로필에서 `bob`과 같은 암호로 로그인합니다. Alice는 마케팅, Bob은 재무 폴더를 봅니다. Bob에게는 재무의 급여 하위 폴더가 보이지 않습니다.
4. 가상 소유자 `dion`으로 로그인해 팀 스킬과 관리 화면을 봅니다. [스킬 예제 복사](../examples/README.ko.md).

파일은 한국어이며 로그인 화면과 설정 → 프로필 → 언어에서 UI 언어를 바꿀 수 있습니다.

## 종료·정리

실행 터미널에서 **Ctrl-C**를 누르면 자신이 시작한 서버만 PID로 종료합니다. 출력된 전용 폴더에 자료가 남습니다. 종료 후 필요 없다면 그 폴더만 지우세요. 실제 팀 폴더는 지우지 마세요. 빌드 실패 후에도 빈 폴더가 남을 수 있으니 재시도할 때 새 경로를 고르세요.

실제 AI 작업은 허용된 계정을 사용하는 별도 [개발 환경](DEVELOPMENT.md)이나 [호스팅 상담](https://ax.trina.app/#contact)으로 진행하세요. 제공사 약관·사용료가 적용됩니다.
