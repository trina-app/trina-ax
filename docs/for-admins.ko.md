# IT 담당자용 도입·운영 안내

[English](for-admins.md)

자료 민감도, 서버 운영자, 허용된 AI 연결, 필요한 클라이언트, 외부 통신과 복구 담당자를 먼저 정하세요. 모델 제공사로 문맥이 전송되며 호스팅 운영자도 저장 자료를 읽을 수 있습니다. [보안 경계](security-and-permissions.ko.md).

밖으로 나가는 통신이 두 가지 더 있습니다. 서버는 시작할 때와 30분마다 `https://updates.trina.app/ip`에 자기 공인 주소를 묻습니다(`MYCEL_EXIT_ADDRESS_CHECK=off`로 끌 수 있고, 끄면 AI가 여는 웹 주소마다 사람에게 묻고 예약 작업은 웹 주소를 열지 않습니다. 서버가 주소를 아는지는 관리자 > 시스템 > 진단에서 보입니다). 그리고 Codex 웹 검색은 검색할 때마다 지금까지의 대화 내용을 OpenAI의 검색 서비스로 보냅니다.

save_url 다운로드는 AI가 여는 웹 페이지처럼 서버에서 파일 주소로 나갑니다. 공용 인터넷 주소만 열고, 리다이렉트마다 다시 확인합니다. 받는 파일은 `<data>/work`에 바로 흘려 쓴 뒤 팀 폴더로 옮깁니다. 크기 상한은 없지만 1 GB가 넘는 파일은 먼저 사람에게 묻고(예약 작업은 건너뜀), 받은 뒤 디스크 여유가 디스크의 10%(최소 5 GB, 최대 20 GB)보다 적게 남는 다운로드는 서버가 거절합니다. 연결된 서비스가 답 안에 담아 보낸 이미지·파일은 `<data>/connection-media`에 24시간 보관합니다(채팅당 최대 200 MB). 연결된 서비스 도구의 답은 이제 25 MB까지 받습니다(그 밖에는 1 MB).

AI가 사진·화면 캡처·스캔한 PDF 페이지를 읽으면 이미지를 직접 보고, 이미지는 다른 파일 내용처럼 모델 제공사로 전송됩니다. 관리자는 팀 설정의 "이미지·PDF 페이지·영상 장면을 AI에게 보내기"(기본 켜짐)로 끌 수 있습니다. 이 설정은 한글 문서 쪽 이미지와 앱 안 브라우저의 화면 캡처에도 적용됩니다. Linux 서버는 글자 인식(OCR)을 하지 않으므로 스캔 문서와 사진은 글자로 검색되지 않습니다.

Linux 서버에서는 AI가 영상·오디오 파일(1GB까지)을 Claude Code 사용자가 ffmpeg와 whisper로 하듯 읽습니다. 고르게 고른 장면(위 설정)과 시간이 붙은 받아쓰기입니다. ffmpeg는 배포판에서 옵니다(설치 프로그램의 apt 의존 패키지이며 번들에 들어 있지 않음). 디코더가 사람들이 올린 파일을 읽으므로 서버의 보안 업데이트를 켜 두세요. 받아쓰기는 "영상 소리를 글로 바꾸기"가 켜져 있을 때만 팀의 음성 제공자(팀 설정 › 음성 입력)를 씁니다. "이 서버에서"는 기본 켜짐(CPU 코어가 2개 이하인 서버에서는 오래 걸려 기본 꺼짐; 장면은 그대로 감), OpenRouter는 기본 꺼짐이며, OpenRouter에서 켜면 팀 파일의 소리가 OpenRouter와 그 제공사로 갑니다(허용해야 할 또 하나의 바깥 연결, 기밀 대화에서는 보내지 않음). 새 받아쓰기마다 활동 기록이 남습니다("영상·오디오 소리를 글로 바꿈": 누가, 어느 파일, 몇 초, 어떤 제공자; 내용은 남기지 않음). "이 서버에서"는 소리를 30초씩 나눠 이 서버가 잰 속도로 한 번 읽는 시간(5분) 안에 끝나는 만큼 바꾸고, 바꾼 조각은 남겨 두어 다시 읽으면 그다음부터 이어 갑니다. 음성 입력이 영상 받아쓰기보다 먼저입니다. 사무실 맥은 아직 영상·오디오를 읽지 못합니다.

트리나가 호스팅하는 서버(무료 요금제 포함)에는 받아쓰기가 들어 있습니다. 팀마다 한 달(한국 시간)에 요금제에 따라 소리 시간이 하나로 주어지고(Starter 50시간, Team 100시간, Business 200시간, 무료 요금제 10시간), 음성 입력과 AI의 영상·오디오 파일 읽기가 함께 씁니다. 이 서버에서는 음성 입력이 기본으로 켜지고 "영상 소리를 글로 바꾸기"도 기본 켜짐입니다. 소리는 OpenRouter를 거쳐 미국의 DeepInfra(DeepInfra가 안 될 때는 미국의 Groq)로 가며, 데이터를 남기지 않고 학습에 쓰지 않는 곳으로만 갑니다. 팀 설정 › 음성 입력에서 요금제의 시간 중 이번 달 쓴 시간을 볼 수 있고, 그 시간을 넘으면 다음 달 1일까지 음성 입력과 영상 받아쓰기가 멈추며 그렇게 알려 줍니다. 팀이 같은 곳에 자기 OpenRouter 키를 넣으면 그 키를 먼저 쓰고, 시간 제한 없이 팀의 OpenRouter 계정으로 요금이 나갑니다. 음성 입력이나 "영상 소리를 글로 바꾸기"를 끄는 것은 다른 서버와 같습니다. 기밀 대화에서는 소리를 내보내지 않습니다. 파일의 소리도, 음성 입력도 마찬가지입니다. 입력창이 어느 대화의 녹음인지 서버에 알리고, 서버는 기밀 대화의 녹음을 OpenRouter로 보내지 않습니다(입력창에 그 이유가 나옵니다. 아직 만들지 않은 새 대화는 모든 대화가 기밀일 때만 기밀로 봅니다). "이 서버에서"를 쓰면 소리가 서버 밖으로 나가지 않으므로 기밀 대화에서도 음성 입력을 쓸 수 있습니다.

기본적으로 한 답변에서 AI는 도구를 최대 150번 쓸 수 있습니다(한꺼번에 쓴 도구는 한 번으로 셉니다). 관리자는 팀 설정의 "한 답변의 도구 사용 한도"(10~500)에서 바꿀 수 있습니다. 한도에 닿으면 답이 멈추고 "이어서 하기"로 계속합니다. 높일수록 한 답변이 더 오래 일하므로 비용이 늘 수 있고, 20분 작업 시간과 예산 한도는 그대로 적용됩니다.

| 방식 | 안내 | 운영 경계 |
|---|---|---|
| Linux 서버·VM | [설치](INSTALL-LINUX.md) | systemd·cgroup v2, 전용 계정·OS 격리. 일반 Docker 컨테이너는 운영 설치 대상이 아님 |
| 사무실 Mac | [설치](OFFICE.md) | 로그인 사용자로 실행, 로그아웃하면 중단. Claude 전용 경로, Codex 없음 |
| 역할 계정 Mac | [영문 상세](INSTALL.md) | 별도 계정·LaunchDaemon. 운영자가 소스 번들 관리; 배포 DMG 경로 아님 |
| 가상 로컬 체험 | [빠른 체험](QUICKSTART.ko.md) | AI 비활성화, loopback, 운영 격리 검증 아님 |

소유자 계정 생성 후 **권한 → AI 연결 → 팀원 초대 → 첫 스킬 → 첫 백업** 순서로 진행하세요. 관리형 연결은 개인 우선이며 새 팀은 회사 연결 하나를 팀 전체가 쓰는 설정이 기본 켜짐입니다. 기존 선택과 연결별 동의는 유지되고 제공사 약관은 별도입니다.

시범 운영 합격 기준: 두 계정의 파일 접근 차이, 원본을 확인한 스킬 결과, 사용량 확인, 암호화한 외부 백업과 복구 검증입니다. [예제](../examples/README.ko.md) · [백업·복원](BACKUP-RESTORE.md).

업데이트 전에 [최신 릴리스](https://github.com/trina-app/trina-ax/releases/latest)와 기본값 변경을 읽고 백업하세요. Linux·사무실 Mac은 트리나 피드를 사용합니다. 앱 롤백이 DB·파일 롤백은 아닙니다. Linux 서버는 지금 버전과 되돌리기용 이전 버전만 남기고 더 오래된 버전은 스스로 지우므로, 앱은 디스크를 1–1.5 GB쯤 씁니다([업데이트](INSTALL-LINUX.md#8-업데이트)). [설정](CONFIGURATION.md) · [문제 해결](TROUBLESHOOTING.md).

현재 브라우저·모바일 웹과 Windows 설치 파일을 사용합니다. Mac 서버 ZIP과 데스크톱 DMG는 다릅니다. 현재 소스는 EN/KO/ID/JA/ES를 지원합니다. HWP 시각 미리보기는 선택해서 설치하는 플러그인(관리 > 플러그인)이며 Debian 12에서 지원하지 않고 기본 번들에는 실행 도구가 없습니다. 설치 파일을 받기 전에 릴리스 설명을 확인하세요. [지원](../SUPPORT.md).

Linux 서버에서 AI가 만드는 PDF는 릴리스에 함께 들어 있는 Noto Sans CJK 글꼴로 한글·일본어·중국어를 그립니다. 따로 설치할 것은 없습니다. 사무실 Mac은 Mac의 글꼴(Apple SD Gothic Neo, Hiragino Sans, PingFang)을 씁니다. PDF마다 쓰인 언어에 맞춥니다. 일본어 문서는 일본어 글꼴을, 중국어 문서는 중국어 글꼴을 먼저 씁니다(같은 한자라도 나라마다 모양이 다릅니다). 한글·일본어·중국어가 없는 문서는 팀 언어를 따릅니다.
