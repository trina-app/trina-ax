# Microsoft 365 is a listed connector with our own Graph tools, signed in through the server's Microsoft app

- Date: 2026-11-25
- Status: accepted
- Supersedes: none
- Branch: feat/m365-connector (owner's ask, 2026-11-25)

- **Ask:** connect Microsoft 365 (Outlook mail, Calendar, OneDrive and SharePoint files, Teams chat) with "Sign in with
  Microsoft", like the Google connectors, on every install type: hosted, a Linux server, the office Mac, and the
  Windows and Mac desktop apps.
- **Rule 1, our own tools:** Microsoft offers no remote MCP server a third-party app can sign in to (its Agent 365 /
  Work IQ servers need a Microsoft 365 Copilot licence, an admin who turns them on and Microsoft's own permissions;
  checked 2026-11-25). The tools are ours, over Microsoft Graph v1.0, served by an MCP server inside the team server
  (`server/src/integrations/microsoft/`): no child process, no Python, so it runs wherever the server runs (Linux,
  macOS, Windows), unlike the Google apps' library (Linux only).
- **Rule 2, one listed service, the GitHub way:** "Microsoft 365" is a listed service (`microsoft365`,
  `serverApp: 'microsoft'`) at the reserved address `https://microsoft-365.invalid/mcp`. Its connection is an
  ordinary MCP connection, personal or team, with every generic rule (the write card, Always allow, per-tool switches,
  scheduled-run rules, audit, sealed tokens). One sign-in covers all four parts; a person who does not want Teams or
  Files switches those tools off. Not four cards like Google: one Microsoft consent screen, one token.
- **Rule 3, the app:** a connection with no own app signs in through the Microsoft (Entra) app the server holds
  (`MYCEL_MICROSOFT_APP_FILE`, else `<secrets>/integrations/microsoft/app.json`, `{ clientId, clientSecret, tenant? }`,
  read like the GitHub App file; hosted teams get it with the tenant command `microsoft-app-set`). Fixed addresses
  `https://login.microsoftonline.com/<tenant>/oauth2/v2.0/authorize|token` (tenant `common` by default), fixed
  delegated scopes `openid profile email offline_access User.Read Mail.ReadWrite Mail.Send Calendars.ReadWrite
  Files.ReadWrite.All Sites.Read.All Chat.ReadWrite`, PKCE S256, no `resource` (Entra v2 refuses it). Nothing is
  discovered, so no server can name another token address for the secret. A refresh uses the app as it is now (a rotated
  secret); a sign-in made with another client ID keeps the client it was made with, and its new secret never goes
  with it, until Microsoft refuses it (sign in again), as for GitHub. Microsoft has no token revocation address: Disconnect forgets the tokens here,
  and the person removes the app's access at myapps.microsoft.com.
- **Rule 4, the return address by where the sign-in starts:** the desktop app (any server) uses its one-time
  `http://127.0.0.1:<port>/callback`, which forwards to the team's own callback (Entra ignores a loopback address's
  port, so one entry covers every port); the web uses `https://<team host>/api/integrations/oauth/callback` (hosted
  teams through one `https://*.<team domain>/api/integrations/oauth/callback` entry, which Entra allows only for an
  app limited to work and school accounts; anything else needs the account host's broker, not built); a server opened
  at `http://localhost` or `http://127.0.0.1` uses that address. A self-installed server on an address of its own uses
  an Entra app of its own (the same file, or the connection's own-app fields), as for GitHub.
- **Rule 5, errors:** Graph's 401 is the MCP answer's 401 (the token is refreshed once, then the connection asks to
  sign in again, as for every service); any other Graph error is that tool's error with Microsoft's own words, cleaned
  (no token, at most 200 characters), so one forbidden mailbox or chat does not mark the whole connection "no access".
- **Why:** the least new machinery: the connection model, cards and UI exist and are tested; only the sign-in's fixed
  addresses and the in-process transport are new.
- **Left out:** personal Microsoft accounts (need the broker), mail attachments, Teams channels, publisher
  verification (an Entra step, not code).
- **Tests:** `tests/unit/c-integrations-microsoft.test.ts` (Graph and Microsoft's token address faked).
- **Version impact:** minor (a new connector).
