01

준비물

원장님 · 설치하는 사람

맥 미니 한 대가 Team AX를 돌리고, 같은 사무실 네트워크의 데스크 PC들이 Edge로 들어와요. AI는 맥 미니에 로그인된 원장님의 Claude 구독으로 답해요.

무엇설명
맥 미니macOS 13 이상. Team AX 전용으로 두고 개인 자료·다른 프로그램은 두지 마세요.
FileVault켜 두세요(시스템 설정 → 개인정보 보호 및 보안 → FileVault). 환자 자료가 디스크에 암호화돼요.
Claude Code맥 미니의 그 사용자 계정에 설치. 권장: 원장님이 claude setup-token으로 만든 토큰 파일(2-1). 토큰 없이 하면 맥 미니에서 구독 계정으로 로그인.
네트워크인터넷 연결(유선 권장). 공유기 포트 열기·고정 IP는 필요 없어요. 사무실 안 대체 경로도 쓰려면 맥 미니 주소 고정(DHCP 예약).
연결 토큰원장님 맥에서 미리 만든 exampleteam.example.com.tunnel-token 파일(2-0). 맥 미니의 다운로드 폴더에.
zip 파일TeamAX-office-0.1.0-mac.zip을 USB·AirDrop로 맥 미니의 다운로드 폴더에.
데스크톱 앱 (선택)Team-AX-Setup-0.1.0-x64.exe·Team-AX-0.1.0-mac-universal.dmg를 zip과 같은 다운로드 폴더에(2-5).
데스크 PC윈도우 10/11 + Edge. 직원 윈도우 계정이면 돼요(관리자 암호 필요 없음).
그 밖에프린터(데스크 카드), 외장 디스크(백업), 가능하면 UPS.
맥 미니에 설치할 것이 없어요

git·Go·Node·Homebrew·GitHub 접근이 필요 없어요. zip 하나에 프로그램이 모두 들어 있어요.

02

맥 미니 설치

15분

먼저 원장님 맥에서 연결 토큰을 만들고(2-0), 맥 미니에 AI가 쓸 Claude 로그인이 있는 그 사용자로 로그인해 터미널에 한 줄씩 붙여 넣어요.

2-0원장님 맥에서 미리: 연결 토큰 만들기 (처음 한 번)

맥 미니가 아니라 Cloudflare에 로그인할 수 있는 원장님 맥에서 해요. Bun과 Team AX 저장소가 필요해요.

gh repo clone potenlab/team-ax ~/team-ax && cd ~/team-ax && bun install
brew install cloudflared && cloudflared tunnel login     # 브라우저에서 example.com 고르기
mv ~/.cloudflared/cert.pem ~/.cloudflared/cert-example.pem
bun scripts/office/public-address.ts set exampleteam.example.com \
  --cert ~/.cloudflared/cert-example.pem
확인마지막에 → http://127.0.0.1:47830과 connector token: ~/.config/teamax-office/exampleteam.example.com.tunnel-token (600; not shown). 이 파일을 AirDrop·USB로 맥 미니의 다운로드에 보내요.
알아 둘 것

이미 ~/.cloudflared/cert.pem이 있으면 tunnel login이 거부하니 그 파일 이름을 먼저 바꿔요(도메인마다 cert 하나). cert 대신 API 토큰(Zone·DNS·Edit + Account·Cloudflare Tunnel·Edit)을 파일에 넣고 --api-token-file <파일>도 돼요. 스크립트는 도메인 꼭대기(기존 웹사이트)와 다른 기록이 있는 이름은 거부하고, 그 이름의 기록 하나만 만들어요.

2-1Claude 구독 토큰 (권장)
claude setup-token
확인원장님 맥에서 실행하고 브라우저에서 구독 계정으로 승인하면 sk-ant-oat01-… 한 줄이 나와요. 그 줄만 claude-token.txt에 넣어 맥 미니의 다운로드로 보내요. 이렇게 하면 AI 엔진이 맥 미니의 Claude 로그인을 볼 수 없어요. 토큰 없이 하려면 맥 미니에서 claude auth status가 "loggedIn": true인지 보고(아니면 claude → /login) 2-2의 마지막 옵션을 빼요. Claude Code가 없으면 curl -fsSL https://claude.ai/install.sh | bash 후 터미널을 다시 열어요.
2-2풀고 설치하기 (sudo 아님)
cd ~/Downloads && ditto -x -k TeamAX-office-0.1.0-mac.zip .
bash ~/Downloads/TeamAX-office-0.1.0/office-install.sh \
  --public-host exampleteam.example.com \
  --tunnel-token-file ~/Downloads/exampleteam.example.com.tunnel-token \
  --claude-token-file ~/Downloads/claude-token.txt
rm ~/Downloads/exampleteam.example.com.tunnel-token ~/Downloads/claude-token.txt
https://exampleteam.example.com 답함 / answers
인터넷 주소 (인증서 설치 필요 없음, 어디서나) / internet address:
  https://exampleteam.example.com
사무실 안 대체 경로 (사무실 인증서를 설치한 데스크) / in-office fallback:
  https://192.168.1.20:8443
처음 한 번, 인증서 받는 곳 / first time: certificate page (http://)
  http://192.168.1.20:8442
인증서 지문: 데스크에서 설치 전에 이 값과 비교 (인증서 → 자세히 → 지문)
  c87162d4 d9b3bf5b 4e07a291 3c6f58e0 127db4aa
첫 설정 링크 (한 번만, 소유자 계정 만들기) ...
=== 설치 끝 / installed: 0.1.0 ===
확인답함 / answers와 마지막 줄 === 설치 끝 ===, 맥 미니의 브라우저에 첫 설정 페이지가 열려요. 두 토큰은 ~/TeamAX/config에 복사되니 받은 파일은 지워요(나중에 Claude 토큰 넣기: teamax configure --claude-token-file <파일> → teamax restart). 포트가 다른 프로그램에 잡혀 있으면 설치 전에 멈추고 다른 번호(--lan-port 9443 등)를 알려 줘요. 앱 포트(--app-port)를 바꿨다면 원장님 맥에서 2-0의 set을 --port <그 포트>를 붙여 한 번 더 실행해요(안 하면 인터넷 주소가 502, 설치기가 이 명령을 알려 줘요).
2-3꺼지지 않게 (한 번, 맥 암호 필요)
sudo pmset -a sleep 0 disksleep 0 womp 1 autorestart 1
확인pmset -g | grep -E ' sleep|autorestart' → sleep 0, autorestart 1. 화면 꺼짐은 괜찮아요.
  • 방화벽: “bun이 들어오는 연결을 허용하겠습니까?”가 뜨면 허용.
  • 공유기 DHCP 예약(사무실 안 대체 경로를 쓸 때): 설치기가 보여 준 맥 미니 주소를 공유기에서 고정해요. 주소가 바뀌면 대체 경로를 쓰는 데스크만 다시 로그인·앱 설치. 인터넷 주소는 상관없어요.
2-4데스크 카드 인쇄
~/TeamAX/teamax card

열린 페이지를 인쇄(⌘P)해서 데스크마다 한 장씩 두세요. 카드 맨 위에 인터넷 주소가 있고, 그 아래 사무실 안 대체 경로의 인증서 받는 곳, 인증서 지문, 데스크 주소가 있어요.

지문은 카드와 비교해요

카드는 맥 미니에서 만든 것이라 네트워크로 바뀔 수 없어요. 인증서 페이지(http)는 일부러 지문을 보여 주지 않아요.

2-5데스크톱 앱 올리기 (설정 → 앱에서 내려받게)

윈도우 설치 파일 Team-AX-Setup-0.1.0-x64.exe와 맥용 Team-AX-0.1.0-mac-universal.dmg를 zip과 같은 폴더(~/Downloads)에 두고 2-2를 하면 설치기가 알아서 올려요. 나중에 받은 파일은 이렇게:

~/TeamAX/teamax desktop add ~/Downloads/Team-AX-Setup-0.1.0-x64.exe
~/TeamAX/teamax desktop add ~/Downloads/Team-AX-0.1.0-mac-universal.dmg
~/TeamAX/teamax desktop list
확인데스크톱 앱을 올렸습니다 / desktop app added: Windows 0.1.0 (… 109.0 MB, 서명 없음 / unsigned). 로그인한 팀원은 설정 → 앱에서 자기 컴퓨터용을 내려받고, 설치 중 경고(윈도우 추가 정보 → 실행, 맥 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기)도 거기 적혀 있어요. 잘린 파일·다른 파일은 거절돼요. 서버 재시작은 필요 없어요.
03

첫 설정

원장님 · 5분

맥 미니에 열린 첫 설정 페이지에서 해요. 다시 열려면 ~/TeamAX/teamax setup-link.

  1. 1팀 이름: 예) OO사무실
  2. 2팀 언어: 한국어. 브라우저가 한국어면 처음부터 한국어로 열려요. 팀원 화면의 기본 언어예요.
  3. 3소유자 계정: 원장님 이름·아이디·비밀번호(8자 이상, 아이디와 같으면 안 돼요). 팀원·폴더 권한을 관리하는 계정이에요.
확인홈 화면이 열리고 오른쪽 위에 원장님 이름이 보여요.
첫 설정은 맥 미니에서만

인터넷 주소는 첫 설정 전에도 로그인 화면만 보여 주고, 첫 설정(소유자 만들기)을 받지 않아요. 설치 직후 다른 사람이 먼저 소유자가 될 수 없게 막아 둔 거예요.

그다음 관리자 → 멤버 → 초대 링크로 데스크마다 링크를 만들어 메신저로 보내요(메일 발송 없음). 맥 미니에서 만들어도 링크는 인터넷 주소(https://exampleteam.example.com/invite/…)로 나와요. 초대 대신 직접 추가도 돼요: 이름·아이디를 넣으면 임시 비밀번호 칸에 외우기 쉬운 비밀번호(예: tiger4271, 영어 단어 + 숫자 4개)가 미리 들어 있어요. 그대로 쓰거나 ↻로 바꾸거나 직접 정해요(8자 이상, 영문·숫자). 만들기를 누르면 접속 주소·아이디·임시 비밀번호가 한 번 보이니 주소·아이디·비밀번호 복사로 메신저에 붙여 넣어 전해요. 직원은 7일 안에 그 비밀번호로 로그인해 새 비밀번호만 두 번 넣으면 끝이에요. 비밀번호를 잊은 직원은 그 사람 줄의 비밀번호 재설정으로 새 임시 비밀번호를 줘요.

04

데스크 PC 연결

PC마다 2분 · 데스크 직원

기본은 인터넷 주소예요. 인증서를 설치할 필요가 없어요.

①Edge로 인터넷 주소 열기

Edge 주소창에 카드 맨 위의 주소 https://exampleteam.example.com.

확인경고 없이 자물쇠가 보이고 로그인 화면이 나와요.
②앱으로 설치

Edge 오른쪽 위 ⋯ → 앱 → 이 사이트를 앱으로 설치 → 설치. 바탕화면·작업 표시줄에 Team AX 아이콘이 생겨요.

③초대 링크로 가입

받은 초대 링크를 Edge에서 열고 이름·아이디·비밀번호로 가입해요. 다음부터는 바탕화면 아이콘으로 열어요.

확인채팅에 “안녕하세요”를 보내면 답이 와요.
집·휴대폰에서도 같은 주소

사무실 밖에서도 같은 주소로 들어와요. 로그인은 사람마다 따로예요.

사무실 안 대체 경로 (인터넷이 끊겼을 때)

인터넷이 끊겨도 쓰려는 데스크만 한 번 해 두세요. 주소가 달라서 로그인·앱도 따로예요.

A인증서 설치 (처음 한 번)
  1. 1Edge 주소창에 카드의 인증서 받는 곳을 http://까지 그대로: http://192.168.1.20:8442
  2. 2윈도우용 인증서 받기 (.cer). “안전하게 다운로드할 수 없습니다”가 나오면 ⋯ → 유지.
  3. 3받은 파일을 열고 자세히 탭 → 지문. 카드의 지문과 같은지 확인(대소문자·띄어쓰기 무시, 적어도 앞 8자리와 끝 8자리). 다르면 멈추고 원장님께 알려요.
  4. 4일반 탭 → 인증서 설치… → 현재 사용자 → 다음 → 모든 인증서를 다음 저장소에 저장 → 찾아보기 → 신뢰할 수 있는 루트 인증 기관 → 확인 → 다음 → 마침.
  5. 5“보안 경고” 창의 지문이 카드와 같으면 예.
USB가 더 안전해요

맥 미니의 ~/TeamAX/tls/ca.cer를 USB로 옮겨 데스크에서 바로 열면 1~2단계가 필요 없어요. 3~5단계는 같아요. 한 PC를 여러 윈도우 계정이 쓰면 계정마다 4~5단계를 해요.

B사무실 주소

Edge를 모두 닫았다가 다시 열고 카드의 데스크 주소 https://192.168.1.20:8443 → 자물쇠 확인 → ②처럼 앱으로 설치 → 로그인.

첫 데스크에서 먼저

윈도우 PC에서의 Edge 앱 설치·사무실 인증서 설치는 아직 직접 확인하지 못했어요확인 전. 첫 데스크 한 대에서 끝까지 해 보고 나머지 9대를 진행하세요.

자동 업데이트 · 새 주소

자동 업데이트

0.2.0부터 맥 미니가 스스로 업데이트해요. 매일 밤 03:00에 updates.treesoop.com에서 새 버전을 확인하고, 있으면 받아서 설치한 뒤 서버를 다시 시작해요(1–3분). 서명과 파일 확인을 통과한 새 버전만 설치하고, 새 버전이 제대로 뜨지 않으면 이전 버전으로 저절로 돌아가요. 데이터·팀 폴더·인증서·설정·데스크 로그인은 그대로예요.

처음 한 번은 손으로 해요. 0.1.0에는 자동 업데이트가 없어서, 0.2.0 zip을 맥 미니에 받아 아래 명령으로 한 번 설치하면 그다음부터는 자동이에요.

cd ~/Downloads && ditto -x -k TeamAX-office-0.2.0-mac.zip .
bash ~/Downloads/TeamAX-office-0.2.0/office-install.sh
~/TeamAX/teamax update status
확인팀이 이미 설정되어 있습니다, 자동 업데이트 … 매일 / every night 03:00, === 설치 끝 / installed: 0.2.0 ===. 웹에서는 관리자 → 시스템 → 자동 업데이트에 버전·다음 확인 시각이 보여요. 0.2.0은 사무실 인증서를 한 번 새로 만들어요: 사무실 안 대체 경로(:8443)를 쓰는 데스크만 새 카드를 보고 인증서를 다시 설치해요.
어느 데스크에서나: 관리자 → 시스템 → 자동 업데이트

원장님·관리자는 맥 미니 터미널 없이 데스크 앱이나 Edge에서 업데이트해요. 지금 업데이트(비밀번호 한 번 더): 밤까지 기다리지 않고 바로, 진행 단계가 보이고 1–3분 뒤 화면이 저절로 새 버전으로 바뀌어요. 자동 업데이트 끄기: 진료 중 바뀌면 안 될 때. 새 버전이 나오면 화면 위에 새 버전 x.y.z이 있어요 — 지금 업데이트 띠가 원장님·관리자에게만 보여요.

데스크 PC의 Team AX 앱

맥 미니가 새 윈도우 앱도 받아 두면, 데스크 앱(0.2.0부터)이 알아서 받아 업데이트 준비됨 — 다시 시작을 띄워요. 나중에를 눌러도 앱을 닫을 때 설치돼요. 0.1.0 앱은 한 번만 설정 → 앱에서 새로 받아 설치해요. Edge 앱은 할 일이 없어요.

인터넷이 막혀 자동 업데이트를 못 쓰면 예전처럼 새 zip을 풀고 office-install.sh를 실행하면 돼요.

인터넷 주소 바꾸기 (명령 두 개)

예: exampleteam.example.com → teamax.새도메인.com. ① 원장님 맥, ~/team-ax에서(새 도메인이면 2-0처럼 그 도메인의 cert부터, 앱 포트를 바꿨다면 --port):

bun scripts/office/public-address.ts set teamax.새도메인.com \
  --cert ~/.cloudflared/<그 도메인의 cert.pem>

새 연결 토큰 파일(~/.config/teamax-office/teamax.새도메인.com.tunnel-token)을 AirDrop으로 맥 미니에 보내고, ② 맥 미니에서:

~/TeamAX/teamax public-address set teamax.새도메인.com \
  ~/Downloads/teamax.새도메인.com.tunnel-token
rm ~/Downloads/teamax.새도메인.com.tunnel-token
~/TeamAX/teamax card        # 새 카드 인쇄
확인인터넷 주소가 답합니다. 답이 없으면 이유(502: 포트, 530: 연결 없음)와 고칠 명령이 나와요.
데스크마다 (로그인·앱은 주소마다 따로)

Edge ⋯ → 앱 → 앱 관리 → 옛 Team AX 제거 → 새 주소를 열어 앱으로 설치 → 다시 로그인. 채팅·파일은 그대로예요. 옛 앱을 남겨 두면 오류만 보이는 “Team AX”와 새 “Team AX 1”이 함께 생겨요.

정리

아직 안 쓴 초대·재설정 링크는 새로 만들어요(또는 주소 부분만 새 주소로). 옛 이름 지우기(원장님 맥): bun scripts/office/public-address.ts remove exampleteam.example.com --cert ~/.cloudflared/cert-example.pem. 끄기: 맥 미니에서 teamax public-address off.

보안 메모

인터넷 주소를 열면 로그인 화면이 인터넷 전체에 보여요

원장님·관리자 비밀번호는 길고 다른 곳에 쓰지 않는 것(단어 4개 + 숫자, 16자 이상)으로. 2단계 인증은 아직 없어요. 대신 로그인 시도 제한이 접속한 사람의 실제 IP와 계정(15분에 10번) 기준으로 걸리고, 로그인·실패는 관리자 → 기록에 줄마다 IP와 함께 남아요(인터넷으로 온 것은 인터넷 표시). 퇴사자는 바로 비활성. 첫 설정은 맥 미니에서만 돼요. 한국에서만 열려면 ~/TeamAX/config/office.env에 TEAMAX_PUBLIC_COUNTRIES=KR → teamax restart. 환자 자료가 Cloudflare를 거쳐 가는 것이 안 되면 teamax public-address off로 사무실 안 경로만 쓰세요. (선택) Cloudflare 대시보드에서 그 이름만 대상으로 http→https 리디렉션 규칙과 /api/auth/login 속도 제한 규칙을 두면 더 좋아요. 존 전체 설정 “Always Use HTTPS”는 꼭대기 웹사이트에도 걸리니 피하세요.

사무실 모드가 지키는 것

  • 폴더 권한·채팅 비공개는 운영 모드와 같은 권한 함수가 판단해요. AI는 질문한 사람이 볼 수 있는 파일만 봐요.
  • 엔진 잠금(Claude Code 자체 셸·파일·웹 도구 꺼짐)과 macOS 샌드박스가 AI를 그 채팅 폴더 안에 가둬요. AI 엔진의 네트워크는 맥 안의 프록시 하나라 Anthropic 말고는(인터넷의 다른 곳, 사무실의 차트 서버·NAS) 닿지 않아요.
  • 구독 토큰(2-1)이면 AI 엔진은 턴마다 바뀌는 가짜 토큰만 받고 맥의 Claude 로그인을 못 봐요. 토큰 없이 설치했다면 엔진 잠금과 샌드박스가 둘 다 뚫릴 때 그 로그인이 샐 수 있어서, 맥 미니는 Team AX 전용으로 둬요.
  • 데이터·백업은 치과의 맥 미니에만 있어요. 중계 서버를 거치지 않아요.
  • 인터넷 주소는 https만(Cloudflare 공인 인증서). 맥 미니는 들어오는 포트를 열지 않고 cloudflared가 바깥으로 연결해요.
  • 사무실 네트워크에는 https만, 사무실 대역에서 온 연결만 받아요(VPN·다른 대역은 403).
  • 사무실 인증서(CA)는 이 맥 미니의 이름과 사무실 대역만 보증할 수 있어요. 키가 새도 은행·포털·다른 기기를 사칭할 수 없어요.

환자 자료

AI 요청의 일부로만 Anthropic에 가요

질문 내용과, AI가 그 질문에 답하려고 읽은 파일 내용이 Anthropic(Claude)으로 전송돼요. 다른 AI 회사(Codex 등)는 사무실 모드에서 쓰지 않아요.

운영 설치가 나중에 더하는 것

  • AI 엔진을 별도 계정으로 돌려 OS 경계를 하나 더 두고, 방화벽(pf)으로 엔진의 인터넷을 모델 프록시 하나로 막아요.
  • 지금은 그래서 Team AX 전용 맥 미니, 개인 자료 없음, FileVault 켜기, 맥 암호는 원장님만을 권장해요.
  • 운영 설치로 옮길 때는 암호화 보관본을 복원해요(같은 자료 구조, OFFICE.md 부록 B).
