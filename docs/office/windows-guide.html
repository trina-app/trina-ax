A

Edge 웹 앱 (기본)

데스크 PC마다 3분

설치할 프로그램이 없어요. Edge로 주소를 열고, 받은 초대 링크로 가입한 다음, 그 사이트를 앱으로 설치해요.

A-1Edge로 주소 열기

Edge 주소창에 exampleteam.example.com을 입력하고 Enter. (https://는 붙여도 되고 안 붙여도 돼요.)

확인주소창에 자물쇠가 보이고 경고 없이 로그인 화면이 나와요. 인증서를 설치할 필요가 없어요.
오류 530 · 1033이 나오면

주소는 맞는데 치과의 맥 미니가 꺼져 있거나 잠들어 있어요. C장 첫 줄을 보세요.

A-2초대 링크로 가입 (처음 한 번)
  1. 1원장님(관리자)에게 나만의 초대 링크를 메신저로 받아요. https://exampleteam.example.com/invite/… 모양이에요.
  2. 2그 링크를 Edge에서 열어요(메신저 안의 미리보기 창이 아니라). 링크를 길게 누르거나 복사해 Edge 주소창에 붙여 넣어도 돼요.
  3. 3이름(화면에 보일 이름), 아이디(영문·숫자), 비밀번호(8자 이상)를 두 번 입력 → 계정 만들고 참여하기.
확인“○○님, 무엇을 도와드릴까요?” 홈 화면이 열려요. 아이디·비밀번호는 다음 로그인에 써요.
초대 링크는 한 사람, 한 번

보통 7일 동안 쓸 수 있고, 가입하면 다시 쓸 수 없어요. 만료됐다고 나오면 원장님께 새 링크를 받으세요.

링크 대신 아이디·임시 비밀번호를 받았다면

A-1 로그인 화면에 그대로 넣어요(예: tiger4271, 한/영 키는 영문). 새 비밀번호를 정하는 화면이 나오면 새 비밀번호만 두 번(8자 이상) → 비밀번호 바꾸기. 임시 비밀번호는 7일이 지나면 쓸 수 없어요.

A-3앱으로 설치하고 작업 표시줄에 고정윈도우에서 확인 전
  1. 1Team AX가 열린 Edge 창에서 오른쪽 위 ⋯(설정 및 기타) → 앱 → 이 사이트를 앱으로 설치.
  2. 2이름은 Team AX 그대로 두고 설치. Team AX가 주소창 없는 별도 창으로 열려요.
  3. 3“앱이 설치됨” 창이 나오면 작업 표시줄에 고정(원하면 바탕 화면 바로 가기 만들기도)을 체크하고 허용.
  4. 4그 창을 놓쳤다면: 작업 표시줄의 Team AX 아이콘을 마우스 오른쪽 단추로 눌러 작업 표시줄에 고정.
확인작업 표시줄과 시작 메뉴에 Team AX 아이콘이 있고, 누르면 별도 창으로 열려요. 이미 로그인한 상태 그대로예요.
메뉴가 안 보이면

Edge가 오래된 버전이면 ⋯ → 앱이 없을 수 있어요. 그때는 주소창 오른쪽 끝의 앱 설치 아이콘(네모 + 화살표)을 눌러도 돼요. Chrome이면 ⋮ → 전송, 저장, 공유 → 페이지를 앱으로 설치.

A-4첫 채팅으로 확인
확인입력창에 “안녕하세요” → Enter → AI의 답이 와요. 다음부터는 작업 표시줄 아이콘으로 열고, 로그인 화면이 나오면 아이디·비밀번호를 넣어요.
집·휴대폰에서도 같은 주소

사무실 밖에서도 https://exampleteam.example.com으로 들어와요. 내 채팅은 나만 보고, AI는 내가 볼 수 있는 폴더만 봐요.

B

데스크톱 앱

AI 브라우저가 필요한 자리만

데스크톱 앱은 Edge 웹 앱과 같은 화면에 AI가 직접 쓰는 브라우저 창을 더한 프로그램이에요. AI가 웹사이트를 열어 읽고 클릭해야 하는 자리에만 설치하세요. 나머지 자리는 A장의 Edge 앱이면 충분해요.

B-1설치 파일 실행윈도우에서 확인 전
  1. 1원장님께 받은 Team-AX-Setup-0.1.0-x64.exe(약 110 MB, USB 또는 메신저). 원장님이 준 파일만 실행하세요.
  2. 2Edge로 받았다면 다운로드 목록에 “일반적으로 다운로드되지 않습니다”가 나올 수 있어요 → 그 줄의 ⋯ → 유지 → 그래도 유지.
  3. 3파일을 두 번 눌러 실행 → 파란 창 “Windows의 PC 보호”가 나오면 추가 정보 → 게시자가 알 수 없는 게시자, 앱이 Team-AX-Setup-0.1.0-x64.exe인지 보고 → 실행.
  4. 4설치 창이 잠깐 나왔다가 닫히고 Team AX가 바로 열려요. 묻는 것이 없어요.
확인바탕 화면과 시작 메뉴에 Team AX 아이콘. 관리자 암호(UAC 창)는 나오지 않아요: 지금 로그인한 윈도우 사용자에게만 설치돼요(%LOCALAPPDATA%\Programs). 지우기: 설정 → 앱 → 설치된 앱 → Team AX → 제거.
왜 “Windows의 PC 보호”가 나오나요

이번 시범판은 코드 서명을 하지 않아서, 윈도우가 처음 보는 프로그램으로 경고해요. 추가 정보를 눌러야 실행 단추가 보여요. 회사 정책으로 실행 단추가 없으면 그 PC는 A장의 Edge 앱을 쓰세요.

B-2팀 주소 · 로그인
  1. 1처음 열면 “팀 주소를 입력하세요” 화면이 한국어로 나와요. 이 설치 파일에는 exampleteam.example.com이 미리 들어 있어요.
  2. 2주소를 확인하고 연결. 지웠다면 exampleteam.example.com(또는 https://exampleteam.example.com)을 직접 입력해요.
  3. 3A-1과 같은 로그인 화면이 앱 안에 나와요 → 아이디·비밀번호. 아직 계정이 없으면 먼저 A-2처럼 초대 링크로 가입하세요.
확인A-4와 같은 홈 화면. 다음부터는 앱을 열면 바로 팀 화면이에요. 앱의 로그인은 Edge와 따로예요.
B-3AI 브라우저 창 기본

AI가 웹사이트를 써야 하면 화면 오른쪽에 브라우저 창이 열려요. 직접 열고 닫으려면 메뉴 보기 → 브라우저 창 보기/숨기기(Ctrl Shift B).

  • 사이트마다 먼저 물어요. AI가 처음 가는 사이트면 창 위에 “AI가 ○○을(를) 쓰려고 해요”가 나와요. 맞는 사이트면 이번만 허용, 자주 쓰는 사이트면 항상 허용, 모르는 사이트면 거부.
  • AI가 쓰는 동안 초록 띠 “AI가 브라우저를 사용 중”이 보여요. 이상하면 멈추기.
  • 비밀번호·카드 번호 입력란은 AI가 쓸 수 없어요. 사이트 로그인은 직원이 직접 해요.
  • 팀 주소와 이 PC 자신의 주소는 열 수 없고, 사무실 안 기기(NAS·공유기 등) 주소는 매번 물어요.

⚙을 누르면 두 가지 중에 골라요:

  • 새 사이트마다 묻기 (기본): 위처럼 사이트마다 물어요. 아래 “허용한 사이트”에서 항상 허용한 사이트를 지울 수 있어요.
  • 모든 웹사이트 허용: 묻지 않고 어떤 공개 사이트든 열고, 그 사이트로 내용을 보낼 수도 있어요. 켜져 있는 동안 “모든 사이트 허용 중”이 보여요.
환자 자료가 있는 자리는 “묻기”를 그대로

AI가 읽은 환자 정보가 허용하지 않은 사이트로 나가지 않게, 새 사이트마다 묻기를 유지하세요. 자주 쓰는 사이트만 항상 허용하면 충분해요.

C

문제 해결

오류 530 · 1033 “Cloudflare Tunnel error”

주소는 맞아요. 치과의 맥 미니가 꺼졌거나, 잠들었거나, 로그아웃됐거나, 인터넷이 끊긴 것이에요. 데스크 PC에서 고칠 것은 없어요.

  1. 1원장님(담당자)께 알려요: 맥 미니를 켜고, FileVault 암호를 한 번 입력해 로그인해 두면 Team AX가 스스로 켜져요.
  2. 21~2분 뒤 F5(새로 고침).

데스크톱 앱에서는 “팀 서버에 연결할 수 없어요”로 나와요. 오류 502는 맥 미니는 켜져 있지만 Team AX가 멈춘 경우예요(담당자: teamax restart).

로그인이 안 돼요

화면할 일
“아이디 또는 비밀번호가 맞지 않습니다.”한/영 키(한글로 입력되고 있지 않은지), Caps Lock을 확인하고 천천히 다시. 아이디는 가입할 때 정한 영문·숫자예요(이름이 아니에요).
여러 번 틀린 뒤 계속 실패15분에 10번 넘게 틀리면 잠시 막혀요. 15분 기다리거나 아래처럼 비밀번호 재설정 링크를 받으세요.
“다른 곳에서 로그아웃했거나 비밀번호가 바뀌어 로그인이 끝났어요.”정상이에요(비밀번호를 바꾸면 다른 PC의 로그인은 끝나요). 다시 로그인해요.
“임시 비밀번호의 사용 기한이 지났습니다.”받은 지 7일이 지났어요. 원장님께 비밀번호 재설정으로 새 임시 비밀번호를 받아요.
초대 링크가 만료·사용됨원장님께 새 초대 링크를 받아요.
데스크톱 앱 “이 주소는 Team AX 팀 서버가 아니에요.”주소 철자를 확인해요: exampleteam.example.com.

비밀번호를 잊었어요

  1. 1원장님(관리자)께 말해요. 관리자는 관리자 → 멤버 → 그 사람 줄의 재설정 링크를 만들어 메신저로 보내요(또는 비밀번호 재설정으로 임시 비밀번호를 줘요: 위 A-2의 팁처럼 로그인).
  2. 2받은 링크를 Edge에서 열어 새 비밀번호(8자 이상)를 두 번 → 새 비밀번호로 로그인.

링크는 24시간 동안 한 번만 쓸 수 있고, 쓰면 다른 PC의 로그인이 모두 끝나요. 메일로는 오지 않아요.

화면이 이상하거나 옛날 화면이 보여요 (캐시 지우기)

  1. 1먼저 Ctrl F5(강력 새로 고침). Edge 앱 창에서도 돼요.
  2. 2그래도 같으면 Edge에서 Ctrl Shift Delete → 시간 범위 모든 시간 → 캐시된 이미지 및 파일만 체크(쿠키는 그대로 두면 로그인이 유지돼요) → 지금 지우기 → Team AX를 닫았다 다시 열기. 윈도우에서 확인 전
  3. 3데스크톱 앱: 메뉴 보기 → 새로고침(Ctrl R). 그래도 안 되면 메뉴 팀 → 팀 목록 → 목록에서 지우기(그 PC에 저장된 로그인·브라우저 기록도 지워져요) → 주소를 다시 넣고 로그인.
그 밖에

채팅이 “엔진을 쓸 수 없음”이면 맥 미니의 Claude 로그인 문제예요: 원장님께. 파일 업로드가 아주 느리면 인터넷 속도 문제일 수 있어요(큰 파일은 조각으로 올라가요).

D

하지 말 것

환자 자료를 지키려면
  • 비밀번호를 같이 쓰지 마세요. 한 사람에 한 계정이에요. AI는 로그인한 사람이 볼 수 있는 폴더만 보고, 로그인·실패는 IP와 함께 기록돼요. 동료의 계정으로 일하면 그 사람의 권한과 기록이 섞여요.
  • 로그인한 채 자리를 비우지 마세요. 잠깐 비울 때는 ⊞ Win L(윈도우 잠금). 여러 사람이 쓰는 PC면 퇴근할 때 왼쪽 아래 내 이름 → 로그아웃. 로그아웃하지 않으면 그 PC에서 로그인이 30일 동안 이어져요.
  • 여러 사람이 쓰는 PC에서는 Edge의 “비밀번호를 저장할까요?”에 안 함.
  • 초대·재설정 링크를 다른 사람에게 넘기거나 단체방에 올리지 마세요. 링크를 연 사람이 그 계정을 갖게 돼요.
  • AI에게 비밀번호를 알려 주지 마세요. 데스크톱 앱의 “모든 웹사이트 허용”을 켜지 마세요(B-3).
