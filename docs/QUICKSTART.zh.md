# 在本地试用 Trina AX

[English](QUICKSTART.md) · [한국어](QUICKSTART.ko.md) · [团队指南](for-teams.zh.md)

在**已经准备好的 Mac** 上，安装依赖、构建并浏览虚构演示，大约需要 **10 分钟**。
全新的 Mac 还需要额外时间安装工具（[完整指南](INSTALL.md#11-tools)（英文）估计需要 30–60 分钟）。
所需时间也受网速和构建缓存影响。这是开发预览，不是正式安装。

## 准备工作

- Git、Bun **1.3.12**（CI 固定使用的版本）、Go **1.27+**，以及一个空闲端口 **19760**。
- 本机构建工具（macOS 上是 Xcode 命令行工具）。支持在 macOS 和 Linux 上从源码构建；本教程是在 macOS 上实际走过的，在 Linux 上评估需要你在自己的机器上验证。Windows 用户请用浏览器连接已经准备好的服务器。
- 如果想试 AI 聊天（可选）：在这台 Mac 上安装并登录受支持的 Claude Code 或 Codex CLI。见[引擎版本](INSTALL.md#11-tools)（英文）。
- PDF / Office 文字提取、PDF 输出和语音输入，需要完整安装指南里的其他工具。浏览预置的 Markdown 词汇表不需要它们。

## 1. 构建并启动

```sh
git clone https://github.com/trina-app/trina-ax.git
cd trina-ax
bun install --frozen-lockfile
bun run demo
```

请让这个终端保持运行。启动程序会完成构建，在本机回环地址 **http://127.0.0.1:19760** 上启动，并自动创建一个新的虚构团队、六个入门技能和一个标明为示例的结果。即使这台机器上已经登录了 CLI，它也会关闭 AI，并且不启动中继。不需要 AI 账号。这里演示的是应用内的权限，不是正式环境的系统级隔离；请不要使用公司的真实资料。

## 2. 打开预置的团队

用 `alice` 和密码 `teamax-demo-1` 登录（这是故意公开的虚构账号）。其他账号有 `bob`、`admin1` 和所有者 `dion`。请不要自己新建团队，也不要再运行一次预置命令。

文件是韩文的；界面默认是英文。如果想换一个端口、使用全新的数据路径并使用韩文界面：

```sh
bun run demo --port 19761 --data "$HOME/.trina-evaluation-new" --locale ko
```

这个数据路径必须是不存在的。端口被占用或目录已存在时，会被拒绝。每次按默认方式运行都会新建一个专用目录，并显示它的路径和守护进程（supervisor）的 PID。在“个人资料 → 语言”里可以选择英语、韩语、印尼语、日语、西班牙语和简体中文。

## 3. 不调用模型，先看到第一个结果

1. 打开 **文件 → shared → 팀-용어집.md**。你会看到一张词汇表，其中包括 `전환율`（转化率）这个词。
2. 浏览市场部小组的文件夹。`alice` 可以打开它。
3. 在浏览器的无痕窗口里打开同一个地址，用 `bob` 和同样的演示密码登录。
4. Bob 可以浏览财务小组；市场部小组的文件和财务里的工资子文件夹，他都看不到。这里验证的是应用内的权限，不是正式环境的系统级隔离。

到这一步，你已经在没有调用模型的情况下，试过了浏览器、服务器、预置文件和按人设置的文件夹权限。

## 4. 可选：向 AI 提问

不带模型的启动程序无法调用 AI。如果想另外搭一个可选的开发环境，请先停掉它，使用获得许可的 CLI 账号，然后运行：

```sh
TEAM_AX_DEV_DIR="$HOME/.trina-ai-evaluation-new" TEAM_AX_DEV_PORT=19761 bun run dev --no-relay
# In a second terminal, before creating a team:
TEAM_AX_DEV_DIR="$HOME/.trina-ai-evaluation-new" bun run demo:seed --base http://127.0.0.1:19761
```

（第二条命令请在另一个终端里、创建团队之前运行。）请使用全新的数据目录和虚构的文件。引擎以你的系统用户身份运行；开发模式没有正式环境的系统级隔离。用 `alice` 打开 http://127.0.0.1:19761。在聊天输入框里选择对应的引擎（默认是 Claude Code；如果你接入的是 Codex CLI，请选 Codex），然后提问：

> Read shared/팀-용어집.md and explain 전환율 in one sentence. Cite the file.

（意思是：“读一下 shared/팀-용어집.md，用一句话解释 전환율，并注明出处文件。”）

回答会使用你本地的 CLI 账号，消耗这个账号在服务商那里的用量额度。展开工具步骤，可以看到读了哪个文件。如果引擎不可用，请检查它的安装和登录情况，以及本机构建；浏览文件仍然可以用。[更多示例](EXAMPLES.md)（英文）。

## 停止与故障排查

在**第一个终端里按 Ctrl-C**。开发守护进程会停止它启动的子进程。文件会留在启动程序显示的专用目录里（可选的 AI 试用则在 `$HOME/.trina-ai-evaluation-new`）；停止之后，如果想从头开始，可以删除这个专用的演示目录。
不要删除真实团队在用的目录。

- **构建失败：** 查看第一个失败的构建命令；确认 Git、Bun、Go 和本机构建工具都已安装。失败的演示可能会留下一个空目录；重试时请换一个新路径。
- **端口被占用：** 停掉你自己的演示进程，或者换一个空闲端口，并在两条命令和浏览器里都使用同一个端口。
- **已经有团队：** 在两个终端里都换一个新的数据目录；不要为了预置演示去重置真实团队的数据。
- **反复要求登录：** 请一直使用 `127.0.0.1`；`localhost` 的 cookie 是分开的。
- **套接字路径太长：** 像上面那样，在你的主目录下使用一个短目录。
- **缺少转换工具：** 按 [INSTALL.md](INSTALL.md)（英文）安装相应工具；只看文字的演示不需要所有转换工具。

如果是真实团队，请按照 [Linux 安装](INSTALL-LINUX.en.md)（英文）或[办公室 Mac 安装](OFFICE.en.md)（英文）操作，使用全新的账号并配置正式环境的隔离。
