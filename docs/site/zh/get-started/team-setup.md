---
title: 设置你的团队
description: 所有者创建团队后的第一步：连接 AI、公司简介、你自己的技能、团队文件和邀请。
---

创建团队后，应用会带你（所有者）完成几个简短的步骤。只有所有者能看到它们。每一步都可以推迟，而且这些步骤会在任何设备上从你停下的地方继续。

## 步骤

:::steps
#### AI 连接（仅在还没有 AI 回答时）
连接 Claude 或 ChatGPT 订阅，或者一个 API 密钥。没有 AI 就无法读取公司简介，所以这一步排在最前面。**稍后** 会离开这些步骤；之后设置行会显示 **连接 AI**。

#### 公司简介
输入公司网站。AI 会读取网站，并写一行关于公司的介绍（“我们的理解：… · 编辑”）。你可以通过 **如有介绍文件，请添加** 加上一份介绍文件或公司演示文稿。

**保存并继续** 会保存简介，并开始制作你的公司简介演示文稿，每个团队一次。按钮下方的一行会说明需要多长时间（团队的演示文稿制作时间，在 管理 › 团队设置 中）以及它会出现在哪里：在你的 Trina 对话列表中的 **我们的公司介绍**。之后再次保存只会保存。**稍后** 会跳过演示文稿。

#### 你的技能
把你在 Claude Code 或 Codex 中使用的技能带到团队。选择你的 `.claude` 文件夹，或者你的 `.codex` 文件夹（Codex 把个人技能放在 `.agents` 中），也可以把文件夹拖到这一步上。或者，在 Claude Code 或 Codex 连接到团队后，在其中粘贴一行内容（见 [MCP 连接器](../../agents/mcp-connector.md)（英文））。在你按下 **与团队共享** 之前，什么都不会发送给团队。含有密钥的技能永远不会离开你的电脑。

#### 团队文件
把团队的文档（公司介绍、报告、表格）放进团队的文件夹。会有一行说明谁能看到它们。

#### 邀请
复制准备好的消息。它会提到一个技能，加入的人会直接进入那个技能的表单。如果每个人需要登录自己的 AI，消息中也会说明这一点。邀请页面会提供对方浏览器的语言。如果那台电脑上已经有别人登录，页面会写“你已经在<团队名>中”，并提供 **退出登录后加入**，它会退出登录并打开同一个链接。
:::

最后，**一切就绪** 会建议你先自己试一试那个技能。它只显示一次。

## 演示文稿制作期间

演示文稿就是一个普通的 Trina 对话。在电脑上，你可以在左侧 Trina 列表的 **Trina历史记录** 中，也就是在这些步骤旁边看到它；你可以随时打开它。在手机上，打开 **Trina** 标签并按 **☰**：它在 **Trina历史记录** 中。

## 回到设置

- 在步骤完成之前，**继续设置 · 2/4** 会显示在左侧栏旁边的 Trina、聊天、文件和动态列表的顶部附近。它会打开你停下时的那一步。在手机上，它在 **Trina** 标签的 **☰** 列表顶部和 **文件** 标签的顶部，首页则会在消息框下方显示一行不显眼的提示。
- 在首页打开应用时，也会带你回到这些步骤，每个浏览器会话一次。
- ✕ 会隐藏这一行。管理 › 首页 中的 **重新显示设置** 会让它重新出现。

## 什么时候算设置完成

公司简介已保存，演示文稿已开始或已推迟，并且你的技能、团队文件和邀请都已完成或已推迟。要合并到现有团队技能中的技能会等到那时；之后，**动态** 中的一条通知 **查看要合并的技能** 会打开合并对话。
