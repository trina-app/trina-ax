---
title: 设置你的团队
description: 所有者创建团队后的第一步：连接 AI、公司简介、技能、团队文件、工具和邀请。
---

创建团队后，应用会带你（所有者）完成几个简短的步骤。只有所有者能看到它们。每一步都可以推迟，而且这些步骤会在任何设备上从你停下的地方继续。

如果你是在 Mac 或 Windows 电脑的浏览器中创建的团队，下一页会提供 **在 Mac 应用中继续**（或 **在 Windows 应用中继续**）：应用会自动为你登录，不需要再输入一次密码，而且只有应用能找到你电脑上的工作文件。**在浏览器中继续** 会进入这里的步骤。 这些步骤会跟着你走：在应用中会从你停下的地方打开，注册链接中的公司网站也已经填好。

## 步骤

:::steps
#### AI 连接（仅在还没有 AI 回答时）
连接 Claude 或 ChatGPT 订阅，或者一个 API 密钥。没有 AI 就无法读取公司简介，所以这一步排在最前面。**稍后再做** 会离开这些步骤；之后设置行会显示 **连接 AI**。

#### 公司简介
输入公司网站。AI 会读取网站，并写一行关于公司的介绍（“我们找到的内容：… · 编辑”）。你可以通过 **如有介绍文件，请添加** 加上一份介绍文件或公司演示文稿。 AI 读取时没有需要按的按钮。如果超过 90 秒，**不等了，继续** 会进入下一步，读取仍会继续；稍后再次打开公司简介即可查看。

**保存并继续** 会保存简介。它还会把网站的图片和一份公司介绍文件放进团队的品牌文件夹；按钮下方的一行会说明这一点。其他什么都不会自动开始。

#### 选择团队要使用的技能
Trina AX 准备好的技能，每个都带有 **示例**：Company slide deck、Promo cards、Promo video 和 Natural writing。如果你保存了公司简介，前三个会预先勾选。按钮会说明要添加什么，例如 **添加 3 个技能**。在你按下它之前，什么都不会添加。要带来你在 Claude Code 或 Codex 中使用的技能，之后请使用 **团队技能 › 导入我的技能**（[团队技能](../use/team-skills.md)）。

#### 团队文件
**选择文件夹**，选一个存放公司文档的文件夹。AI 只根据文件名、文件夹和日期，建议团队可以用的文件，由你勾选要上传的内容。在你按下按钮之前，什么都不会上传。之后 AI 可以读取这些文件，并建议把它们整理到哪些文件夹（**要这样整理吗？**）。会有一行说明谁能看到这些文件。

#### 连接工具
**要连接常用的工具吗？** 提供 Google Drive（如果你的服务器支持）和 Notion，**连接其他工具** 会打开完整列表。在手机上会跳过这一步。

#### 邀请
复制准备好的消息。它会提到一个技能。加入的人会先来到首页，欢迎卡片会告诉他们是谁邀请的、第一步可以做什么；这个技能在**团队技能**里。如果每个人需要登录自己的 AI，消息中也会说明这一点。邀请页面会提供对方浏览器的语言。如果那台电脑上已经有别人登录，页面会写“你已经在<团队名>中”，并提供 **退出登录后加入**，它会退出登录并打开同一个链接。
:::

最后，**一切就绪** 会建议你用团队的某个技能做出第一个成果，例如 **制作宣传卡片**。它只显示一次。

## 回到设置

- 在步骤完成之前，**继续设置 · 2/5** 会显示在左侧栏旁边的 Trina、聊天、文件和动态列表的顶部附近。它会打开你停下时的那一步。在手机上，它在 **Trina** 标签的 **☰** 列表顶部和 **文件** 标签的顶部，首页则会在消息框下方显示一行不显眼的提示。
- 在首页打开应用时，也会带你回到这些步骤，每个浏览器会话一次。
- ✕ 会隐藏这一行。管理 › 首页 中的 **重新显示设置** 会让它重新出现。
- 首页的团队目标卡片和 **团队中已准备好** 都有 **隐藏**。在 **设置 › 个人资料** 中可以重新显示（团队目标也可在 管理 › 首页 中重新显示）。

## 什么时候算设置完成

公司简介、技能、团队文件、工具和邀请都已完成或已推迟。要合并到现有团队技能中的技能会等到那时；之后，**动态** 中的一条通知 **查看要合并的技能** 会打开合并对话。
