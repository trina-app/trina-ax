Trina AX 由几个基本部分组成。其他所有页面都会用到这些词。

## 人员和角色

| 角色 | 可以做什么 |
|---|---|
| **所有者** | 管理员能做的一切，再加上团队层面的决定，例如更新、恢复、移除成员和团队名称。 |
| **管理员** | 管理成员、小组、文件夹权限、团队的 AI 连接和引擎，以及团队设置。管理员无法阅读其他人的对话。 |
| **成员** | 与 AI 对话，使用自己可以打开的文件和技能，并拥有个人文件夹和技能。 |
| **访客** | 团队之外的人，只在一个群聊或一个项目中，别处都看不到。除非团队开启，否则他们的 AI 是关闭的。 |

**小组** 是一组人，例如销售或财务。文件夹规则可以指定小组或个人。

## 团队文件夹

公司的所有知识都放在服务器上的一个团队文件夹中。

| 文件夹 | 谁能看到 |
|---|---|
| `shared/` | 按文件夹规则而定，通常是整个团队。 |
| `groups/<group>/` | 该小组的人，除非有规则加入了其他人。 |
| `projects/<project>/` | 按文件夹规则而定。 |
| `skills/` | 所有人都能读取。技能管理者可以修改。 |
| `users/<id>/` | 只有本人。连所有者和管理员也看不到。 |

你无法打开的文件夹或文件是看不见的：在文件中、AI 的回答中、搜索、预览、历史记录和回收站中都看不见。[阅读文件和权限](../use/files-and-permissions.md)。

## 对话和项目

**对话** 是与 AI 的一次交谈。在发起人把它共享给人员或小组之前，只有发起人能看到。团队项目中的对话，项目成员都能看到。

**项目** 是一个带有指示的文件夹，适合反复用到同一批文件的工作。在项目中的对话会让 AI 使用那个文件夹和那些指示。[阅读对话和项目](../use/chats-and-projects.md)。

## 技能

**技能** 是一个 `SKILL.md` 文件，包含名称、描述和操作步骤。它告诉 AI 你们团队如何完成一项任务。它永远不会授予额外的访问权限。[阅读团队技能](../use/team-skills.md)。

## 引擎和 AI 连接

**引擎** 是负责回答的智能体：

| 引擎 | 说明 |
|---|---|
| Claude Code | 默认引擎。 |
| Codex | OpenAI 的智能体。在办公室的 Mac 上不可用。 |
| API | 实验性功能。使用配置好的 API 地址、模型和密钥。 |

**AI 连接** 是引擎使用的账号：Claude 订阅、API 密钥或 ChatGPT 登录。连接可以是个人的，也可以由一个小组或整个团队共享。

## MCP 和其他连接

**MCP 连接** 让 AI 使用外部服务，例如 Notion 或 Linear，使用的是个人或团队自己的登录。Trina AX 也可以反过来用：你自己的 Claude 可以把 Trina AX 当作 MCP 服务器来连接。[阅读 MCP](../use/mcp.md)。

## 定时任务和用量

**定时任务** 按时间表重复一个请求，使用团队的时区。**用量** 按人统计回答数、token 数和预估费用，并可设置限制。[阅读定时任务](../use/scheduled-tasks.md)。
