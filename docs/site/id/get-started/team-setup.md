---
title: Menyiapkan tim Anda
description: Langkah pertama owner setelah membuat tim: menghubungkan AI, profil perusahaan, skill Anda sendiri, file tim, dan undangan.
---

Setelah Anda membuat tim, aplikasi memandu Anda, sebagai owner, melalui beberapa langkah singkat. Hanya owner yang melihatnya. Setiap langkah bisa ditunda, dan langkah-langkah ini berlanjut dari tempat Anda berhenti, di perangkat mana pun.

## Langkah-langkahnya

:::steps
#### Koneksi AI (hanya jika belum ada AI yang menjawab)
Hubungkan langganan Claude atau ChatGPT, atau kunci API. Tanpa AI, profil perusahaan tidak bisa dibaca, jadi langkah ini datang lebih dulu. **Nanti saja** keluar dari langkah-langkah ini; baris penyiapan lalu bertuliskan **Hubungkan AI**.

#### Profil perusahaan
Ketik alamat situs web perusahaan. AI membacanya dan menulis satu baris tentang perusahaan ("Ini yang kami pahami: … · Ubah"). Anda bisa menambahkan file perkenalan atau deck perusahaan dengan **Tambahkan berkas profil jika ada**.

**Simpan dan lanjut** menyimpan profil dan mulai membuat deck profil perusahaan Anda, satu kali per tim. Baris di bawah tombol menyebutkan berapa lama prosesnya (waktu deck tim, Admin › Pengaturan tim) dan di mana deck itu nanti berada: **Profil perusahaan kami** di daftar chat Trina Anda. Menyimpan lagi nanti hanya menyimpan. **Nanti saja** melewati deck.

#### Skill Anda
Bawa skill yang Anda pakai dengan Claude Code atau Codex ke tim. Pilih folder `.claude` Anda, atau folder `.codex` Anda (Codex menyimpan skill pribadi di `.agents`), atau seret folder itu ke langkah ini. Atau tempelkan satu baris ke Claude Code atau Codex setelah keduanya terhubung ke tim (lihat [konektor MCP](../../agents/mcp-connector.md) (bahasa Inggris)). Tidak ada yang sampai ke tim sebelum Anda menekan **Bagikan ke tim**. Skill yang berisi kunci tidak pernah meninggalkan komputer Anda.

#### File tim
Masukkan dokumen tim (profil perusahaan, laporan, formulir) ke folder tim. Satu baris menyebutkan siapa yang akan melihatnya.

#### Undang
Salin pesan yang sudah disiapkan. Pesan itu menyebut satu skill, dan orang yang bergabung langsung masuk ke formulir skill tersebut. Jika setiap orang masuk ke AI mereka sendiri, pesan itu menyebutkannya. Halaman undangan menawarkan bahasa browser orang tersebut. Jika orang lain sudah masuk di komputer itu, halaman menampilkan "Anda sudah ada di <nama tim>" dan menawarkan **Keluar untuk bergabung**, yang mengeluarkan akun tersebut lalu membuka tautan yang sama.
:::

Di akhir, **Semua siap** menawarkan agar Anda mencoba skill itu sendiri lebih dulu. Ini hanya tampil satu kali.

## Selama deck dibuat

Deck adalah chat biasa dengan Trina. Di komputer, Anda melihatnya di **Riwayat Trina** pada daftar Trina di sebelah kiri, di samping langkah-langkah tadi; Anda bisa membukanya kapan saja. Di ponsel, buka tab **Trina** dan tekan **☰**: deck ada di **Riwayat Trina**.

## Kembali lagi

- **Lanjutkan penyiapan · 2/4** tampil di dekat bagian atas daftar Trina, Obrolan, File, dan Aktivitas di samping bilah kiri sampai semua langkah selesai. Baris ini membuka langkah-langkah di tempat Anda berhenti. Di ponsel, baris ini ada di bagian atas daftar **☰** pada tab **Trina** dan pada tab **File**, dan Beranda menampilkannya sebagai baris tenang di bawah kotak pesan.
- Membuka aplikasi di Beranda juga membawa Anda kembali ke langkah-langkah ini, satu kali per sesi browser.
- ✕ menyembunyikan baris itu. **Tampilkan penyiapan lagi** di Admin › Beranda memunculkannya kembali.

## Kapan penyiapan dianggap selesai

Profil perusahaan sudah disimpan dengan deck dimulai atau ditunda, dan skill Anda, file tim, serta undangan masing-masing sudah selesai atau ditunda. Skill yang akan digabung ke skill tim yang sudah ada menunggu sampai saat itu; setelahnya satu pemberitahuan di **Aktivitas**, **Periksa skill yang akan digabung**, membuka chat penggabungan.
