Trina AX は、いくつかの基本的な要素でできています。ほかのページはすべて、ここで説明する用語を使います。

## 人と役割

| 役割 | できること |
|---|---|
| **オーナー** | 管理者ができることすべてに加えて、アップデート、復元、メンバーの削除、チーム名など、チーム全体に関わる決定。 |
| **管理者** | メンバー、グループ、フォルダー権限、チームの AI 接続とエンジン、チーム設定の管理。管理者もほかの人のチャットは読めません。 |
| **メンバー** | AI とのチャット、開いてよいファイルとスキルの利用、個人のフォルダーとスキルの保管。 |
| **ゲスト** | チームの外の人で、最大で 1 つのプライベートチャンネルかグループトークと 1 つのプロジェクトに参加します。AI が選ばれていない限り、AI は使えません。席（シート）は使いません。[ゲストについて読む](../use/guests.md)。 |

**グループ** は、営業や経理のような人の集まりです。フォルダーは、グループや人と共有できます。

## チームのフォルダー

会社の知識はすべて、サーバー上の 1 つのチームフォルダーに入っています。

| フォルダー | 見える人 |
|---|---|
| `shared/` | 共有の設定のとおり。ふつうはチーム全員。 |
| `groups/<group>/` | そのグループの人と、共有された人。 |
| `projects/<project>/` | そのプロジェクトのメンバーだけ。 |
| `skills/` | 全員が読めます。変更できるのはスキル管理者です。 |
| `users/<id>/` | 本人だけ。オーナーや管理者にも見えません。 |

開けないフォルダーやファイルは、どこにも表示されません。ファイル画面にも、AI の回答にも、検索、プレビュー、履歴、ゴミ箱にも出てきません。[ファイルと権限について読む](../use/files-and-permissions.md)。

## チャットとプロジェクト

**チャット** は AI との会話です。始めた人が人やグループに共有するまでは、その人にしか見えません。チームのプロジェクトの中のチャットは、始めた人がロックしない限り、そのプロジェクトのメンバーに見えます。

**プロジェクト** は、指示がついたフォルダーです。同じファイルを何度も使う仕事に向いています。プロジェクトの中のチャットでは、AI がそのフォルダーと指示を使います。[チャットとプロジェクトについて読む](../use/chats-and-projects.md)。

## スキル

**スキル** は、名前、説明、手順が書かれた `SKILL.md` ファイルです。チームがある作業をどう進めるかを AI に伝えます。スキルによってアクセスできる範囲が広がることはありません。[チームスキルについて読む](../use/team-skills.md)。

## エンジンと AI 接続

**エンジン** は、回答するエージェントです。

| エンジン | 補足 |
|---|---|
| Claude Code | 標準のエンジンです。 |
| Codex | OpenAI のエージェントです。社内の Mac では使えません。 |
| API | 試験的な機能です。設定した API のアドレス、モデル、キーを使います。 |

**AI 接続** は、エンジンが使うアカウントです。Claude のサブスクリプション、API キー、ChatGPT のログインのいずれかです。接続は個人用にすることも、グループやチーム全体で共有することもできます。

## MCP とそのほかの接続

**MCP 接続** を使うと、AI が Notion や Linear などの外部サービスを、本人またはチームのログインで使えます。逆向きにも使えます。自分の Claude から、MCP サーバーとして Trina AX に接続できます。[MCP について読む](../use/mcp.md)。

## 定期タスクと使用量

**定期タスク** は、決まったスケジュールで、チームのタイムゾーンに合わせて依頼を繰り返します。**使用量** では、一人ひとりの回答数、トークン数、推定コストを数えます。上限を設けることもできます。[定期タスクについて読む](../use/scheduled-tasks.md)。
