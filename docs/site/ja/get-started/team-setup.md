---
title: チームを準備する
description: チームを作ったあとにオーナーが行う最初の手順です。AI の接続、会社紹介、自分のスキル、チームのファイル、招待。
---

チームを作ると、アプリがオーナーであるあなたを、いくつかの短い手順に案内します。この手順はオーナーにしか表示されません。どの手順も後回しにでき、どの端末からでも中断したところから再開できます。

## 手順

:::steps
#### AI の接続（まだ AI が答えられないときだけ）
Claude または ChatGPT のサブスクリプション、あるいは API キーを接続します。AI がないと会社紹介を読み取れないため、この手順が最初に来ます。**あとで** を押すと手順を抜けます。そのあと、設定の行には **AIを接続する** と表示されます。

#### 会社紹介
会社のホームページのアドレスを入力します。AI がそれを読んで、会社について 1 行にまとめます（「このように理解しました：… · 編集」）。**紹介資料があれば一緒に入れる** から、紹介ファイルや会社案内の資料も追加できます。

**保存して続ける** を押すと、会社紹介が保存され、会社紹介資料の作成が始まります（チームごとに 1 回）。ボタンの下の行に、かかる時間（チームの資料作成時間。管理 › チーム設定）と、できあがる場所が表示されます。場所は、トリナのチャットの一覧にある **会社紹介資料** です。あとでもう一度保存しても、保存されるだけです。**あとで** を押すと、資料の作成を飛ばします。

#### 自分のスキル
Claude Code や Codex で使っているスキルをチームに持ち込みます。`.claude` フォルダー、または `.codex` フォルダー（Codex は個人のスキルを `.agents` に置きます）を選ぶか、この手順の画面にドロップしてください。Claude Code や Codex をチームに接続したあとなら、そこに 1 行貼り付ける方法もあります（[MCP コネクター](../../agents/mcp-connector.md)（英語）を参照）。**チームに共有** を押すまで、チームには何も送られません。キーを含むスキルは、あなたのパソコンから出ることはありません。

#### チームのファイル
チームの資料（会社紹介、報告書、書式）をチームのフォルダーに入れます。誰に見えるかが 1 行で表示されます。

#### 招待
用意されたメッセージをコピーします。メッセージには 1 つのスキルの名前が入っていて、参加した人はそのスキルのフォームから始めます。一人ひとりが自分の AI にログインする場合は、メッセージにそのことが書かれます。招待ページは、その人のブラウザーの言語で表示されます。そのパソコンで別の人がすでにログインしているときは、ページに「すでに<チーム名>に参加しています」と表示され、**ログアウトして参加** を選べます。これを押すとログアウトして、同じリンクを開きます。
:::

最後に **準備ができました** の画面で、そのスキルをまず自分で試すよう勧められます。この画面は 1 回だけ表示されます。

## 資料ができるまでのあいだ

資料は、トリナとのふつうのチャットです。パソコンでは、手順の横、左にあるトリナの一覧の **トリナの履歴** に表示され、いつでも開けます。スマートフォンでは **トリナ** タブを開いて **☰** を押すと、**トリナの履歴** の中にあります。

## あとで戻ってくる

- 手順が終わるまで、左のバーの横にあるトリナ、トーク、ファイル、アクティビティの一覧の上のほうに **設定を続ける · 2/4** が表示されます。押すと、中断したところから手順を開きます。スマートフォンでは、**トリナ** タブの **☰** の一覧と **ファイル** タブのいちばん上に表示され、ホームではメッセージ欄の下に目立たない行として表示されます。
- ホームでアプリを開いたときも、ブラウザーのセッションごとに 1 回、手順に戻ります。
- ✕ を押すと、この行が隠れます。管理 › ホームの **初期設定をもう一度表示** で元に戻せます。

## 設定が終わったとみなされるとき

会社紹介が保存され、資料の作成が始まっているか後回しになっていて、自分のスキル、チームのファイル、招待がそれぞれ終わっているか後回しになっているときです。既存のチームスキルにまとめるスキルは、それまで待ちます。終わったあと、**アクティビティ** に **まとめるスキルを確認** という通知が 1 件届きます。これを開くと、まとめるためのチャットが開きます。
