팀을 만들면 앱이 팀장에게 짧은 단계 몇 개를 차례로 보여 줘요. 이 단계는 팀장에게만 보여요. 어느 단계든 미뤄 둘 수 있고, 어떤 기기에서 다시 열어도 멈춘 곳부터 이어져요.

## 단계

:::steps
#### AI 연결 (아직 답하는 AI가 없을 때만)
Claude나 ChatGPT 구독, 또는 API 키를 연결해요. AI가 없으면 회사 소개를 읽을 수 없어서 이 단계가 맨 앞에 와요. **나중에**를 누르면 단계에서 나가고, 시작 설정 줄에는 **AI 연결**이라고 나와요.

#### 회사 소개
회사 홈페이지 주소를 입력해요. AI가 홈페이지를 읽고 회사를 한 줄로 정리해요("이렇게 이해했어요: … · 고치기"). **소개 자료가 있으면 같이 넣기**로 회사 소개 파일이나 회사 소개서를 같이 넣을 수도 있어요.

**저장하고 계속**을 누르면 회사 소개를 저장하고, 회사 소개서 만들기를 시작해요. 소개서는 팀마다 한 번만 만들어요. 버튼 아래 줄에 얼마나 걸리는지(팀의 소개서 만들기 시간, 관리자 › 팀 설정)와 어디에 생기는지가 나와요. 트리나 채팅 목록의 **우리 회사 소개서**예요. 나중에 다시 저장하면 저장만 해요. **나중에**를 누르면 소개서는 건너뛰어요.

#### 내 스킬
Claude Code나 Codex에서 쓰던 스킬을 팀으로 가져와요. `.claude` 폴더나 `.codex` 폴더(Codex는 개인 스킬을 `.agents`에 둬요)를 고르거나, 단계 화면에 끌어다 놓아요. Claude Code나 Codex를 팀에 연결해 뒀다면 한 줄을 붙여 넣는 방법도 있어요([MCP 커넥터](../../agents/mcp-connector.md) (영어) 참고). **팀에 공유**를 누르기 전에는 팀에 아무것도 가지 않아요. 키가 들어 있는 스킬은 내 컴퓨터 밖으로 나가지 않아요.

#### 팀 파일
팀 문서(회사 소개, 보고서, 양식)를 팀 폴더에 넣어요. 누가 보게 되는지 한 줄로 알려 줘요.

#### 초대
미리 써 둔 초대 메시지를 복사해요. 메시지에는 스킬 하나가 들어 있고, 초대받은 사람은 들어오자마자 그 스킬의 양식을 보게 돼요. 각자 자기 AI에 로그인해야 하는 팀이면 메시지에 그렇게 적혀 있어요. 초대 페이지는 받는 사람 브라우저의 언어로 열려요. 그 컴퓨터에 다른 사람이 이미 로그인해 있으면 "이미 <팀 이름>에 들어와 있어요"라고 나오고, **로그아웃하고 참여하기**를 누르면 로그아웃한 뒤 같은 링크를 열어요.
:::

마지막 화면 **준비 끝났어요**에서는 그 스킬을 내가 먼저 써 보라고 권해요. 이 화면은 한 번만 나와요.

## 소개서를 만드는 동안

소개서는 트리나와 나누는 보통 채팅이에요. 컴퓨터에서는 단계 화면 옆, 왼쪽 트리나 목록의 **트리나 기록**에 보여요. 언제든 열어 볼 수 있어요. 폰에서는 **트리나** 탭에서 **☰** 버튼을 누르면 **트리나 기록**에 있어요.

## 다시 이어 하기

- 단계를 다 마칠 때까지 왼쪽 막대 옆 트리나, 대화, 파일, 활동 목록 위쪽에 **설정 이어서 하기 · 2/4**가 보여요. 누르면 멈춘 단계부터 열려요. 폰에서는 **트리나** 탭의 **☰** 목록과 **파일** 탭 맨 위에 있고, 홈에서는 메시지 입력창 아래에 조용한 줄로 보여요.
- 앱을 홈에서 열어도 단계 화면으로 돌아와요. 브라우저를 새로 열 때마다 한 번이에요.
- ✕를 누르면 이 줄을 숨겨요. 관리자 › 홈의 **시작 설정 다시 보기**로 다시 보이게 할 수 있어요.

## 설정이 끝났다고 보는 때

회사 소개를 저장하고 소개서를 시작했거나 미뤘을 때, 그리고 내 스킬, 팀 파일, 초대를 각각 마쳤거나 미뤘을 때예요. 기존 팀 스킬에 합칠 스킬은 그때까지 기다려요. 그 뒤에 **활동**에 **합칠 스킬 확인하기** 알림이 하나 오고, 누르면 합치는 채팅이 열려요.
