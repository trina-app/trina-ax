Trina AX는 몇 가지 기본 단위로 이루어져 있어요. 다른 페이지는 모두 이 용어를 써요.

## 사람과 역할

| 역할 | 할 수 있는 일 |
|---|---|
| **팀장** | 관리자가 하는 일을 모두 하고, 업데이트, 복원, 팀원 내보내기, 팀 이름처럼 팀 전체에 걸린 일도 정해요. |
| **관리자** | 팀원, 부서, 폴더 권한, 팀의 AI 연결과 엔진, 팀 설정을 관리해요. 다른 사람의 채팅은 읽을 수 없어요. |
| **팀원** | AI와 채팅하고, 열 수 있는 파일과 스킬을 쓰고, 개인 폴더와 개인 스킬을 둬요. |
| **게스트** | 팀 밖의 사람이에요. 비공개 채널이나 그룹 대화 한 곳과 프로젝트 한 곳까지 들어올 수 있어요. 따로 AI를 골라 주지 않으면 AI를 쓸 수 없어요. 팀 인원 수에 들어가지 않아요. [게스트 알아보기](../use/guests.md). |

**부서**는 영업, 재무처럼 사람을 묶은 단위예요. 폴더 규칙에는 부서나 사람을 지정할 수 있어요.

## 팀 폴더

회사 자료는 모두 서버의 팀 폴더 하나에 있어요.

| 폴더 | 볼 수 있는 사람 |
|---|---|
| `shared/` | 폴더 규칙대로예요. 보통은 팀 전체예요. |
| `groups/<group>/` | 그 부서 사람들이에요. 규칙으로 다른 사람을 더할 수도 있어요. |
| `projects/<project>/` | 폴더 규칙대로예요. |
| `skills/` | 모두 읽어요. 팀 스킬 담당자가 고쳐요. |
| `users/<id>/` | 그 사람만요. 팀장과 관리자도 못 봐요. |

열 수 없는 폴더나 파일은 아예 보이지 않아요. 파일 화면, AI 답변, 검색, 미리보기, 기록, 휴지통 어디에서도요. [파일과 권한 알아보기](../use/files-and-permissions.md).

## 채팅과 프로젝트

**채팅**은 AI와 나누는 대화예요. 사람이나 부서와 공유하기 전까지는 시작한 사람만 봐요. 팀 프로젝트 안의 채팅은 그 프로젝트 멤버가 봐요.

**프로젝트**는 지침이 붙은 폴더예요. 같은 파일을 두고 계속 반복되는 일에 써요. 프로젝트 안에서 채팅하면 AI가 그 폴더와 지침을 받아요. [채팅과 프로젝트 알아보기](../use/chats-and-projects.md).

## 스킬

**스킬**은 이름, 설명, 진행 순서가 적힌 `SKILL.md` 파일이에요. 팀이 어떤 일을 어떻게 하는지 AI에게 알려 줘요. 권한을 더 주지는 않아요. [팀 스킬 알아보기](../use/team-skills.md).

## 엔진과 AI 연결

**엔진**은 실제로 답을 만드는 AI 도구예요.

| 엔진 | 참고 |
|---|---|
| Claude Code | 기본 엔진이에요. |
| Codex | OpenAI가 만든 엔진이에요. 사무실 Mac에서는 쓸 수 없어요. |
| API | 실험 기능이에요. 설정해 둔 API 주소, 모델, 키를 써요. |

**AI 연결**은 엔진이 쓰는 계정이에요. Claude 구독, API 키, ChatGPT 로그인 중 하나예요. 연결은 개인용일 수도 있고, 부서나 팀 전체가 같이 쓸 수도 있어요.

## MCP와 다른 연결

**MCP 연결**을 쓰면 AI가 Notion, Linear 같은 바깥 서비스를 써요. 로그인은 각자의 계정이나 팀 계정으로 해요. 반대 방향도 돼요. 내 Claude가 Trina AX를 MCP 서버로 연결할 수 있어요. [MCP 알아보기](../use/mcp.md).

## 예약 작업과 사용량

**예약 작업**은 정해 둔 일정에 맞춰, 팀 시간대 기준으로 같은 요청을 반복해요. **사용량**은 사람마다 답변 수, 토큰, 예상 비용을 세고, 원하면 한도도 걸 수 있어요. [예약 작업 알아보기](../use/scheduled-tasks.md).
