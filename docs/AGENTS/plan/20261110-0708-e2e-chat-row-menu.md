## Goal

header's title menu (first, and the title is now a menu for every made chat) and the search palette's chat row menu
(between rename and delete). CI does not run the web e2e, so the specs that list those menus exactly fail on `dev`
since then. After this change they pass again, with the item in its place and the tests' intent unchanged.
