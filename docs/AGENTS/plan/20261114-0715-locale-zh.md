# Simplified Chinese (zh) across Trina AX

- Date (UTC): 2026-11-14 07:15
- Branch: `feat/locale-zh`
- Status: in progress
- Where: Team AX core (shared, server, web, desktop, relay, push gateway, menubar). Why: app languages are core.
- Version impact: minor, a new app language

## Goal

Chinese-speaking office workers can use Trina in Simplified Chinese. The Trina Cloud sign-up console can set a team's
default language to `zh`, so the server must accept `zh` as a team and personal language.

## Scope

In: locale `zh` (label 简体中文) in the shared `Locale` type, browser/OS language detection, every server message table
and helper (errors, mail, notifications, AI language hints), the web dictionary `web/src/i18n/zh.ts`, the desktop
shell strings, the menubar app, the relay pages, the push gateway lock-screen lines, i18n checks and tests, docs that
list languages.
Out: the phone app's native setup screens (Korean and English only today, as for ja/es), App Store / Play listing text.

Detection: `zh`, `zh-CN`, `zh-Hans`, `zh-SG` and also `zh-TW`, `zh-HK`, `zh-Hant` all map to `zh`. Simplified Chinese is
the only Chinese we have, and a Traditional reader reads it better than English.

## Steps

1. Add `zh` to `Locale`, `LOCALE_NAMES`, `LOCALE_ORDER`, `asLocale`.
2. Fill `zh` in every table and positional helper (`bun run check:i18n`, `bun run typecheck`).
3. Translate `en.ts` into `zh.ts` and the desktop strings: plain words for non-developers, placeholders and plural
   forms unchanged.
4. Menubar, relay, push gateway, docs, README language links, tests that list languages.
5. Typecheck, i18n check, unit tests against base; screenshots in zh at 1440 and 390.

## Risks

Six app languages instead of five: every new table must carry `zh` (the i18n check enforces it). No migration: the
language columns are free text checked by the shared `Locale` schema.
