# My setup ("내 설정"): one personal card on Home for everyone, the owner included

- Date (UTC): 2026-11-20 01:36
- Branch: `feat/my-setup-card`
- Status: done
- Where: Team AX core (server/src/onboarding, web/src/components/onboarding, web/src/pages/Home.tsx). Why: onboarding
  and Home are core (docs/REPOSITORY-RULES.md).
- Version impact: minor (a new card for owners, a new row for everyone, one additive migration)

## Goal

The owner (Dion, 2026-11-20) approved one personal setup card for everyone. Today the member welcome card is only for
people who were invited, and the owner gets nothing personal after the team setup. The card is now "내 설정" for
everyone: connect your own tools, a photo, and the computer's files.

## Scope

In:
- Home top, one card at a time (owner): team setup unfinished → "설정 이어서 하기" (on a computer too; the list
  panel's setup row hides on Home then); finished → 내 설정; 내 설정 done or hidden → the 7-day goal. A member who
  joins sees 내 설정 first (as before).
- Server: the owner's card is made when the team setup reaches its end screen (finishedAt), counting 14 days from
  then. New column `member_welcome.setup` (migration 428_b, additive). `welcomeOf` returns `kind: 'owner'` for it.
- New row "내 도구 연결": the team's recommended tools first (`memberTools` from GET /api/integrations, PR #93), then
  the usual defaults (Google Drive, Gmail, Google Calendar, Notion), at most four, each with its own [연결] for the
  person's own account. A listed service connects in place (the welcome tools step's own flow); a Google tool opens
  its page in Settings › Connectors (its own personal sign-in). A tool the team connected for everyone shows
  "팀 연결됨" with no button. Done (server) once the person has any connection of their own. Counted.
- Rows: owner 3 (tools, photo, files); member: tools, hi, photo, ask (or the no-AI way out), files.
- Merges: the files row is "Bring work files" in the desktop app and "Open the desktop app" in a Mac or Windows
  browser; the rooms row is one line under the title; "팀 파일 정리하기" moves to Admin › Home (admins).
- Ends: required rows done → "준비 끝" for a few seconds, then gone; Hide; 14 days. Hidden but still within its days:
  Settings › Profile has "Show my setup on Home again" (PATCH /api/me/welcome `{ show: true }`).

Out: a card for owners whose setup finished before this release; Drive inline sign-in on Home (it opens its page).
If PR #93 is not merged, `memberTools` is absent and read as "not chosen" (defaults only): no code waits for it.
