## Goal

The owner asked the team AI to put the company seal on a quote PDF; no tool could change an existing PDF. Then: "PDFs
must be freely editable, not only stamped". People ask Trina to remove, extract, merge, split, reorder, rotate and insert
pages, stamp a seal, add a line of text, a watermark or page numbers, and get a new PDF next to the original.

## Scope

In: stamp_pdf; edit_pdf (operations in order on one PDF); merge_pdfs; split_pdf; pdf-lib (MIT) in the office worker
only; Pretendard through @pdf-lib/fontkit (MIT) for text that is not Latin; the same permission handling as every save
(SHARED_TOOLS, ROOM_FILE_TOOLS, WRITE_TARGET_ARGS, the read card for files named inside lists); notices.
Out: changing a PDF's own text or pictures, PDF forms, encryption.

## Steps

1. stamp_pdf (worker mode `pdf-stamp`), tests.
2. edit_pdf, merge_pdfs, split_pdf (worker mode `pdf-pages`), page lists, tests.
3. Shared-chat read card for nested paths (namedPaths), tests.
4. Real-AI run in a shared project chat, independent review, QA rows, PR.

## Decisions

`docs/decisions/20261116-edit-pdf.md`.

## Risks

Untrusted PDFs, images and the font are parsed only in the office worker. Permissions follow make_file's path. A
locked PDF is refused. Text font: whole Pretendard embedded (about 1.2 MB a file), because subsetting drew nothing.
