# A seal on a PDF lands on the printed mark, under the same rules as Word and Hangul

- Date (UTC): 2026-11-23 20:36
- Branch: `fix/pdf-sign-slots`
- Status: in progress (plan under review)
- Where: Team AX core (`server/src/files`, `server/src/tools`, `shared/src/tools.ts`). Why: the PDF tools and the signing path are core (docs/REPOSITORY-RULES.md)
- Version impact: minor, `stamp_pdf` and `edit_pdf` `stamp_image` gain an `at` input, and a picture the person did not upload now asks first

## Goal

PR 2 of docs/decisions/20261123-signing-slots.md. Today the AI must work out x/y for a seal on a PDF from a page image, and
any picture goes on with no ownership check. Word and Hangul have a shared target resolver, a card for a picture that is not
the person's own, and a result that says what was checked. PDF gets the same.

## What was measured before planning

- `pdftotext -bbox -cropbox` (Poppler is on every install, `packages.json`) gives word boxes **in the page as shown**, from its
  top-left, for /Rotate 0, 90, 180, 270 and with a CropBox (8 made-up PDFs). That is the coordinate system `stamp_pdf` already
  takes as `x_mm`/`y_mm`. Its page width and height are **not** swapped for 90 and 270, so they are not used.
- It reads text in Form XObjects and real font widths, which `pdf-text.ts` does not (that reader estimates `Uni*-UCS2-H`).
- Drawing order is not reading order, so `occurrence` cannot count in drawing order.

## Design

1. **Input.** Optional `at` and `occurrence` on `stamp_pdf` and `stamp_image`. `at` and `position` exclude each other. With `at`,
   `page` limits the search (default: the whole PDF) and the default width is 15 mm. Corners and x/y work as before.
2. **Model, `server/src/files/pdf-marks.ts`.** From `pdftotext -bbox-layout -cropbox` on the exact bytes: pages, lines, words with
   boxes. Reading order is explicit: page, then top to bottom, then left to right, as shown. Text drawn twice at one spot (fake
   bold) is one place.
3. **Resolver.** The same `pickSignMark`, `bareMarkAsk`, `placedOn` as Word and Hangul. Several places: refuse and list them,
   as capped quoted text, unless `occurrence` picks one in reading order.
4. **Invariant.** One proved location. A label that crosses lines must be contiguous in one block. Two hits that cannot be
   ordered without doubt (same line band and overlapping) are refused.
5. **Measure.** The mark's word box. A mark inside a longer word (`홍길동(인)`) uses character shares inside that one measured word.
6. **Hidden text.** The chosen mark must be visible, read from the `pdf-text.ts` glyph flags. Invisible text counts only on a scanned
   page (a page image with an OCR layer), and the result says so. If the glyph reader cannot see the mark (in a Form XObject),
   the result says visibility was not checked.
7. **Same call.** With `at`, `edit_pdf` takes only other `stamp_image` operations in that call. Page, text and form changes go first
   in their own call, so nothing shifts between the read and the stamp.
8. **Ownership.** `isOwnUpload`, `confirmNotOwnPictures`, Always keys, for `stamp_pdf` and `stamp_image`, with or without `at`. The
   target is resolved before the card, so nobody approves a call that is then refused. `docs/ASKS.md` updated.
9. **Landing.** The worker reads the image's matrix back from the **saved** bytes and maps it to the page as shown; the same mark is
   found again in the saved file's text. More than 2 mm off on either axis: nothing is saved. Mark not found again: "not checked".
10. **Result.** Quotes the text it landed on and one state: `measured on the saved file`, or `not checked` with the reason.

## Scope

Out: scanned PDFs with no text layer (no mark to find: corners and x/y as before, and the result says it cannot find marks),
label cells and signature boxes without printed text, marks in annotations or form fields.

## Risks

- **Behaviour change:** a scheduled run that stamps a picture the person did not upload is refused unless they chose Always. This
  includes a company logo or seal in a quote skill. It is the rule Word and Hangul already have, decided by the coordinator.
- Tool schemas change: exact tool lists and engine prompt pins are re-recorded on purpose.
- `pdftotext` runs twice on a call with `at`, under the existing read timeout. Without Poppler, `at` is refused with the reason.

## Tests

Corpus in each case with numeric distance to the mark: whole line, two signers on a line, duplicated marks, multi-page, the four
rotations, CropBox, marks in a Form XObject, invisible text, fake bold, a mark glued to a name, Korean CID fonts. A generated
test: shuffled drawing order and repeated marks, asserting the true target or a refusal. `typecheck`, PDF, picture and card
suites, `check:prepush` on Bun 1.3.12.
