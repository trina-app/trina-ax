## Goal

Five things QA found on dev after #651, in one PR.

## Scope

1. A shared chat's file link that does not open for me had a dead end ("can't be found, or you don't have access")
   unless the chat made the file in its creator's own folder. Any team file linked in a message of a shared chat (a
   project's shared chat too) that I see, by someone who can read it, now offers [Ask to view] (an ordinary file access
   request, as a room message's link does). Where no ask applies, the line says who can share it.
2. Problem report sheet: the "also sent" line under the preview box, not inside its scroll; file links in the preview
   read as the file's name.
3. Scheduled tasks: a template's folders in place words on the list card ("전사 공유 → 내 폴더 › reports") and the save
   line; the detail page says "다음 실행" and "아직 실행한 적이 없어요" once.
4. The chat trash banner's button says "실행 취소", the word of the delete toast (#651's decision: undo is 실행 취소).
5. A forked chat: on a phone only the composer's "이어 왔어요" line (the top line is hidden below 768 px).

Out: the file-access of a chat I cannot see (its 404 stays), a link pasted outside any chat or room (no ask: anyone
could probe paths; the plain line only).

## Steps

1. `server/src/files/linked-file-ask.ts`: the rooms' "may I ask about this linked file" check, given the person who
   linked it; rooms/file-ask.ts and chat/access-requests.ts both use it. The chat's linker: the message's sender, or
   the answer's turn person, on a message I see (not hidden from me).
2. `ChatFileAccess` gains `view`, `viewAsked` and `open`; `requestChatFile` answers `open` with an optional link.
3. Web: ChatFileAsk shows the room ask's body for `view`; every shared chat passes its id to the panel; FileMoved's
   "no" adds `preview.notFoundWho`.
4. Problem report: `previewAlso` after the box; `reportPreviewText` turns file links into names.
5. `schedulePreview` and `saveLine` take place words; the details block drops what the status line and the runs say.
6. TrashedBanner `common.undo`; `chat.inTrash` wording in 6 locales.
7. ForkedFromLine `max-md:hidden`.
