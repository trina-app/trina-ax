# Web tests: a file that leaves React's act() open fails the next file at once, naming it

- Date (UTC): 2026-11-12 01:10
- Branch: `fix/web-tests-ci-1112`
- Status: done
- Where: web tests only (`web/test/unit/preload.ts`). Why: a test-host fix (see docs/REPOSITORY-RULES.md)
- Version impact: none, tests only

## Goal

CI's "Web unit tests and build" on dev (run 43126320918, Bun 1.3.12, Linux) failed about 550 tests in 88 files
(`timed out waiting for …: <div></div>`, `null is not an object (evaluating 'e.click')`, `setLater is not a
function`). All of them came from one file, `member-welcome.test.tsx` (PR #430), which called the test host's async
`unmount()` without `await`. Two React `act()` scopes overlapped, React's act depth stayed above 0, and from then on
React kept every render in its act queue: every page mounted later in the same process stayed `<div></div>`. PR #508
added the missing `await`s. The test host still lets one such slip break every file after it, with nothing pointing
at the file that did it, and only on some machines: with Bun 1.4.4 the same leak happens to leave act() closed (a Mac
run was green), with CI's Bun 1.3.12 it does not.

## Scope

In: at the start of each test file the preload checks that no act() scope is left open. If one is, that file fails at
once with one line that names the file before it (where the scope was left), and so does every file after it (React
keeps its act depth to itself, so it cannot be put back). A test of the check in `test-file-end.test.tsx`.
Out: CI workflow and the Bun version; the server's Bun 1.3 binding bug (another branch).

## Steps

1. Reproduce: dev before #508 in Docker with CI's order, then dev now.
2. `preload.ts`: the check, and the file's path passed to the file start.
3. A unit test that shows a left-open act is caught and named, and that files start as before once it is closed.
4. Full `test:web` on Bun 1.3.12 (local and Docker in CI order) and 1.4.4; typecheck, check:i18n, check:docs, build:web.

## Risks

A false alarm would fail a green file: the check is a sync `act(() => {})`, which closes its own scope at once when
none is open (no queue left), so a clean run is unchanged. Tests only; nothing ships.
