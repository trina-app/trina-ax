# Voice input and video sound use ElevenLabs Scribe v2 by default

- Date (UTC): 2026-11-23 04:32
- Branch: `feat/speech-scribe-v2`
- Status: done
- Where: trina-ax `shared/`, `server/src/jobs/`, `server/src/credentials/`. Why: the speech request and its default
  model are in the open server (see docs/REPOSITORY-RULES.md)
- Version impact: minor. The default speech model changes for new teams and for hosted teams (a new default behavior,
  no API change)

## Goal

The owner says that Trina's speech-to-text is not as good as the speech input of other AI chat apps. The owner wants
to try ElevenLabs Scribe v2 (`elevenlabs/scribe-v2` on OpenRouter) as the default model in place of
`openai/whisper-large-v3-turbo`. Scribe v3 is not on OpenRouter yet.

## Scope

In:

- `DEFAULT_SPEECH_MODEL` becomes `elevenlabs/scribe-v2`. `HOSTED_SPEECH_MODEL` follows it.
- The OpenRouter request fits each model: the provider list in the request is the model's provider (ElevenLabs for
  `elevenlabs/*`, DeepInfra and Groq for whisper), and Scribe gets `tag_audio_events: false` (no "(laughter)" in
  dictation).
- A model that refuses `response_format: "verbose_json"` (400) gets `json` once more; the server remembers that model
  until it restarts.
- A language as an ISO 639-3 code ("kor", "eng", "ind") is read as whisper's 2-letter code.
- Tests for each item.

Out (follow-ups in the PR body):

- Voice input pieces (2.5 s, then up to 7 s) go out with no text from the pieces before them.
- The voice input hint is the app's language, not the language the person speaks.
- No `keyterms` with team words (Scribe can take them; OpenRouter passes `keyterms`).
- A benchmark on real speech with a key.
- A plan field for the hosted model, so the control plane can change it without a release.

## Steps

1. `shared/src/api/entities.ts`: the new default and the whisper model as its own constant.
2. `server/src/jobs/openrouter-stt.ts`: `speechProviders(model)`, `openRouterRouting(model)`, the ElevenLabs
   option, the `json` fallback.
3. `server/src/jobs/speech-language.ts`: ISO 639-3 codes.
4. Tests in `tests/unit/c-speech-openrouter.test.ts` and `tests/unit/speech-language.test.ts`; update tests that name
   the old default.
5. Decision file, changelog fragment.

## Decisions

- `docs/decisions/20261123-speech-scribe-v2.md`: the default speech model is ElevenLabs Scribe v2. Changes the model of
  [Voice input through OpenRouter](../../DECISIONS.md) and the hosted model of "Hosted speech-to-text".

## Risks

- **Ops order.** The hosting key's guardrail at OpenRouter allows only whisper-large-v3-turbo today. A hosted server
  with this release and the old guardrail gets every speech request refused ("Hosted transcription is not
  available"). The owner must let the guardrail allow `elevenlabs/scribe-v2` (keep whisper too) before this release
  reaches hosted servers.
- **Cost.** OpenRouter lists Scribe v2 at $0.0000611 a second of sound ($0.0037 a minute, $0.22 an hour). Whisper
  turbo is $0.00000333 a second ($0.0002 a minute, $0.012 an hour): about 18 times less. A hosted team that uses all
  10 free hours costs about $2.20 a month instead of $0.12.
- **No whisper scores.** Scribe gives no `avg_logprob` or `no_speech_prob`. The whisper checks that use them
  (`openRouterUnsure`, the long-recording language retry, the voice input hint retry) then do nothing: no second
  request, no extra cost. The sound checks (silence, weak sound) and the sound-tag filter still apply.
- **Not run live.** There was no key for a test. The request shape follows OpenRouter's STT reference. The first QA
  request on qa.trina.app with a team key must confirm the answer (text, language, segments).
- Existing teams that saved Team settings keep their saved model (whisper). Only new teams and hosted teams change.
