# Excel files made by the AI can hold a chart

- Date (UTC): 2026-11-16 05:00
- Branch: `feat/xlsx-charts`
- Status: done
- Where: server/src/tools (make_file) and shared/src/tools.ts (its input). Why: the AI makes Excel files there; a chart is part of the file it writes.
- Version impact: minor, a new make_file option the AI can use

## Goal

A person asks for "the sales sheet with a bar chart in it". Today make_file writes the table but no chart (exceljs and
SheetJS cannot write charts), so the AI says it cannot and shows a picture beside the chat instead (AI scenario check
EDIT-13). After this, the Excel file opens with a real Excel chart that follows the cells.

## Scope

In: make_file `charts` for xlsx: column, bar, line and pie charts over a range of one of the sheets it writes (first
column = labels, first row = series names). Written as DrawingML parts into the zip after exceljs writes it, with the
zip reader/writer the server already has (files/zip-write.ts). No new dependency.
Out: adding a chart to an existing workbook in place (the AI rewrites the table with make_file, as it does today for
other changes); styling options (colours, axes titles), more chart kinds.

## Steps

1. `server/src/tools/xlsx-chart.ts`: parse the range, build chartN.xml / drawingN.xml / rels, add them to the zip.
2. `MakeFileInput.charts` (xlsx only) and one short sentence in make_file's description; the result text says how many
   charts the file has.
3. Unit tests: parts present and well-formed, chart count, references and cached values, wrong ranges refused.
4. Render once with LibreOffice and look at it; re-run AI scenario cases EDIT-13 and EDIT-11.

docs/decisions/20261116-xlsx-charts.md

## Risks

A malformed part makes Excel offer to "repair" the file: the parts follow the ECMA-376 order and are checked by tests
and a LibreOffice render. No migration, no UI, no i18n.

## Tests

`bun run typecheck`, `bun run check:docs`, `bun test tests/unit/xlsx-chart.test.ts` and the make_file tests.

## Result

Built as planned: `server/src/tools/xlsx-chart.ts`, make_file `charts` (xlsx only, at most 10), one sentence in
make_file's description (~100 words with the field descriptions, ~180 tokens per turn). Rendered with LibreOffice
(column, bar, line, pie). AI scenario check: EDIT-13 fail (first run) -> pass twice (1 chart each run); EDIT-11 pass,
then one jargon fail unrelated to charts ("이 도구는 ... 수정하지 못해서"), then pass. PR: PULL_REQUEST_LINK
