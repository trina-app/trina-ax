## Goal

Onboarding v6.2 (FLOW-v6 §2, §2.2, §2.5, §4.1, §4.2, §6): nothing goes into a team without a press that names it. The
owner chooses the four kept skills (회사 소개서, 카드뉴스, 홍보 영상, 자연스러운 글) on 내 스킬, and owners and admins
find the ones the team does not have in one folded line on Team skills. A skill shipped later only raises that line's
count: no notice, dot or prompt. Bringing one's own skills (Claude Code, Codex) stays, moved under the rows, and its
AI check really ends after 30 seconds (walk review MUST 2).

## Scope

In:
- `GET /api/onboarding/packs` (owners, admins): each kept skill with its title, one line, whether the team has it (by
  path or skill name, as `placeSkill` decides), its example (an image or a short text, or none yet) and its source.
- `POST /api/onboarding/packs/:id/install` takes an optional `skills` list. An install of the visual skills runs a hook
  first (the brand action of §1A registers there); an owner's install records 내 스킬 done like a share does.
- `POST /api/skill-shares/:id/stop-check` (the proposer): ends a running AI check (`ai: failed`, `status: ready`).
- Team skills: the fold "트리나가 준비한 스킬 · N개 더" (owners, admins; nothing pre-checked; [팀에 넣기 · n개]; hidden
  while searching, absent when nothing is missing), replacing the empty page's button. "내 스킬 가져오기" for everyone on
  a computer (owners and admins: a sheet that applies; members: `ContributeSheet`); on a phone one plain line.
- 내 스킬 (O3): the rows, pre-checked from the company profile; bring-your-own below with a secondary folder button;
  one primary that names what goes in; the order on press and the notes of §2.5; the 30-second stop; the phone variant.
- The example viewer: one dialog (a sheet on phones), ‹ › between rows, the fictional-company line and the source line;
  a placeholder until the examples exist (EXAMPLES-PLAN.md) and an error state.
- i18n in five languages, DECISIONS "W6", the API reference, unit and e2e tests.

Out (other v6 parts): the brand action itself, `setupWelcomeTeam` without the pack, the end screen's first result, 팀
파일, 도구 연결, the handover, the member suggestion's new trigger, the desktop folder window, the example files.
