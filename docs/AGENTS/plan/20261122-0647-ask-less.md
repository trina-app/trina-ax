## Goal

The ask audit (QA TC-ask1-12..19, TC-cards-6/8) found questions and notices nobody needs. Claude Code acts on a clear
request and says afterwards what it assumed; Trina asked first in about 5 of 12 clear "make" requests, repeated its own

## Scope

In, by priority:

1. **Act, then say what was assumed** (TC-ask1-12, TC-cards-6). One general line in the turn rules, every turn that
   has `ask_user`, placed with ASK_USER_RULE (ACT_FIRST_RULE, about 70 tokens): a request clear enough to act on is
   done at once with sensible defaults or a sample; the answer then says in one line what was assumed and any tool
   limit ("the video tool makes 18.5 s videos, so this one is 18.5 s"). Ask first only when a choice cannot be undone,
   reaches other people, or has no reasonable default. Never ask the same question twice in a row; an answer to your
   question is acted on. It agrees with NO_INVENT_RULE (#316): defaults and samples fill the shape (length, layout,
   sections, sample rows labelled as samples), never facts; a price, rate, date or name nobody gave stays a visible
   blank (`[rate?]`). The rule names that split in one clause, so neither rule reads as "ask" for a missing fact.
   - promo_video's description: "say so before you make it … unless they say no" becomes "make it at 18.5 s and say
     so in one line after" (the root of the 18.5 s question).
   - Prompt pins: the line is in every turn with ask_user, once, under a length cap; ASK_USER_RULE and NO_INVENT_RULE
     unchanged in meaning; the promo text pinned.
2. **Share dialog notes** (TC-ask1-14).
   - The "this link is this computer's address … Admin › System › Connection" line leaves the Share dialogs'
     Copy link (components/ShareCopyLink.tsx). It is said only when a link is really copied there: the copy toast
     carries it. Admin, invites and onboarding keep LocalLinkNote (they are where a link is handed out).

4. **One place for a waiting question** (TC-ask1-18, -19).

5. **Move and send cards** (TC-cards-8).

## Decisions

docs/decisions/20261122-ask-less.md: act on a clear request with defaults or a sample and say what was assumed;
ask only for irreversible choices, ones reaching other people, or no reasonable default; never the same question
twice. Facts nobody gave stay blanks (NO_INVENT_RULE unchanged).

## Risks

- Acting without asking could make the wrong thing: it is limited to undoable work in the user's own place; anything
  that reaches other people keeps its card.
- Stop sharing in one press: Undo is there; the server already checks the creator.
- Trash without a question only in the person's own folder (Undo, trash kept).
- Five languages + id for every new string; phone and desktop for every screen change.
- No migration.
