## Goal

One card per answer per kind on the real engine, Undo visible the moment a no-card send lands, no English working lines in a Korean answer.

## Scope

In: the group key of file-tool cards, the lean card for skill saves, a short gathering wait on deferred cards, one undo window hook for the post and share cards, own-language names in the language check.
Out: the phone app's grouped card (left out by #431).

## Steps

1. File-tool calls carry their tool name into the card (the group key); skill saves use the lean card.
2. Deferred cards of a running answer gather before they can be pressed.
3. PostedCard and ShareCard share one undo window that starts when the step ends and counts down.
4. Naming the answer's own language is not asking for another one.
5. Tests, gate, real replay, proxy check.

## Decisions

docs/decisions/20261123-cards-gather.md. The language check is narrowed, not changed: docs/decisions/20261122-interim-text-not-answer.md still holds, and English chats are unchanged.

## Result

Real run on a private managed-mode copy with Claude Code: 3 skills gave one card and one press saved all 3; a named post showed Undo at once, counted down, and Undo removed it for the recipient; the chat and a make_file PDF went through the model proxy.
