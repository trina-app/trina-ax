# The AI finds files people sent in their conversations

- Date (UTC): 2026-11-17 12:00
- Branch: `feat/chat-file-find`
- Status: in progress
- Where: trina-ax `server/src/rooms/reader.ts` (the person's view of their rooms), `server/src/chat/room-tools.ts`,
  `shared/src/tools.ts` (the `rooms` tool's input), `server/src/connectors/remote-mcp/rooms.ts` (the same search for an
  AI app). Why: room reading is Team AX core (chat, rooms, files), and the search already lives there.
- Version impact: patch, a user-visible change to what the AI finds in conversations.

## Goal

Owner 2026-11-17: "can Trina find files from things I sent, or from my conversations, and answer with them?" e.g. "the
business registration PDF I sent Kanghyun", "the account form I sent in the leads thread". People often send a file
with no words, so a search of the message words alone misses it.

## Scope

In:
- `rooms` search matches the names of the files sent with a message, not only its words (each word: in the text or in
  a file name; a few file-type words such as "엑셀"/"excel"/"pdf" match the file's type).
- New `rooms` filters: `from_me` (messages the user sent), `with_person` (only rooms that person is in, their 1:1 chat
  included), `files` (only messages that carry files). Any of them makes it a search.
- Search results already give each file's name, type, size and file_id with its room_id and thread; the tool text says
  so, so the AI goes straight to `room_file`.
- Tool descriptions: `room_file` reads files of thread replies too; to fill in, stamp or edit a room file, save a copy
  with `save_room_file` first (no save_as: the user's own downloads, no card), then use the file tools on the copy.

Out:
- Searching inside the files' contents (only names).
- Any new place the tools are offered (still the person's own unshared chat and the AI app connection).

## Rules kept

- Only rooms the person is in, only messages they can see (SEE_SQL, the same as room_read). A `with_person` name
  narrows the person's own rooms by their members, which the person already sees in each room.
- Every room whose message a result shows joins the chat's read scope (the wider-audience warning when the chat is
  later shared), the chat is marked (cards for changes), the audit line names nothing.
- Bounded output as before (limit, ROOM_READ_CHARS, the scan budget).
