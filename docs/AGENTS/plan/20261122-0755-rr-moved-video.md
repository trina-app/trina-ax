## Goal

Root causes found in real claude-code runs (tool events on the QA server):
- S-018: the AI remakes a picture with box_shell, not with an AI file tool, so #334's "not found" notes never fired.
  - box_shell's "changed by other people" note showed the move's first half as `delete`, so the AI said 박준호 deleted the file.
  - The remade poster was copied to the old place, which made a NEW file. A copy could never replace the moved file:
    copy_files always made "(2)", and the AI said "an image cannot be overwritten in place".
- S-007: the video is the promo_video artifact, not a chat file.
  - Each edit rebuilt all the slots from nothing, so the look changed.
  - The tool had no way to read an earlier version, so "go back to Junho's version" could not be done.
  - There was no music-off choice.

## Steps

1. track.ts / tool.ts:
   - A move shows as `moved <old> to <new> (moved, not deleted)`. The new place is named only when the person may open
     it and everyone in the chat may read it.
   - After a command, a file made at a moved file's old place is called NEW, with where the moved file is.
2. copy_files onto a file of that name that the AI read in this answer saves a new version of it. A change since the read
   keeps both files, and the result says so.
3. make_file and copies out of the work folder (in a turn) to a moved file's old place: the save is refused the first
   time with where the file is now. A second call makes the new file.
4. promo_video_versions (read only):
   - It lists the versions with who asked for each, and gives one version's exact slots.
   - promo_video with exactly an earlier version's slots brings that version back as it was checked then.
   - Music `none` makes a silent video.
5. Prompt and tool text, plus tests. Tool lists and prompt pins are updated.

## Result

Real claude-code runs on a private QA copy (Linux container, port 19987): S-018 2/2 and S-007 2/2 pass (the PR has the logs).
Two independent reviews are done, and their findings are applied.
