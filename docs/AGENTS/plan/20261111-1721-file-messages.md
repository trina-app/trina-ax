## Goal (QA TC-230, P3)

1. B saves a text file A saved a moment before: B got two toasts with raw paths, one about B in the third person
   ("최비 님의 내용을 사본(shared/Notes/memo (충돌 사본 …).txt)으로 따로 저장했어요"). Now one notice, the folder as on
   screen (전사 공유 › Notes), in the first person for the one who saved; the others get it with the saver's name and
   a 사본 열기 button.
2. A chunked upload that reached its 7-day cap said "업로드가 만료됐어요(24시간)" although chunks arrived seconds
   before. Now the words name the limit that ended it: 24 hours with nothing arriving, or 7 days from the start (and
   a part file that is gone says the upload cannot go on).
3. ⌘K "주간" found no folder: `/api/files/find` lists files only (ripgrep --files). With `folders=1` (⌘K) it also
   returns folders whose name holds every word, among the folders the person would see in the file screen.

## Steps

1. Web: `conflictNotice.ts` (the words; this window's own save is not told twice: FilePanel marks the path before
   the save, live.ts skips the event for it). FilePanel's toast and live.ts use it. Old keys
   `preview.savedConflict` / `files.conflictNotice` replaced by two keys in five languages.
2. Server: `row()` tells the two expiries apart (`expired` 24 h idle, `expiredMax` 7 days), `uploadLost` for a
   gone part file; words in five languages.
3. Server: `findFolders` walks folders (async readdir, the ones `siblingVisible` shows, at most 20,000), only when
   asked; folders first in the answer. ⌘K asks for them; the composer's file picker does not.

Out: `Files.tsx` list layout (another session reworks it).
