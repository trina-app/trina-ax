# Demo banner and prompt fixes from the 11-22 free-roam QA (WP5)

- Date (UTC): 2026-11-21 19:51
- Branch: `fix/demo-wp5-banner` (stacked on `fix/demo-banner-local-tool`, PR #282)
- Status: done
- Where: server (demo fakes, chat prompt), scripts/demo/steepling. Why: the demo's banner and Higgsfield fakes and
  the AI's instructions live there (see docs/REPOSITORY-RULES.md)
- Version impact: patch. Fixes to the demo's fakes and two prompt lines; no new feature, no API change.

## Goal

Free-roam demo QA on 11-22 found four things in the banner flow and the AI's words:

- F5: changing only the headline also changed the photo and shrank the title, and one word ("했어요.") was left
  alone on a line.
- F6: asked for a scene the demo has no photo for, the AI got the same prepared photo twice and two junk files.
- F1: the AI wrote a drive.google.com link for a practice Drive file, which opens Google's "file does not exist" page.
  The link itself goes away in WP3; this is the prompt line.
- F17: the AI uses tú/kamu in Spanish and Indonesian, while the app uses usted/Anda.

## Scope

In:
- `banners.ts`: only `scene` changes the photo. The first banner uses the kit's `defaultScene`, which is the launch
  banner's scene, so a words-only edit keeps the seeded photo.
- `banner.ts`: the kit's `defaultScene`. In the typst document: runt, orphan and widow costs, optimized line breaks,
  Korean breaks only between words (each word in a box, the way `word-break: keep-all` works on the web), and the
  last two words of a line kept together. The headline keeps the layout's size while it fits in three lines.
- `higgsfield.ts`: `pickPicture` returns null when no word matches. `generate_image` then answers with one line and
  the list of prepared scenes, and makes no job and no picture. If the closest photo is the one it gave last time, it
  says so and gives no second copy.
- `prompt.ts`: two lines in `DEMO_FAKES_NOTE` (Drive files have no web address; a missing scene gets a one-line answer
  with no retry). An address rule for es and id (usted, Anda) after the answer-language line.
- `kit.ts`, `make.ts`: `defaultScene: 'one-cup'` in the kit; comments.

Out:
- Re-drawing the seeded `campaign-banner.<locale>.jpg` from the kit when the snapshot is built (plan item F5 c). The
  seeded picture already uses the one-cup photo with the same words and layout. Re-drawing it would make
  `writeSteepling` async and need typst in the snapshot build (build-snapshot.ts and other packages' tests).

## Steps

1. Plan (this file) and changes note.
2. banner.ts, banners.ts, kit.ts: the photo stays, the line breaks, the headline size.
3. higgsfield.ts: no picture when nothing matches; no second copy of the same photo.
4. prompt.ts: the demo lines and the es/id address rule.
5. Tests in demo-banner, demo-fakes and b-chat.

## Decisions

- The address rule is in `answerLanguageLine`, not in `LANGUAGE`. `LANGUAGE` is also used where the AI writes in the
  person's own voice (often-asked questions, onboarding drafts), where "address the user as usted" does not fit.
- es/id formal register: owner decision 3 of the 11-22 demo QA plan. It applies to every real es/id team, not only
  the demo.

## Risks

- The register line reaches every Spanish and Indonesian team's answers (intended).
- The typst changes affect only the demo's banner kit. Korean words longer than 16 letter-widths still break inside,
  so a long word never runs off the banner.

## Tests

`bun run typecheck`, `bun run check:prepush`, `bun run check:i18n`, `tests/unit/*demo*.test.ts` (demo-banner with
typst), the prompt tests in b-chat.

## Result

Built as planned, with these differences:

- F6 test prompt: "눈 내리는 창가" shares "창가" (window) with the story photo, which is a frosted window, so that prompt
  still gets that photo once. The no-match test uses "눈 내리는 밤 거리" and "a snowy mountain cabin at night". Asking
  for "눈 내리는 창가" a second time now gets "nothing new was made; do not save it again" instead of a second copy,
  which covers what A4 saw (the same photo twice, saved twice).
- F17: the register is a separate `ADDRESS_RULE`, added to the answer-language line, not a change to `LANGUAGE`
  (see Decisions).
- F5 (c), re-drawing the seeded banner from the kit, is left out (see Scope).
- The hostile-words test in demo-banner gets a 300 s timeout: 120 typst runs take about 1.5 s each on a busy Mac.
