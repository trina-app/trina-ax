## Goal

The last eight completed runs (43750043115 … 43857031225) fail 20-23 tests each. Find each cause, fix the stale and
font-dependent tests, and write up what is left.

## Decisions

- Stale after intended changes (fixed): the used invite says why (#899), the member invite dialog is titled by its tab
  (#998), a held version's button is "Try this version again" (#1089, ed221143f), Members' "…" has the usage limit
  (#908), the photo picker's words (#998) and a room's 10 GB file limit (#1104), Notion's "Add to a conversation" line
  under its Connectors row (#1043), the phone greeting under the welcome card is for screen readers only (#929).
- Font (fixed): Folder permissions' two views are one picker row when the words do not fit half the row
  (components/ui.tsx Tabs, by design); on the CI's DejaVu Sans "What a person can open" does not fit. The four tests
  take the row or the picker (`helpers.ts` `phoneTabs`). The "no history" test compares React Router's index, as Back
  sees it: the picker's closed sheet leaves an entry ahead (history.length + 1) that Back never reaches.
- Font (fixed): Delete account's button is under the first screen on DejaVu Sans since #1060 lengthened the text; the
  test scrolls to it, as a person does.
- Font (follow-up, decided): the Feature map workflow installs Roboto (`fonts-roboto-unhinted`) and makes it
  sans-serif and system-ui (`web/test/e2e/fonts/phone-font.conf`), so phone layouts are drawn as on a phone. The copy
  is not shortened. With it the English empty-DM line fits (195 of 200 px) and Folder permissions draws its tab row in
  English at 390 px (the picker at 360 px, and in Spanish and Indonesian); `phoneTabs` stays.
- `phone-polish.spec.ts:94` still fails on Linux for Japanese: the line is 214-218 px in Hiragino Sans and Noto Sans CJK
  JP against 200 px. It passes on a Mac only because the test measures every language in the Korean page's font
  (Apple SD Gothic Neo: 189 px). Recorded in the QA sheet; the copy stays.
- Follow-up, product: the Korean "too big" line of the phone app's photo picker names the kind (이 사진은 / 이 동영상은 /
  이 파일은, `lib/preview.ts` `mediaKindOf`); the other languages start with the names and needed no change.
- Follow-up: the history entry the picker sheet leaves ahead (`history.length` + 1) is every sheet's closed entry
  (`lib/backCloses.ts`): Back never reaches it and Forward onto it returns where it was (checked). Not a bug.
