## Goal

The official Slack app "Trina AX" (#563) lets a team's owner add Slack with one button, but the docs site has no page
for it: only `docs/SLACK.md`, which is written for developers. Team owners and members need a short, friendly guide
with screenshots: how to add it, how each person links their account once, how to ask in a channel or a DM, and how to
remove or add it again.

## Scope

In:
- `docs/site/use/slack.md`, in **Use Trina AX › Work with the AI** after MCP connections: add Trina AX to Slack (the
  owner), invite it to channels, link your account once and ask (everyone), "If Add to Slack isn't there" (a server the
  hosting service does not serve: the own app, linked to `docs/SLACK.md`), "Remove or reconnect", a short FAQ.
- Screenshots from the real end-to-end run of QA TC-203, cropped to the part a step talks about (no team name, user
  name, test address or real company workspace in them), as WebP under `docs/site/images/slack/`.
- Slack in the Admin menu table on `use/admin.md`, linked to the new page.
- `changes/slack-guide.md`.

Out: new screenshots of steps that the run has no clean shot of (the private link prompt in Slack, the answer in a
channel and in a DM, the link page, the Remove dialog); re-shooting in English and the light theme like the other
pages, once a server the hosting service serves has demo data.
