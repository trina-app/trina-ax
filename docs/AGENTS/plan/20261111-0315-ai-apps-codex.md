# AI apps: Codex has its own row, and Claude Code finds its connection

- Date (UTC): 2026-11-11 03:15
- Branch: `feat/ai-apps-codex`
- Status: in progress
- Where: `web/` (Settings › AI apps, Admin › AI apps). Why: the rows and their steps are web UI only; the server
  already accepts Codex's sign-in (see docs/REPOSITORY-RULES.md)
- Version impact: minor. A new app row with its own steps is a visible UI change.

## Goal

The team wants to focus on Claude and Codex first. Today Codex shows only under "Other MCP apps", with generic steps.
Claude Code also shows under "Other MCP apps": Claude Code registers as `Claude Code (<server name>)`, and the row
matches the client name exactly, so the Claude Code row keeps "Connect" with no "✓ Connected".

After this change:
- Codex is a row of its own, with its logo and its steps: `codex mcp add <name> --url <address>`, then
  `codex mcp login <name>` if the sign-in does not open by itself.
- A connection whose client name is the app name, or the app name and ` (…)`, belongs to that app's row. So
  `Claude Code (trina-ax)` is Claude Code, and `Codex` is Codex.
- "Other MCP apps" stays as it is, for every other app.

## Scope

In: `AI_APPS` gets Codex; `connectedTo` matches `<name>` and `<name> (…)`; the Codex dialog steps; the Codex logo and
its notice row; the five app languages; unit and e2e tests; the user guide; a changelog fragment.

Out (later): a compact "Connected apps" list (logos, shorter scope lines, Reconnect); accepting more sign-in callbacks
on the server (Cursor, Antigravity, Kiro and other VS Code based apps).

## Steps

1. `web/src/lib/connectors.ts`: add `{ id: 'codex', name: 'Codex', logo: 'codex.svg' }` before `other`.

5. Tests: `web/test/unit/ai-app-connected.test.ts`, `web/test/e2e/ai-apps.spec.ts`; the logo test reads `AI_APPS`.
6. Docs: `docs/site/agents/mcp-connector.md`; `changes/ai-apps-codex.md`.

## Risks

No migration, no server change, no API change. The new match must not put `Claude Code (…)` under Claude: the match
is the whole name, or the name followed by ` (`. Five languages. Phone width: the row already truncates.
