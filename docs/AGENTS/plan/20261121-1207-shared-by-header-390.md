# A phone's chat header gives the "Shared by" line room

- Date (UTC): 2026-11-21 12:07
- Branch: `fix/shared-by-header-390`
- Status: in progress
- Where: web/ (chat header). Why: QA on qa.trina.app at 390 px: in a chat shared with people, the recipient's phone
  header squeezes the title and "Shared by {name}" into the 48px bar, so the line almost touches the title and the
  bar's bottom border, light and dark (follow-up to PR #208, plan 20261121-0510-shared-chat-header-sharer.md)
- Version impact: patch, a layout fix on an existing screen with no new API

## Goal

On a phone, a chat shared with me by someone else has a 56px header: the title, then "Shared by {name}" with at least
4px between the title and the line and between the line and the bottom border. Every other header stays 48px.

## Scope

In:
- web/src/pages/Chat.tsx: the bar is `h-14` (56px) when the sharer line shows on a phone, `h-12` otherwise.
- web/src/components/TitleMenu.tsx (via ChatTitleMenu.tsx): a `compact` look for the two-line state, the name button
  `py-0.5` instead of `min-h-11`, with `touch-hit` so it still takes taps from a 44px box.
- web/src/components/chat/SharedChat.tsx: the line sits under the title with `mt-1` (spacing-1, 4px) instead of
  overlapping the title button's padding (`-mt-3`).

Out:
- Computers: unchanged (the line stays in the title's row).
- Room, thread and side-chat headers.

## Steps

1. TitleMenu `compact` prop, passed by ChatTitleMenu.
2. Chat.tsx: h-14 and compact title when `sharedBy && phone`.
3. SharedByLine `line`: `mt-1`, no negative margin.
4. e2e web/test/e2e/shared-chat-header-sharer.spec.ts: at 390 the recipient's bar is 56px, gaps title → line and line
   → border at least 4px, messages start below the bar; every other header stays 48px; the tap on the line still opens
   the title's menu.
5. changes/shared-by-header-390.md.

## Decisions

none

## Risks

The bar is a flex item above the scroller (no sticky offset), so a taller bar only shortens the message list. The
title's tap target stays 44px through `touch-hit`.
