## Goal

Four things the batch 4 smoke run still showed wrong on screen:

1. A guest of a project is counted in a project chat's "N명이 이 채팅을 볼 수 있어요" and shown in its header faces,
   but a guest opens no shared chat but their own ("Guests: only what they were invited to"). Opening the chat shows
   "이 채팅을 열 수 없어요" with "링크를 보낸 사람에게 나와 공유해 달라고" (impossible for a guest) and "트리나에게 묻기"
   even when the guest has no AI.
2. S-118 (TC-b3s-20/22, TC-b4s r118): after 박준호 left 영업 the AI still says it "couldn't find" the folder. Cause:
   the lost-access fact (#389/#408 `lostAccessFor`) only knows places this person's own answers *read earlier in this
   chat*. In the smoke run the chat was shared from the start, so the first answer never read `groups/영업`; the later
   globs in `shared`/`groups/마케팅` and `list groups` had nothing to report.
3. Step lines still show developer words: a page's key ("화면 보기 · year-end-party"), a regex in a search
   ("내용 검색 \"A형.{0,40}(원|단가|가격)\""), a glob's place before its name so the place is never worded
   ("파일 찾기 · shared · \"단가표\"", "· groups/마케팅 ·", "· projects ·"), and the top folders `groups`/`projects` alone.
4. TC-f2-d03: after 버전 기록 › 되돌리기 on the Files screen, the open preview keeps the old content until a reload.

## Scope

In:
1. Server `sharedOf` (project chat): `audience` = `Audiences.ofChat` (no guest but the chat's own creator), as cards
   and notices already count. `Project.chatAudience` (new optional field): how many would see a new shared chat of
   this viewer (non-guests, plus the viewer when a guest); the new-chat box and its upload line use it. Web chat header
   faces leave out guests (but the chat's creator). The not-found page for a guest: a guest line ("게스트는 초대받은
   곳만 열 수 있어요 …") in place of "ask them to share it with me", and no "트리나에게 묻기" when the guest has no AI.
2. `lostAccessFor`: a second source of lost places: folders a group rule opens for a group this person left in the
   last 30 days (`group_member_since.left_at`, not back in it), that they can no longer read, and whose name the person
   wrote in one of their own messages in this chat (so the answer reveals nothing new, also in a shared chat). Any
   search, listing, refused search or "not found or no access" in the turn then gets the fact once (own words: "was in
   the group, access ended, who can give it again"; in a shared chat only "cannot be opened from this chat now").
   Sub-agent calls get it too (the same `withLost`/`afterFileTool` paths).
3. Step words: artifact steps show the page's title (from the newest version in this chat when the call names only a
   key), never a slug key; grep patterns in words (alternatives "A, B", regex tokens left out); glob line puts the place
   last ("파일 찾기 \"단가표\" · 전사 공유") so `stepPlace` words it; glob alternatives "a, b"; `placeName` words
   `groups`, `projects`, `skills` and `projects/<name>/…`. All 6 languages use the existing TOP_FOLDER_LABELS.
4. FilePanel (team file): reads the file again on a `files.changed` for its path (not while editing); the history
   dialog's restore also emits the change locally so the preview updates without waiting for the socket.

Out: per-version preview in the history dialog and the "이전 버전으로 되돌림" label wording (TC-f2-d03's other two
points); the admin dialog note (TC-7438, already has a line).
