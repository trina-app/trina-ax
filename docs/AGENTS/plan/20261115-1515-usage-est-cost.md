# Usage "Est. cost" is never a flat $0 (QA TC-3143)

- Date (UTC): 2026-11-15 15:15
- Branch: `fix/usage-est-cost`
- Status: done
- Where: trina-ax core, `server/src/credentials`, `server/src/admin`, `web/src`. Why: usage and AI connections are core.
- Version impact: patch, a usage display fix with one added column

## Goal

Admin › Usage and Settings › Usage show "Est. cost $0.00" for teams on a managed subscription connection (Claude
sign-in, ChatGPT sign-in). The proxy records subscription requests at 0 on purpose (D16: no per-request price, budgets
count only money spent), so the estimate tile shows 0 although tokens were used. Codex on a local login reports no
cost either and is recorded as 0 without being marked unpriced.

## Scope

In:
- `turns.est_cost_usd`: the API list-price estimate of a turn's subscription requests, priced per request by the
  proxy (with the cache split), kept apart from `cost_usd` so budgets and connection limits do not change.
- The usage screens show `cost_usd + est_cost_usd`, count `estimatedTurns`, and say "estimated at API prices".
- Unpriced: a turn with tokens and no amount (old subscription rows, Codex local login, provider without price)
  counts as unpriced on read; the tile shows "No price" instead of $0 when nothing is priced.
- Price table: add Claude Fable 5.2 / Mythos 5.2.
Out: budgets in USD for subscriptions (still 0), re-pricing old rows (their per-request cache split is gone).

## Steps

1. Migration 406_b_turn_estimated_cost.sql.
2. prices.ts `estimateOf`; broker.record writes the estimate.
3. Codex parser marks its usage costUnknown.
4. One SQL amount fragment for my-usage and admin usage; schemas get `estimatedTurns`.
5. UI tiles and notes, six languages; unit tests; changelog fragment.

## Risks

Migration number 406 (B range) may race another PR. Budgets read `cost_usd` only, unchanged.

## Result

Root cause: the proxy prices subscription requests (anthropic-oauth, chatgpt) at 0 by design (D16), and the usage
screens showed that 0 as "Est. cost"; Codex on a local login reports no cost and was stored as 0 without being marked
unpriced. Now the proxy also writes the API list-price estimate to `turns.est_cost_usd` (migration 406), the screens
show cost + estimate with a note "estimated at API prices, not a bill", and turns with tokens but no amount count as
unpriced ("No price" instead of $0). Budgets still read `cost_usd` only. Old subscription rows are not re-priced: the
turn row keeps only summed tokens, without the cache split that makes up most of a Claude Code turn, so a guess
would be several times too high; they show as "no price" instead.
