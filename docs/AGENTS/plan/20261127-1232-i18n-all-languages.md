# Language audit: every language, every kind of wrong-language text

- Date (UTC): 2026-11-27 12:32
- Branch: `fix/i18n-all-languages` (on #696 `fix/id-korean-leaks`, merged in first)
- Status: in progress
- Where: web, mobile, desktop, server, tests. Why: the owner asked whether the Korean-in-Indonesian audit covered every
  language ("한글 뿐만아니라 모든 언어 문제가 들어간거지?"); it did not.
- Version impact: patch, fixes of texts shown in the wrong language and new guard tests; no new feature or API change.

## Goal

A person on any of the six languages (en, ko, id, ja, es, zh) sees only their language: no English that skipped
translation, no Korean, no date or number in another language's format. New wrong-language text fails a test.

## Scope

In:
1. The real list of languages and which surfaces have all six (web, desktop shell, phone app, server messages, push,
   e-mail texts, relay pages).
2. Literal screen text that skips t(): a static scan (JSX text, aria-label / title / placeholder / alt / label,
   toast/confirm text) of the web and phone apps, and of API refusals (fail() / new HttpError()) on the server. Fix what
   it finds, and a guard test for each with an allowlist and reasons.
3. Translations still equal to English: list per language, translate the ones that are not loanwords, and a guard test
   with the list of words that are the same in that language.
4. Formatting: dates, times, numbers, plurals, relative times, currency through the person's language.
5. AI and server text: instructions that name one language, default names of system rooms, folders, sections.
6. A live walk in ko, id, ja, es and zh at 390 and 1440 on a private local copy with test data; screenshots of any
   wrong-language text.

Out: Trina Cloud's console pages and the ax.trina.app site (other repositories; a separate task fixes Trina Cloud's
Korean default for new teams). The office Mac's update CLI (an operator's terminal, Korean and English by design).

## Steps

1. Scan scripts (scratchpad), then fix: server refusals into a six-language table (`server/src/http/route-messages.ts`)
   with the caller's locale; skill move refusals into `skills/text.ts`; the few untranslated values; the archive folder
   rule names all six; the thread reply counter and the browser pane title in the app's language.
2. Guards: `tests/unit/no-untranslated-literals.test.ts`, `tests/unit/no-english-server-messages.test.ts`,
   `tests/unit/i18n-still-english.test.ts`.
3. Live walk; fix what it finds.
