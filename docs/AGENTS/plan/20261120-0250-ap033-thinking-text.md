# Keep the AI's thinking text on its "Thinking" step (QA AP-033)

- Date (UTC): 2026-11-20 02:50
- Branch: `ap033-thinking-text`
- Status: in progress
- Where: server (chat turn), web (chat steps). Why: the server drops the text, the web app shows the steps.
- Version impact: minor. A new visible feature (the thinking text under the "Thinking" step); no API break, no
  migration.

## Goal

AI parity QA 2026-11-19, AP-033: claude.ai shows the model's thinking text. Trina shows a "Thinking" step with no
text: `server/src/chat/turn.ts` drops the `thinking` deltas. After this change the person sees what the engine
thought, under the "Thinking" step, closed until they click it. The text stays after a reload.

## Scope

In:
- Keep the thinking deltas of each thinking step. Write them on the step (`Step.detail`) when the step closes, through
  `updateStep`, so the connection-secret redaction (`redact.ts`) applies to the whole text and the 4000-character cap
  applies after the redaction.
- Web: a thinking step with text is a row that opens on click (closed by default) and shows the text.
- Shared chats: only the person whose turn it was sees the text (`viewSteps` already strips `detail` for the others).

Out:
- No per-message "extended thinking" toggle and no thinking budget change. We show only what the engine returns now.
  The toggle is a separate owner decision (cost, latency).
- Phone app: it has no step view (`mobile/src` shows no steps), so no change there.
- A sub-agent's thinking stays dropped (docs/DECISIONS.md "Sub-agents").

## Steps

1. `turn.ts`: a raw buffer per thinking step; `closeThinking` writes it as the step's `detail`.
2. `Steps.tsx`: a test id and an accessible name for the thinking row; i18n key in every locale.
3. Fake engine: `@fake {"think": "..."}` sends main-session `thinking_delta` stream events.
4. Unit test (server): text kept after reload, a stored connection secret hidden, an empty think adds no text.
5. Web test: the row is closed by default and opens on click.
6. Decision file, changelog fragment.

## Decisions

`docs/decisions/20261120-ap033-thinking-text.md`.

## Risks

- Privacy: thinking can quote file text. Redaction as for step details; in a shared chat only the runner sees it.
- Size: the step detail cap (4000 characters) cuts long thinking. Accepted for now.
