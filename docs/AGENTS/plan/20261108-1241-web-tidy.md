# Web tidy-ups from a design audit: one name for AI chats, one row menu, rename in a room's "⋯", leftovers

- Date (UTC): 2026-11-08 12:41
- Branch: `chore/web-tidy`
- Status: done
- Where: trina-ax core (`web/src/i18n/`, `web/src/components/Sidebar.tsx`, `web/src/components/rooms/RoomMenu.tsx`,
  `web/src/components/rooms/MembersDialog.tsx`, `web/src/pages/Projects.tsx`, `web/src/components/settings/SettingsDialog.tsx`,
  `web/src/pages/ConnectorConnections.tsx`). Why: chats, rooms and settings screens are core (see docs/REPOSITORY-RULES.md).
- Version impact: patch. Wording, one menu component and dead code; no API or data change.

## Goal

A design audit of dev found loose ends:

1. The Korean screens call the AI conversations different things: the sidebar says "트리나 기록" and "삭제한 기록", the
   project page says "채팅", other lines say "채팅". The owner chose **기록**. Admin's audit log is also called "기록",
   which reads like chat history. Confidential mode stays "기밀 대화" (the owner: "기밀 기록" sounds odd).
2. Sidebar chat rows have a hand-made popover; room rows use the shared menu (right-click, long press, a sheet on a
   phone).
3. A room's "⋯" has no 이름 바꾸기 (only a tap on the title finds it), and 대화방 나가기 is both in the "⋯" and in the room's
   info.
4. Dead code: `pages/ConnectorConnections.tsx`, the removed `integrations` section in the Settings dialog, and i18n keys
   no screen uses.

## Scope

In:
- Korean: the project page's list heading reads "{name} 기록" (the sidebar's own message); lines that name the list or a
  past conversation say 기록; "기밀 채팅" → "기밀 대화"; admin "기록" → "활동 로그" with the lines that name that log.
  Other languages only where they have the same mismatch.
- Chat rows use `MenuButton` (the rooms' row menu): same items (이름 바꾸기, 프로젝트로 옮기기…, 삭제), right-click, a long
  press and a sheet on a phone. The hand-made popover goes.
- A room's "⋯" gets 이름 바꾸기 where `Room.canRename`, the info dialog's own name form in a small dialog. The info
  dialog's 대화방 나가기 goes (the "⋯" in the header has it).
- Delete `ConnectorConnections.tsx` and its strings; drop `integrations` from the dialog's section sets; remove i18n
  keys no code uses in any of the 5 languages (keys built in templates stay).

Out: the chat delete confirm (`chat.deleteTitle`, `chat.deleteBody`, `chat.deleted`), the project delete confirm and the
trash list while another branch (`fix/shared-chat-trash-live`) changes them. Rooms keep the name 대화.

## Steps

1. Plan (this file).
2. i18n wording (ko first), the project page heading.
3. Sidebar chat rows on `MenuButton`; `useRowMenu` for right-click and long press.
4. `RoomMenu`: 이름 바꾸기; `MembersDialog`: no 나가기; its name form reused.
5. Dead code and unused keys (a script lists keys with no literal use; template-built keys are kept).
6. Tests, docs, DECISIONS entry, CHANGELOG line.

## Risks

No migration. Five languages: removing keys must keep `bun run check:i18n` at 0. Keys built in templates
(`${k}.offTitle` in KnowledgeGraph.tsx) look unused to a plain search. Phone: a long press must not start text
selection. Specs that assert old strings.

## Tests

`bun run typecheck`, `bun run check:i18n`, `bun run check:docs`, `bun run test:web`, `bun run build:web`, the full web
e2e, screenshots of the project page and the room "⋯" at 1440 and 390, light.

## Result

Built as planned, with these differences:
- The project page's heading uses the sidebar's own message (`sidebar.aiChats`) instead of a second key, so it changed
  in every language ("Trina history" and so on); `projects.myChats` is gone.
- Other languages changed where they named one place two ways: the trash setting row now uses the trash page's name
  (en, id, ja, es), and Japanese's activity-log setting uses the page's 操作ログ.
- 이름 바꾸기 opens the shared rename prompt (`promptDialog`, with `placeholder`, `allowEmpty` and `maxLength` added)
  rather than the info dialog's own field in a dialog: a dialog opened from a row is a portal whose pointer and
  right-click events reach the row's long-press and right-click handlers.
- The server's one share refusal that said 기밀 채팅 changed too; other server messages keep their words.
- After review, lines where 기록 read like "the log" (restore, export, Drive sharing) or described a chat that goes on
  (the access change lines, the footer, the skill form) went back to 채팅.
- MenuButton: a click right after a long press no longer closes the menu, and the menu is as wide as its words.
- `fix/shared-chat-trash-live` (#217) merged first; after the rebase the chat and project delete confirms say 기록 too
  (공유 채팅 stays).
- Not changed: on a phone, Settings › Connectors shows its name in the bar and again on the page (the removed
  `integrations` entry once kept the bar on "설정"); left for the owner.
