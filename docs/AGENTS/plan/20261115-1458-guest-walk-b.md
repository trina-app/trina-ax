# Guests in Admin, and one name for each thing (guest walkthrough, part B)

- Date (UTC): 2026-11-15 14:58
- Branch: `fix/guest-walk-b`
- Status: in progress
- Where: Team AX core (web/src/pages/admin, server/src/auth/guests.ts, web/src/i18n, docs/site). Why: Admin and the
  app's words are core (see docs/REPOSITORY-RULES.md)
- Version impact: patch, words and an Admin card; one optional API field (User.guest.leftThemselves) and one additive column

## Goal

The independent guest walkthrough (11-15) found guests hard to find in Admin, guests who left listed as removed, and
one thing called by five names. Admins should find guests in one tap and read the true state of each one; every
screen should call a group chat, a guest, a team member and the owner by one name.

## Scope

In:
- S2: Admin Home gets a Guests card ("Guests 1/3", the names) that opens Members filtered to guests (?role=guest). The
  Members card counts team members only. No sidebar item (it would point at the same page as Members: not lean).
- S3: a guest who left on their own reads "Left" (나간 게스트), one taken out reads "Removed" (내보낸 게스트). The server
  says which (User.guest.leftThemselves, from guests.left_at). The guest's leave dialog no
  longer says the account is deleted: it is switched off, and Admin still lists it.
- S4: a guest whose project is in the trash stays in the active list with "Restore project", not behind "Show removed".
- N1: Admin's button is "Invite people" (사람 초대); its dialog is titled by what is picked: "Invite a team member" / "Invite a guest".
- N2: the Guests heading's count is "1/3", not "Guests 1/3" under "Guests".
- N4: no unresolved Korean particle after a name the app cannot read aloud ("'QA-Budget Review'을(를)"): the texts
  with a user-typed name put the particle after a fixed word instead ("'…' 프로젝트를").
- N5: one AI notice sentence ("중요한 내용은 확인해 주세요", as every other chat).
- N6: a group chat's manager is "대화 관리자" / "Chat manager".
- Naming: group chat = 그룹 대화 / group chat; any conversation = 대화 / conversation; 게스트 never 손님; 팀원 for
  someone who is or becomes a team member; 팀장 never 소유자; 초대하기 split into 팀원 초대 / 게스트 초대 /
  그룹 대화에 추가. All six app languages, docs/site and the zh docs.

Out: the guest's own screens, the invite page, links and the guest cap (fix/guest-walk-a).
