# The AI knows where things are in its own app

- Date (UTC): 2026-11-16 05:06
- Branch: `feat/ai-app-map`
- Status: done
- Where: server/src/chat/. Why: the instructions the AI gets each turn are built there (prompt.ts, situation.ts).
- Version impact: patch, the AI's answers change; no screen, API or data changes.

## Goal

Asked "where do I …" or "can I …", the AI hedges ("if there is such a setting"), sends people to an admin, or says a
feature does not exist (AI scenario check, first run 2026-11-16, root cause #2, about 15 cases: room apps, Always
allow, the Trina AX MCP, guest AI, usage and limits, time zone, voice input, notifications, the apps and version,
System, chat rename/folders/regenerate, handover and find work files, skill packs, bringing one's own skills, AI
providers and model, the dev environment). The AI gets a short map of the app's screens with their real labels in the
person's language.

## Scope

In:
- `server/src/chat/app-map.ts`: a short "Where things are in the app" section, one line per place, labels taken from
  the web app's i18n keys (and one server card label). Role-aware (a member gets one line for all of Admin),
  install-aware (guest AI only on managed installs, the dev environment only where the server has it). No map for
  guests.
- `server/src/chat/app-map-labels.ts`: the labels, generated from web/src/i18n by `scripts/app-map-labels.ts`; a unit
  test fails when a key disappears or its text changes, and when a referenced Settings tab, Admin page, Team settings
  group or System group is gone.
- prompt.ts: the new section `appMap` (in shared chats too: app facts, the same for everyone; members' short form is
  never used there).
- Decision file, changes fragment.

Out: the no-jargon rule (#1057), skill moves between groups (SKL-08), a `where_is` tool (only if the map does not fit).

## Steps

1. Map module + generated labels + generator script.
2. Wire into prompt.ts and turn.ts; SHARED_PROMPT_SECTIONS entry.
3. Unit tests: labels current, places exist, role/install variants, token size.
4. Re-run the 16 scenario cases in a combined worktree; before/after.

docs/decisions/20261116-ai-app-map.md.

## Risks

Prompt size (every turn): kept to about 25 lines, measured. Labels drift: the test. Role leak in shared chats: the
shared form is the role-neutral one.

## Tests

tests/unit/ai-app-map.test.ts; ai-situation, b-shared-chats, i18n-languages; scenario cases.

## Result

- Map in server/src/chat/app-map.ts, labels generated into app-map-labels.ts, checked by tests/unit/ai-app-map.test.ts.
- Cost: about 900 tokens (owner/admin, Korean), 620 (member), measured with the engine. No `where_is` tool (decision file).
- Scenario re-run of the 16 cases: 0/16 before (first run), 11/16 after, twice. The 5 left are judge disagreements
  (the real paths, which the judge does not know), the time zone claim (root cause #3) and English skill ids (#1).
