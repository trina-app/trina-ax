## Goal

- TC-5088: `stamp_pdf` refused `page: "1"` with "Invalid input: page". A numeric text is the number; the other PDF tools take the same rule where a page number or list is written (`edit_pdf` stamp_image page and insert_pdf after, a bare number as a page list, `split_pdf` every).
- TC-5089: a room's own box cut a 60,000-character paste to 10,000 without a word (the textarea's maxLength). The server takes 10,000 (`ROOM_MESSAGE_MAX`), so the paste becomes `Pasted text.txt` as in the AI chat boxes (batch 2, #1325), through the same helper.
