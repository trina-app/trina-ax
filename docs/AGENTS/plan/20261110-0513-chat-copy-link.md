# Copy a link to an AI chat

- Date (UTC): 2026-11-10 05:13
- Branch: `feat/chat-copy-link`
- Status: in progress
- Where: trina-ax/web (chat header, history row menus, i18n). Why: web chat screens are core UI (see docs/REPOSITORY-RULES.md)
- Version impact: patch, a small copy-only action with no server or data change

## Goal

The owner wants to tell teammates "I'm working here" with a link to an AI chat. Rooms and projects already have "링크 복사";
AI chats do not. Add it to the chat header's "⋯" menu and to the "Trina history" row menus (sidebar, search row menu, and
a new "⋯" on a project page's chat rows, copy only). The text copied is the chat's in-app address (`<origin>/c/<id>`) and
nothing else. The toast says who can open it: a shared project chat "프로젝트 사람 N명이 열 수 있어요", a private chat
"나만 열 수 있어요".

## Scope

In: the menu item and toast in five languages; a `chatLink` helper; web unit tests; one e2e spec (a member opens the link,
a non-member gets the existing not-found page).
Out: share settings, public links, any change to who sees a chat, server changes.

Checked and unchanged: the route `/c/:chatId`; a signed-out visit goes to `/login?next=<path+search>` and returns
(App.tsx); a chat that is missing or not visible shows the same not-found page (the server answers 404 for both, no
oracle); room links already open inside the desktop app as in-app paths (only the app's own origin is allowed), a chat
link has the same shape.
