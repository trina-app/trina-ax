## Goal

- TRINA-24: an ask_user card of the AI showed its own text box while the message box also answered the question (two
  boxes, the secrets line twice). One place to type.
- CHATS-17: a room's side chat showed tap icons under messages while room messages use a long press. Same pattern.
- Android Back with a phone menu sheet open: already done by open PR #452 (`MenuButton` calls its overlay hook). Not
  touched here.

## Scope

In:
- docs/DECISIONS.md "The message box answers the AI's open question" keeps the message box as the typed answer. So the
  card the box answers (`BoxAnswers` context from the full chat and the side chat) drops its own text box and secrets
  line and says "Or type your own answer in the message box below". Options, [답하기] and [건너뛰기] stay. Cards no
  box answers (a room's AI status, Settings, a read-only or trashed chat, a server check) keep their box.
- Side chat panel on phones (`pressMenu`): copy, retry, edit and the model go into a long-press sheet (MenuButton, as a
  room message). The icons are hidden from sight only (screen readers, keyboard). "스레드에/대화방에 보내기" stays a
  labelled button under each finished answer (DECISIONS "Trina side chat: send here").

Out: the full AI chat keeps its tap pattern. Back for sheets: #452.

## Steps

1. `BoxAnswers` in lib/askAnswer.ts; Chat.tsx and SideChatPanel provide it; AskCard reads it.
2. `usePhonePress` + `PressSheet` in Messages.tsx; `pressMenu` from SideChatPanel.
