# 常见问题

[English](FAQ.md) · [한국어](FAQ.ko.md) · [支持](../SUPPORT.md)

## Trina 是给开发者用的吗？

它是给团队用的公司 AI 工作空间。大家用浏览器使用；如果自己架设服务器，由 IT 负责运维。和各自单独使用的个人聊天相比，区别在于：共享的文件、可以反复使用的工作说明，以及按人设置的文件夹权限。[团队指南](for-teams.zh.md)。

## 费用是多少？

自托管的软件本身免费；服务器、运维和 AI 用量另算。Trina 托管（AWS 首尔）可以免费试用 14 天，之后按月订阅；AI 用量由你接入的账号另行计费。免费试用期间，无人使用时服务器会关闭，再次启动约需一分钟；付费订阅始终保持开启。[当前价格](https://ax.trina.app/#pricing)。

## 没有 AI 账号也能试用吗？

可以。[本地演示](QUICKSTART.zh.md)使用虚构的文件，AI 处于关闭状态。它不是正式安装，也不用来测试模型的回答。

## AI 连接是怎么运作的？

由服务器统一管理 AI 连接的安装方式（managed）可以使用获得许可的 Claude 订阅 / Anthropic API，以及 ChatGPT / OpenAI API 连接，但要看运维方的设置和服务商的条款。选用顺序是：符合条件的个人连接 → 分配给个人的连接 → 分配给小组的连接 → 全团队连接。别人的私人连接不会被选来给你用。

在新建的 Trina 团队里，默认一个公司连接可以供全团队使用，每个人也可以接入自己的连接。已经保存的选择会保留。每个连接自己的同意设置依然有效；如果这项设置原本就是开启的，新连接也同样适用。这只是软件的功能，并不代表 Anthropic 或 OpenAI 的套餐或条款允许这样做。请只使用获得授权的账号和套餐；不要以为一个人的个人订阅就能覆盖整个公司。服务商的用量限制和费用另算。

开发模式和办公室本地登录模式，使用的是服务器上那个系统用户的 CLI 登录，不会像统一管理的连接选择那样挑选连接。一条命令启动的演示会完全关闭 AI 引擎。办公室模式只支持 Claude；如果需要上面这些连接功能，请选择 Linux 上统一管理连接的安装方式。

## 管理员能看到所有内容吗？

你和 Trina 的聊天只有你自己能看到。对话（room）只有成员能看到；管理员打不开自己不在其中的对话。应用管理员没有可以浏览所有人私人聊天的界面。服务器和存储的运维人员可以读取存储的文件和聊天记录；使用托管时，也包括托管方的运维人员。被选中的上下文会发给 AI 服务商。调整权限不会收回之前已经给出的回答。[安全与权限](security-and-permissions.zh.md)。

## 支持哪些文件和设备？

文本 / Markdown，以及支持的 Office / PDF 的文字提取和生成，取决于服务器上安装了哪些转换工具。HWP/HWPX 的文字提取、搜索和原文件下载，所有团队都能用。如果安装并开启了可选的 HWP Preview 插件（管理 > 插件），AI 还可以新建 .hwpx 文档（标题作为大纲级别、段落、粗体、斜体、列表、简单表格、分页；可使用 skills/ 里的团队模板），也可以填写已有的 .hwp 或 .hwpx（edit_hwp：占位符、精确文字、空白表格单元格、照着某一行复制出新的表格行），只改动这些部分，然后以相同格式保存为新版本或新文件。没有这个插件时，AI 不会提供这两项功能。写入不使用预览渲染器，所以只要插件开着，即使在无法预览的地方也能用。它不能新建 .hwp 文件，也不会添加新的样式、图片或表格。仅供分发的文档、有密码保护或带签名的文档，以及含有宏（脚本）或 OLE 对象的文档，都不会被修改。可视化预览也来自同一个插件（从官方列表安装）；它的运行组件不包含在默认的发布包里。Debian 12 无法安装这个插件（glibc 2.36；固定版本的渲染器需要 2.39），所以 Debian 12 上既没有可视化预览，也不能写入和填写韩文文档。原文件下载和文字提取仍然可以用。详见[运行限制](../resources/hwp/README.md)（英文）。不保证复杂排版完全还原。

电脑和手机浏览器都可以用；Windows 安装程序已经发布。Mac 办公室版 ZIP 是服务器安装包，不是已发布的桌面版 DMG。iPhone 应用已在 [App Store](https://apps.apple.com/app/id6829192435) 上架；它打开的是你们团队的服务器，所以功能和那台服务器的版本一致。Android 应用正在审核中。这份源码在整个应用中支持英语、韩语、印尼语、日语、西班牙语和简体中文；已发布版本是否包含，请查看各版本的发布说明。

## 怎样把大量媒体文件放进项目？

在网页应用里上传。在“文件”里打开项目文件夹，然后用“上传文件夹”，或者直接把文件夹拖到页面上。子文件夹会保留。每次同时上传三个文件，每个文件最大 20 GB。连接中断后，大文件会从服务器已经收到的分块接着传。不需要 SSH。请在电脑浏览器里打开应用来做这件事：手机无法选择文件夹。

在这一行显示上传完成之前，请不要关闭页面。如果某个文件失败了，其他文件会继续上传，点“重试”会重新发送失败的文件。如果存储空间或服务器磁盘满了，上传会停下并提示原因。腾出空间后再点“重试”。网页无法分辨快捷方式（链接）和文件，所以选择器可能会把链接指向的文件内容一起发送。如果这会造成问题，请先删掉链接。同名文件会被改成新名字，所以同一个文件夹上传第二次会产生副本。

连接的文件夹和 Google Drive 不会把文件放进项目文件夹。连接的文件夹是服务器上某个文件夹的只读副本，位于 `connected/<name>`，每个文件最大 100 MB。Google Drive 让 AI 能读取某个人的 Drive，但不会把文件放进项目文件夹。

## 有更新和备份吗？

版本以[最新发布](https://github.com/trina-app/trina-ax/releases/latest)为准。Trina 更新源在 `https://updates.trina.app` 提供带签名的 Linux 和办公室版更新。更新前请先看发布说明并做好备份。应用回滚不等于数据回滚。[备份与恢复](BACKUP-RESTORE.md)（英文）。

## Docker、离线使用和支持？

我们不承诺提供官方的生产环境 Docker 镜像。Linux 安装需要 systemd / cgroup v2。自托管并不能让云端模型的推理离线进行。[故障排查](TROUBLESHOOTING.md)（英文）· [支持与社区](../SUPPORT.md)。
