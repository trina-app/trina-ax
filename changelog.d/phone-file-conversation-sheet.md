- On a phone, a file or photo opened from a room, a DM, a group chat or a thread now has its conversation in a sheet over it: **💬** in the top bar (with the number of replies) opens the message's thread, where you can reply, and **✦** opens your Trina side chat with the file quoted, without leaving the file. Drag the sheet's handle up for the whole screen or down to close it; Back closes the sheet first, then the file. With a file quoted in the side chat (✦ in the viewer, or **Ask Trina** in the file's preview), its box now says **이 파일에 대해 트리나에게 묻기…** instead of "about this message". On a computer, a PDF's page thumbnails show only when the space left of the thread is wide enough for them and a readable page (a 1,280 px window with the thread open shows the page wider instead), and **패널에서 열기** has its own icon (⤡) instead of a second panel icon beside the thread's toggle. No API or data change. In all five languages.
