A PDF sent in a room, a DM, a group chat or a thread is now read the way a PDF in the team folder is: pages with text as text, scanned pages as pictures, so Trina no longer asks you to save a scanned PDF to the team folder first. A long PDF is read a few pages at a time, and with image viewing off (Team settings) no page goes to the AI as a picture. Trina still reads only what you can see in that conversation, checked again just before the pages go to the AI. The app connector for AI apps reads room PDFs as text, as before. No API or data change.
