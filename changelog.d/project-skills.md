- **Project skills.** A team project in `projects/<name>/` can have skills of its own in its `skills/` folder (`<skill>/SKILL.md`). The AI uses them only in that project's chats (private, shared and scheduled), for the people who see the project; never in rooms or other chats. A project only adds new names (personal > group > team > project): the Skills page shows each project's section, **{project} 프로젝트 스킬** with "이 프로젝트 채팅에서만", and a small **같은 이름: 팀 전체** where a wider skill runs instead; the "/" menu marks them inside the project. Saving one asks on the same card, named for the project, and a name already taken elsewhere is offered another name instead of a save that would never run. Skills move between levels: **옮기기…** on the Skills page (who gains and who loses at each level, who may change it there; the whole text first when more people would get it) and the AI's new `move_skill`, which only moves a team skill to a group or a project, or a group's to a project, where nobody new reads it or may change it, after a card that lists every file. A project's first skill makes its skills folder. The file tools now tell the AI that skills do not move with files, instead of pointing at the Files screen (it once left a README as a stand-in). In a shared project chat a team skill everyone may use wins over a group's only some may, while a name the sender has a personal skill of stays theirs; a project skill never takes a name the sender already has. Sharing a personal project whose `skills/` holds skills (they are copied into its new `projects/<name>`), an admin pointing a project whose folder is gone at a `projects/<name>` with skills, and moving a project's folder into `projects/` on the Files screen ask first and name the skills. A scheduled task whose project its owner no longer sees is skipped, paused and says so once, instead of running outside the project. New: `GET /api/skills?projectId=` and `?projects=1`, `GET` / `POST /api/skills/move`, `skillsOk` on `POST /api/files/move`, `PATCH /api/projects/:id` and `POST /api/projects/:id/share`, optional fields on skills, skill changes, the save card's preview and inbox notices. Migration 279 (add-only). In all five languages.
