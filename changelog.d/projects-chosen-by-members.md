- Projects live only in `projects/`, and the people in a team choose who sees them. Any member can now make a team project (an admin can keep that to admins in Admin › Team settings › **팀원이 팀 프로젝트를 만들 수 있음**): the server makes a new `projects/<name>` folder and gives each person and group chosen, and the creator, read and write, and everyone else no access, so opening the team root to everyone does not open it. A personal project lives only in `users/<me>/projects/<name>`. The create and edit dialogs always say who can see it ("볼 수 있는 사람: 영업 부서 · 김소라 · 팀장·관리자 (9명)"); members pick people from the team list and their own groups (부서), admins any group. The creator and admins change who sees it in the edit dialog, saved like Admin › Folder permissions (a change by someone else meanwhile is refused and shown); adding people first asks once, with what they will see (files other people put there, the whole history of the project's shared chats, its project skills), and the people who already saw it are told; removing people saves at once and takes the project's shared chats away from them. Sharing a personal project makes a team project in `projects/` with the people chosen, instead of copying it into any folder. Deleting a team project can put its folder in the trash too. Removed: the **기존 폴더** kind, **프로젝트로 만들기** in Files (**프로젝트 열기** stays) and pointing a project at another folder, except an admin pointing a project whose folder is in the trash or gone at an existing `projects/<name>`. Projects made before on other folders keep working unchanged; admins see one line about them in the edit dialog. New: `GET /api/projects/:id/access`, `PUT /api/projects/:id/participants`, `POST /api/projects/access-preview`, `DELETE /api/projects/:id?trashFolder=1`, `TeamSettings.projectCreators`, `Me.team.projectCreators`; `POST /api/projects` refuses any other folder (400 `project_location`) and `POST /api/projects/:id/share` takes `participants` instead of `toParent`. Add-only migration 280 (`projects.folder_made`: only a folder the server made is its creator's to change; older projects stay the admins'). In all five languages.
