- 공유 프로젝트 채팅에 내 컴퓨터의 파일을 바로 붙일 수 있어요. In a shared project chat, and in the new-chat box of a project that shares its chats, a file from your computer (📎, a paste or a drop) is now attached in one step: it is saved in the project folder's **채팅 첨부** subfolder (named in the team's language; one already there under another language's name is used), where the project's people can open it in Files, and attached as a team file. Before, the box refused it and said to upload it to the project folder first. One line under the file says where it went and how many people see it ("프로젝트 폴더(채팅 첨부)에 저장돼요 · 프로젝트 사람 3명이 볼 수 있어요"). A name that is taken gets " (2)" and nothing is overwritten; an AI instruction file's name (CLAUDE.md, AGENTS.md, GEMINI.md, SKILL.md) is saved as "CLAUDE (2).md". It needs write access to the project folder: without it the box says so and points to **팀 파일에서 추가**. ✕ on the file before sending moves it to the team trash (restorable from Files › 휴지통). The same size and count limits and checks as any attachment apply, and it is your upload in the file's history. API: new `DELETE /api/attachments/:id`; `POST /api/uploads` and upload sessions for a shared chat answer a team-file attachment, or 403 `shared_upload_read_only`. No migration.
