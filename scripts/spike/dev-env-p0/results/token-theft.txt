Token theft probe (in-box/thief.sh): a process left in the box by an earlier command watches for the engine of a
later turn (engine IN the box, turn.sh) and tries environment, fd 3 and memory.

kernel.yama.ptrace_scope=0 (Debian default; this VM):
  environ: CLAUDE_CODE_OAUTH_TOKEN_FILE_DESCRIPTOR=3          (no token in the environment)
  fd3: cat: /proc/<pid>/fd/3: Permission denied / gone        (Claude Code reads fd 3 once and closes it)
  mem: tokens found: ['mpx_UmLx2d6G...']                      (STOLEN: full scan of /proc/<pid>/mem)
  (a first scan that only read rw regions < 256 MB found nothing; the token is in a larger region)

kernel.yama.ptrace_scope=1:
  environ: CLAUDE_CODE_OAUTH_TOKEN_FILE_DESCRIPTOR=3
  mem: refused: [Errno 13] Permission denied: '/proc/<pid>/mem'

MITM (in-box/mitm.py, mitm.txt) works with any ptrace_scope: the in-box forwarder on 127.0.0.1:4000 can be replaced.
Engine OUTSIDE the box (turn-outside.sh, engine-outside.txt): thief and MITM see nothing.
