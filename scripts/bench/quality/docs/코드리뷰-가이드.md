# 코드 리뷰 가이드

개발팀 공통 규칙. 2026년 7월 개정.

- 풀 리퀘스트 하나는 변경 400줄 이하로 유지한다. 넘으면 나눠서 올린다.
- 승인은 리뷰어 2명이 필요하다. 그중 1명은 해당 모듈 담당자여야 한다.
- 리뷰 요청을 받으면 근무 시간 기준 24시간 안에 첫 의견을 남긴다.
- 머지 전에 자동 테스트와 정적 분석이 모두 통과해야 한다.
- 금요일 오후 4시 이후에는 운영 배포를 하지 않는다. 긴급 장애 대응은 예외.
- 리뷰 의견에는 "필수"와 "제안"을 앞에 붙여 구분한다.
- 테스트 커버리지는 새 코드 기준 80% 이상을 목표로 한다.
