# 2026년 하반기 고객 만족도 조사 결과

조사 기간: 2026년 9월 1일 ~ 9월 20일 / 응답: 고객사 담당자 412명 (응답률 37%)

## 요약
- 전체 만족도는 5점 만점에 4.1점으로 상반기(3.8점)보다 올랐다.
- 순추천지수는 44로 집계되었다.
- 가장 큰 불만은 모바일 화면의 느린 로딩(응답자의 31%)이었고, 다음은 요금 인상에 대한 부담(22%)이었다.

## 항목별 점수
| 항목 | 상반기 | 하반기 |
|---|---|---|
| 예약 편의성 | 4.0 | 4.3 |
| 고객지원 응대 | 3.7 | 4.2 |
| 앱 속도 | 3.2 | 3.4 |
| 가격 대비 가치 | 3.5 | 3.6 |

## 개선 과제
1. 모바일 첫 화면 로딩 시간을 2초 이내로 줄인다 (담당: 개발팀, 기한 2027년 1분기).
2. 연간 결제 시 15% 할인을 도입해 요금 부담을 낮춘다.
3. 고객지원 채팅 운영 시간을 저녁 9시까지 늘린다.
