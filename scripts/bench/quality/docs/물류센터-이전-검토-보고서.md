# 물류센터 이전 검토 보고서

작성: 운영팀 / 2026년 10월

## 배경
현재 용인 물류센터는 임대 계약이 2027년 6월에 끝나고, 센서 출고량이 늘면서 공간이 부족하다. 이천 후보지 두 곳을
검토했다.

## 후보지 비교
| 구분 | 이천 A (부발읍) | 이천 B (마장면) |
|---|---|---|
| 면적 | 1,650㎡ | 2,100㎡ |
| 월 임대료 | 1,320만 원 | 1,580만 원 |
| 고속도로 나들목까지 | 4km | 1.5km |
| 입주 가능 시기 | 2027년 3월 | 2027년 5월 |

## 비용
- 이사 비용(운송, 랙 재설치)은 약 8,500만 원으로 예상한다.
- 이전 기간 동안 출고가 3일간 멈춘다. 이 기간의 주문은 미리 재고를 쌓아 대응한다.

## 권고
이천 B를 권고한다. 임대료는 월 260만 원 더 들지만, 면적이 넓어 2029년 물량까지 감당할 수 있고 배송 시간이 하루
평균 40분 줄어든다. 최종 결정은 2026년 12월 경영회의에서 한다.
