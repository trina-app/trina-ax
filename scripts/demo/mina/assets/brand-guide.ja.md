# スティープリング ブランドガイド（2026）

スティープリングはこのデモのために作った架空の会社です。このページはサンプルです。

## ひとことで
**静かに、あたたかく。** 大きな声は出しません。一杯のお茶のように、気取らずやさしく話します。

## 色
| 名前 | コード | 使うところ |
|---|---|---|
| リーフグリーン | `#1F4D3A` | メインカラー：見出し、ロゴ、濃い背景 |
| クリーム | `#F6F1E7` | 明るい背景、濃い背景の上の文字 |
| ゆずイエロー | `#F2B630` | アクセント。**1画面に1か所だけ**（セールのバッジかボタン） |
| インク | `#1B1F1C` | 本文の文字 |

- 赤、紫、蛍光色は使いません。
- 虹色やパステルのグラデーションは使いません。背景は単色か、自然な実写の写真に。

## 写真
- 自然光、本物のキッチンや食卓、冬の朝。パウチはいつも濃い緑にクリーム色のラベル。
- 写真の中に文字は入れません。文字は写真の上に載せます。

## 書体
- 見出しとロゴ：欧文は **Fraunces**（SemiBold、強調したい1語だけイタリック）、和文は **Noto Serif JP**（SemiBold）。
- それ以外の文字（説明、価格、ボタン、ラベル）はすべて **Noto Sans JP**。
- 見出しは本文の3倍以上の大きさに。
- 和文は単語の途中で改行しないようにし、見出しは意味の切れ目で改行します。

## バナー
1. **メッセージはひとつ。** 見出しは短く、1〜2行。
2. 読む順番：見出し → 1行の説明 → セール（ゆずイエローのバッジ） → ボタン。
3. ロゴは**左上**、端から48px以上離す。
4. 商品は右側に大きく。文字で商品を隠さない。
5. サイズ：1200×628（Web・広告）、1080×1080（Instagram）。

## 話し方
- 気取らず、親しみやすく。「です・ます」で、やわらかく。感嘆符は1文にひとつまで。
- 「最高」「No.1」は使いません。数字は根拠があるときだけ。
