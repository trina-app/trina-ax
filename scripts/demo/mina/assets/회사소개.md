# 차곡 회사 소개

차곡은 데모용으로 만든 가상의 회사예요. 이 문서의 사람, 숫자, 거래처는 모두 지어낸 것입니다.

## 한 줄 소개
찬물에 넣어 두기만 하면 되는 **콜드브루 티백**을 만들어요. "차를 차곡차곡, 매일 한 잔"이 우리 말버릇이에요.

## 우리가 파는 것
- **차곡 콜드브루 티** 6종: 보리, 현미녹차, 루이보스, 히비스커스, 페퍼민트, 얼그레이 (10개입 9,900원)
- **11월 신제품**: 겨울 한정 **유자생강 블렌드** (11월 23일 출시, 10개입 11,900원)
- 판매처: 자사 온라인 몰(60%), 카페·사무실 납품(40%)

## 사람들 (12명, 서울 성수동)
| 팀 | 사람 | 하는 일 |
|---|---|---|
| 대표 | 정우진 | 회사 전체, 제품 기획 |
| 마케팅 (3) | 박서연 팀장, 윤미나, 강레오 | 캠페인, SNS, 배너·상세페이지 |
| 운영 (4) | 한도윤 팀장 외 3명 | 주문, 배송, 고객 문의 |
| 영업 (2) | 최하은 외 1명 | 카페·사무실 납품 |
| 개발·몰 (2) | 오지수 외 1명 | 온라인 몰, 정기배송 |

## 일하는 방식
- 회사 소식은 **#전체**, 마케팅 일은 **#마케팅** 대화방에서 나눠요.
- 캠페인 자료는 팀 프로젝트(예: "11월 런칭 캠페인")에 모아 둬요.
- 디자인할 때는 `shared/브랜드 가이드.md`를 먼저 봐요.
- 외부 디자인 에이전시: 물결 에이전시 김지훈 실장님 (배너 게재, 광고 집행)
