# 3 版社媒文案

## 资料来源
- 语气参照 `shared/品牌手册.md`。
- 如果是活动，核心信息和优惠从 `groups/市场部/` 里的简报取。

## 做法
1. 三个版本：**A 走心**、**B 俏皮**、**C 优惠优先**。
2. 每版：一句让人停下来的开头，2–3 行正文，3–5 个话题标签。
3. 折扣和日期严格按简报写。
4. 最后每版用一句话说明什么时候用最合适。

## 规则
- 不说“最好”“第一”。一句话最多一个感叹号。
- 在对话里回答。只有被要求时才保存。
