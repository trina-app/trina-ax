# 新闻稿草稿

## 资料来源
- 公司信息来自 `shared/公司介绍.md`，产品来自活动简报。日期留作“[日期]”。

## 格式
1. **标题**：20 字以内，写清楚什么东西、什么时候推出。
2. **副标题**：一句话，说明为什么值得关注。
3. **正文 3 段**：是什么（产品）→ 为什么（CEO 引语留空写“[引语]”）→ 在哪儿买、多少钱。
4. **关于 Steepling** 3 行，**联系方式**留空写“[姓名、邮箱]”。

## 规则
- 不编造数字或引语。留空并写“待确认”。
- 只有被要求时才做 Word 文件，并先问存到哪里。
