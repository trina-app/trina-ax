# プレスリリースの下書き

## 資料
- 会社の情報は `shared/会社紹介.md`、商品と日付はキャンペーンのブリーフから。

## 形式
1. **タイトル**：30字以内で、何がいつ出るのか。
2. **サブタイトル**：なぜ意味があるのかを1行で。
3. **本文3段落**：何を（商品） → なぜ（CEOのコメントは「[コメント]」と空けておく） → どこで、いくらで。
4. **スティープリングについて**を3行、**お問い合わせ先**は「[名前、メールアドレス]」と空けておきます。

## 守ること
- 数字やコメントを作り上げません。空欄にして「要確認」と書きます。
- Wordファイルは頼まれたときだけ作り、どこに保存するか聞きます。
