# Steepling 品牌手册（2026）

Steepling 是为这个演示虚构的公司，本页内容均为示例。

## 一句话
**安静，温暖。** 我们不大声吆喝，说话就像一杯好茶：轻松、亲切。

## 颜色
| 名称 | 色值 | 用在哪里 |
|---|---|---|
| 茶叶绿 | `#1F4D3A` | 主色：标题、logo、深色背景 |
| 奶油白 | `#F6F1E7` | 浅色背景、深色背景上的文字 |
| 柚子黄 | `#F2B630` | 点缀色，**每个画面只用一处**（折扣标签或按钮） |
| 墨色 | `#1B1F1C` | 正文文字 |

- 不用红色、紫色和荧光色。
- 不用彩虹或马卡龙渐变。背景用纯色，或真实、自然的照片。

## 照片
- 自然光，真实的厨房和餐桌，冬天的早晨。包装袋永远是深绿色配奶油白标签。
- 照片里不放文字，文字叠在照片上面。

## 字体
- 标题：中文用 **Noto Serif SC**（SemiBold）；英文字标 Steepling 用 **Fraunces**（SemiBold）。
- 其他所有文字（说明、价格、按钮、标签）用 **Noto Sans SC**。
- 标题至少是正文的 3 倍大。

## Banner
1. **只说一件事。** 标题要短，一到两行。
2. 阅读顺序：标题 → 一句说明 → 折扣（柚子黄标签）→ 按钮。
3. Logo 放**左上角**，离边缘至少 48px。
4. 产品放在右边，要大。文字不能挡住产品。
5. 尺寸：1200×628（网页和广告），1080×1080（Instagram）。

## 语气
- 平实、亲切。一句话最多一个感叹号。
- 不说“最好”“第一”。数字只在有依据时才用。
