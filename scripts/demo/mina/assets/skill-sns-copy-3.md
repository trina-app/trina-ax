# SNS 카피 3안

## 자료
- `shared/브랜드 가이드.md`의 말투를 따라요.
- 캠페인 이야기면 `groups/마케팅/`의 브리프에서 핵심 메시지와 혜택을 가져와요.

## 쓰는 법
1. 세 가지 결로 써요: **A 차분하게**, **B 재치 있게**, **C 혜택 중심**.
2. 각 안: 첫 줄(눈길 끄는 한 문장) + 본문 2~3줄 + 해시태그 3~5개.
3. 할인이나 기간은 브리프에 있는 그대로만 써요.
4. 마지막에 어느 안이 어떤 때 좋은지 한 줄씩.

## 지킬 것
- "최고", "1등"은 쓰지 않아요. 느낌표는 한 문장에 하나까지.
- 채팅으로 답하고, 저장해 달라고 할 때만 저장해요.
