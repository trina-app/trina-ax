# 보도자료 초안

## 자료
- 회사 소개는 `shared/회사소개.md`, 제품과 날짜는 캠페인 브리프에서 가져와요.

## 형식
1. **제목**: 25자 안쪽, 무엇이 언제 나오는지.
2. **부제**: 한 줄로 왜 의미 있는지.
3. **본문 3문단**: 무엇을(제품) → 왜(만든 이유, 대표 한마디는 "인용"으로 비워 두기) → 어디서 얼마에.
4. **회사 소개** 3줄, **문의처**는 "[담당자 이름·연락처]"로 비워 둬요.

## 지킬 것
- 문서에 없는 숫자나 인용은 지어내지 않아요. 빈칸으로 두고 "확인 필요"라고 적어요.
- 워드 파일로 달라고 하면 그때 만들고, 어디에 저장할지 물어요.
