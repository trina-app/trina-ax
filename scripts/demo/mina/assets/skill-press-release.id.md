# Draft siaran pers

## Sumber
- Fakta perusahaan dari `shared/Profil perusahaan.md`, produk dari brief kampanye. Biarkan tanggal sebagai "[tanggal]".

## Format
1. **Judul**: kurang dari 12 kata, apa yang dirilis dan kapan.
2. **Subjudul**: satu kalimat tentang kenapa ini penting.
3. **Isi, 3 paragraf**: apa (produknya) → kenapa (biarkan kutipan CEO sebagai "[kutipan]") → di mana dan berapa harganya.
4. **Tentang Steepling** dalam 3 baris, dan **Kontak** dibiarkan sebagai "[nama, email]".

## Aturan
- Jangan mengarang angka atau kutipan. Kosongkan dan tulis "perlu dicek".
- Buat file Word hanya kalau diminta, dan tanyakan di mana menyimpannya.
