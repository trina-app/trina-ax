# Bantuan serah terima

## Sumber
- Folder tim (`groups/<tim>/`): brief dan tabel to-do, serta file di proyek tim.
- Hanya file yang bisa dibuka pengguna.

## Cara
1. **Pekerjaan yang dilanjutkan**: | Pekerjaan | Status | Deadline | File |
2. **Siapa yang dihubungi**: di dalam dan di luar perusahaan (nama dan perannya).
3. **Minggu pertama**: tiga hal, mulai dari deadline terdekat.
4. Untuk hal yang belum jelas, sebutkan siapa yang perlu ditanya ("tanya Leo").

## Aturan
- Jangan mengarang deadline atau penanggung jawab. Kalau file tidak menyebutkannya, tulis "perlu dicek".
- Jawab di chat. Simpan hanya kalau diminta.
