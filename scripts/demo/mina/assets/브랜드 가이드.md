# 차곡 브랜드 가이드 (2026년판)

차곡은 데모용으로 만든 가상의 회사예요. 이 문서는 데모용 예시입니다.

## 한마디로
**조용하고 따뜻하게.** 크게 외치지 않고, 차 한 잔처럼 편안하게 말해요.

## 색
| 이름 | 코드 | 쓰는 곳 |
|---|---|---|
| 찻잎 그린 | `#1F4D3A` | 메인 색. 제목, 로고, 짙은 배경 |
| 크림 | `#F6F1E7` | 밝은 배경, 짙은 배경 위 글씨 |
| 유자 옐로 | `#F2B630` | 포인트. **한 화면에 한 곳만** (할인 배지나 버튼) |
| 먹 | `#1B1F1C` | 본문 글씨 |

- 빨강, 보라, 형광색은 쓰지 않아요.
- 무지개·파스텔 그라데이션은 쓰지 않아요. 배경은 단색이나 자연스러운 사진 느낌으로.

## 글꼴
- **Pretendard** 하나만 써요.
- 제목은 ExtraBold, 본문은 Regular. 제목은 본문보다 3배 이상 크게.

## 배너 규칙
1. 메시지는 **하나**. 제목은 15자 이내, 한두 줄.
2. 읽는 순서: 제목 → 한 줄 설명 → 할인(유자 옐로 배지) → 버튼.
3. 로고는 **왼쪽 위**, 가장자리에서 48px 이상 띄워요.
4. 제품은 오른쪽에 크게. 글자가 제품을 가리지 않게.
5. 기본 크기: 1200×628 (웹·광고), 1080×1080 (인스타그램).

## 말투
- "~해요"체. 느낌표는 한 문장에 하나까지.
- "최고", "1등" 같은 말은 쓰지 않아요. 숫자는 근거가 있을 때만.
