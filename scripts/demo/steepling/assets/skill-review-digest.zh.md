# 客户评价汇总

## 资料来源
- 只用 `projects/客户评价/评价 十月–十一月.csv` 这一个文件：一条评价一行（月份、口味、星级、主题、客户原话、名字、可引用）。
  文件很小，读一遍就在里面数。不打开其他文件。

## 做法
1. 一句话概括：评价条数、平均星级、最受欢迎的口味（按被问到的月份，没问就看全部）。
2. **主题**：| 主题 | 条数 | 客户怎么说 |，按条数从多到少。
3. **可以引用的原话**：三句。只选“可引用”为“是”的行，连名字和口味一起写。
4. **下一步**：三件，每件一行。再写谁来负责比较合适（客户服务、运营、市场、线上商城）。

## 规则
- 条数和平均值只从文件里来，不估算：各主题的条数加起来要等于总数。
- “可引用”为“否”的人，不引用。
- 在对话里回答，只有被要求时才保存。
