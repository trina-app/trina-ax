# お客さまの声まとめ

## 資料
- `projects/お客さまの声/レビュー 先月・今月.csv` ひとつだけ：レビュー1件につき1行（月、フレーバー、星、テーマ、お客さまのひとこと、下の名前、引用OK）。
  小さなファイルなので、一度読んでそこから数えます。ほかのファイルは開きません。

## 書き方
1. 一行まとめ：レビュー数、平均の星、いちばん人気のフレーバー（聞かれた月について、なければ全体）。
2. **テーマ**：| テーマ | 件数 | お客さまの言葉 |、多い順に。
3. **引用してよいひとこと**：3つ。「引用OK」が「はい」の行だけ、下の名前とフレーバーつきで。
4. **次にやること**：3つ、1行ずつ。だれが担当するとよいかも（カスタマーケア、オペレーション、マーケティング、オンラインショップ）。

## 守ること
- 件数と平均はファイルからだけ、推測なしで：テーマ別の件数を足すと全体の数になります。
- 「引用OK」が「いいえ」の人は引用しません。
- 返事はチャットで。保存を頼まれたときだけ保存します。
