# 데모 회사 "트리나"

`bun run demo:trina` 가 올리는 샘플 회사예요.

**트리나는 가상의 회사예요.** 사람, 고객사, 숫자, 규정, 문서는 모두 데모를 위해 지어낸 것이고, 실제 회사의 정책이나
데이터가 아니에요. 웹사이트 주소(`trina-box.example`)도 쓰이지 않는 예시 주소예요.

트리나는 직원 15명이 사무실 간식·커피 구독 서비스 "트리나 박스"를 운영하는 회사예요. 데모에서 보는 사람은
2026년 11월 5일(목) 마케팅팀에 입사한 신입 한지우예요.

## 켜기·끄기

```bash
bun run demo:trina                  # 서버 19830, 중계 19831, 데이터 ~/.trinademo
bun run demo:trina --local          # 이 맥에서만 열기
```

- 출력된 `phone:` 주소를 같은 Wi-Fi의 휴대폰에서 열고 **한지우 님으로 시작하기** → 신입 한지우로 시작해요.
- 위쪽 띠의 **사람 바꾸기** → 팀장 서민재(마케팅팀) / 대표 정해온으로 같은 질문을 해 봐요.
- 끄기: 시작한 터미널에서 Ctrl-C. 데이터는 `~/.trinademo`에 남아 다음에 그대로 열려요. 처음부터 하려면 끈 뒤 그
  폴더만 지워요.
- 직원 15명은 모두 멤버이고 공개 비밀번호 `teamax-demo-1`을 써요. 팀의 owner는 직원이 아닌 `trina-admin` 계정이고,
  처음 켤 때 만든 무작위 비밀번호가 데이터 폴더의 `owner-password`(이 맥 사용자만 읽음)에 있어요. 터미널에는 처음
  한 번만 나와요.
- 이 맥이 연결된 모든 네트워크(Wi-Fi, VPN, Tailscale)의 누구나 이 데모를 열고 이 맥의 Claude 로그인으로 AI를 쓸 수
  있어요. 데모가 끝나면 꺼 주세요.
- 사람 바꾸기는 데모 모드(`MYCEL_DEMO`, 개발 서버 전용)에서만 있어요. 제품에는 "다른 사람으로 로그인"이 없어요. 데모
  모드에서는 연결 폴더, 플러그인 파일 설치, 아무 주소의 API 엔진, 비밀번호를 다시 묻는 관리 작업, 데모 사람의
  비밀번호·역할·계정 바꾸기가 꺼져 있어요.

## 폴더와 볼 수 있는 사람

| 경로 (`files/` 아래) | 내용 | 볼 수 있는 사람 |
|---|---|---|
| `shared/규정/` | 취업규칙 요약, 복지·휴가 안내 | 전 직원 |
| `shared/신입-온보딩-가이드.md`, `shared/사내-용어집.md` | 첫 주 체크리스트, 용어 | 전 직원 |
| `shared/회의록/` | 전사 주간회의 (11/2) | 전 직원 |
| `shared/경영/2026-4분기-예산-전사.xlsx` | 4분기 운영 예산 1억 원, 팀별 합계 | 대표만 |
| `shared/경영/팀별/<팀>/` | 팀별 4분기 예산 | 대표와 그 팀 팀장만 |
| `groups/마케팅팀/` | 11월 캠페인 기획, 브랜드 가이드, 팀 회의록 (10/27, 11/3) | 마케팅팀 |
| `groups/영업팀/` | 고객사 현황 | 영업팀 |
| `groups/인사팀/` | 급여표, 상반기 평가 | 인사팀과 대표 |
| `skills/new-hire-first-week/`, `skills/meeting-action-items/` | 팀 스킬 "신입 첫 주 안내", "회의록 → 할 일 정리" | 전 직원 |
| `skills/사내-규정-답변.md` | 팀 규칙 (AI가 매번 읽는 답변 규칙) | 전 직원 |
| `skills/marketing/` | 마케팅 스킬 팩의 스킬 (이 폴더에는 없고 제품의 팩에서 가져와요) | 마케팅팀 |

대표 정해온도 멤버예요: 폴더 규칙으로 모든 팀 폴더(`groups/`)를 읽고 `shared/경영/`에 써요. 예산 숫자는 서로 맞아요. 전사 시트의 팀별 금액은 각 팀 시트의 합계이고,
마케팅팀 4,500만 + 영업팀 1,800만 + 인사팀 900만 + 경영지원 1,600만 + 전사 공통 1,200만 = 1억 원이에요.

## 스프레드시트 다시 만들기

`.xlsx` 파일은 스크립트로 만들어 커밋해 둔 거예요. 숫자를 바꿀 때는 스크립트를 고치고 다시 돌려요.

```bash
bun tests/demo/make-trina-files.ts
```

Markdown 파일은 손으로 써요.
