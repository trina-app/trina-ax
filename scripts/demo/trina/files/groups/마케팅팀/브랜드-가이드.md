# 트리나 박스 브랜드 가이드

- 관리: 마케팅팀 서민재 · 최종 수정 2026-09-15

## 1. 톤
- **친근하게**: 옆자리 동료에게 말하듯 해요체로 써요.
- **짧고 또렷하게**: 한 문장에 한 가지만 말해요. 광고 문구는 20자 안팎.
- **과장 없이**: 사실과 숫자로 말해요. 고객이 직접 확인할 수 없는 약속은 하지 않아요.

## 2. 쓰는 말 / 피하는 말
| 쓰는 말 | 피하는 말 | 이유 |
|---|---|---|
| 사무실 간식 걱정 덜기 | 업계 최고, 1등, 국내 유일 | 최상급 비교는 근거를 대기 어려워요 |
| 우리 팀 취향에 맞춰 골라요 | 완벽한 큐레이션 | 과장 |
| 커피와 간식을 정기적으로 | 무조건, 100% 만족 | 약속할 수 없어요 |
| 가볍게 즐기는 간식 | 면역력 강화, 다이어트, 피로 회복 | 확인되지 않은 건강 효능은 금지 |
| 총무 담당자님 | 고객님들~ | 받는 사람을 정확히 불러요 |

- 다른 회사 제품을 이름으로 비교하지 않아요.
- 할인은 기간과 조건을 함께 적어요. 형식: "○월 ○일까지 신청하면 첫 달 ○% 할인"

## 3. 표기 규칙
- **트리나 박스**: 띄어 써요. "트리나박스", "TRINA BOX"는 쓰지 않아요.
- 플랜 이름: 트리나 박스 베이직, 트리나 박스 플러스
- 가격: "월 19만 원부터", "월 39만 원부터". 부가세 별도면 "(부가세 별도)"를 붙여요.
- 숫자: 1,200만 원, 300건처럼 쉼표와 단위를 써요.
- 날짜: 11월 16일(월)처럼 요일을 붙여요.
- 이모지는 SNS에서만 한 문장에 하나까지.

## 4. 색과 로고
- 메인 색: 숲 초록 (#2F6B4F)
- 보조 색: 크림 (#F6F1E7), 강조 색: 귤색 (#F29E4C). 강조 색은 버튼과 가격에만.
- 로고: "트리나 박스" 글자 로고. 둘레에 로고 높이의 절반만큼 여백을 둬요.
- 복잡한 사진 위에는 로고를 올리지 않아요. 크림 배경이나 흰 배경 위에 써요.
