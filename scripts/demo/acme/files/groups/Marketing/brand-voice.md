# Acme brand voice

Acme is a fictional company. This page is sample data for the demo.

- Friendly, short and clear. Write like a helpful colleague, not a billboard.
- Lead with what the office manager gets: fewer empty desks, no booking spreadsheets.
- Use numbers only when we can show where they come from.
- Never: "best", "number one", "revolutionary", exclamation marks in headlines.
- Product names: Acme Desk Starter, Acme Desk Pro. Prices: "$7 per desk a month".
- Colors: ink #1D2B3A, sky #3E8EDE, sand #F4EFE6.
