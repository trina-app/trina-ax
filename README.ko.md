## 설정은 한 번, 쓰는 건 팀 전체

**AI 계정 하나로 팀 모두가 써요.** Claude나 OpenAI API 키 하나(또는 약관이 허용하는 요금제)를 연결하면 누가 묻든 AI가 그 계정으로 답해요. 토큰 한도는 사람별, 그룹별, 팀 전체로 걸 수 있어요.

한 사람이 팀 서버에 한 번 설정하면, 모두의 AI가 첫 질문부터 그걸 써요. 브라우저에서도 앱에서도요. 나머지 팀원은 Claude Code를 깔거나 스킬을 복사할 필요가 없어요. 필요할 때 자기 계정에 로그인만 하면 돼요.

## 모두가 트리나로 하는 일

**동료가 하던 일, 그대로 이어서.** 팀 프로젝트에서 동료의 AI 세션을 열면 지금까지의 대화와 답이 모두 보이고, 바로 이어서 물을 수 있어요. 새 답은 물어본 사람의 권한으로 처리돼요. 그 밖의 세션도 Google Drive 파일처럼 사람이나 그룹에 공유할 수 있어요.

<img src="docs/images/readme/v4/shared-sessions.gif" width="100%" alt="Mina가 Sam의 프로젝트 세션을 열어 카드뉴스를 이어서 고쳐요. Mina가 묻는 건 Mina의 권한으로 처리돼요.">

**대화 중에 옆에서 묻고, 답은 클릭 한 번으로 보내요.** 나만 보는 옆 채팅에서 묻고, 클릭 한 번이면 트리나의 답이 대화방에 올라가요.

<img src="docs/images/readme/v4/room-share.gif" width="100%" alt="Expo booth crew 대화방에서 Mina가 자기만 보는 옆 채팅으로 트리나에게 참가 규정을 체크리스트로 만들어 달라고 하고, 그 답을 대화방에 올려요.">

**내 AI도 내가 열 수 있는 것만 봐요.** Mina가 Finance를 못 열면 Mina의 AI도 못 열어요. [권한은 이렇게 돌아가요](docs/PERMISSIONS.md)

<img src="docs/images/readme/v4/folder-access.gif" width="100%" alt="관리자가 Sales 폴더를 열 수 있는 사람을 바꾸고, Mina가 열 수 있는 폴더를 확인해요. Finance는 목록에 없어요.">

**파일을 내용으로 찾아요.** 밤마다 팀 AI가 공유·그룹·프로젝트 폴더의 새 파일과 바뀐 파일을 읽고, 파일마다 무엇인지 한 줄씩 적어 둬요. 그래서 `temp.pdf`라는 스캔본이나 `IMG_2031.jpg`라는 사진도 내용으로 찾을 수 있어요. 이 작업은 팀 AI 계정으로 하고, 개인 폴더는 읽지 않아요. 가상 파일 2,238개로 시험했을 때 Claude Code는 질문 184개 중 이 한 줄 설명이 있으면 181개, 없으면 172개에서 맞는 파일을 찾았어요.

## 시작하기

- **브라우저에서 써 보기:** 설치 없이 가상 팀으로 써 봐요. AI는 꺼져 있어요. [데모 열기](https://ax.trina.app/demo/ko/)
- **트리나 호스팅:** 서버를 따로 운영할 필요가 없어요. 14일 무료 체험 뒤 월 요금제예요. [요금제](https://ax.trina.app/pricing)
- **앱:** [맥, Windows, Linux, 아이폰, 안드로이드](https://ax.trina.app/download) 앱이 있고, 브라우저에서도 쓸 수 있어요.
- **직접 설치:** 회사 리눅스 서버, 윈도우 PC, Docker, 사무실 맥에 설치해요. 무료예요. [리눅스](docs/INSTALL-LINUX.md) · [윈도우 PC](docs/INSTALL-WINDOWS.ko.md) · [Docker](docs/INSTALL-DOCKER.md) · [사무실 맥](docs/OFFICE.md) · [AI 에이전트로 설치](docs/INSTALL-LINUX.md#ai-에이전트로-설치하기)

<b>Docker로 직접 설치</b> (리눅스, 또는 OrbStack을 쓰는 맥)

```sh
git clone https://github.com/trina-app/trina-ax.git && cd trina-ax/docker
cp env.example .env && docker compose up -d --build
docker compose exec trina-ax trina-ax-setup-link   # 링크를 열어 소유자 계정을 만들어요
```

리눅스 설치보다 새로 나온 방식이라 아직 덜 검증됐어요. Ubuntu 24.04 서버는 먼저 호스트 설정 하나가 필요해요. [Docker 안내](docs/INSTALL-DOCKER.md)

<b>10분 만에 내 컴퓨터에서 써 보기</b> (가상 팀, AI 꺼짐)

```sh
git clone https://github.com/trina-app/trina-ax.git && cd trina-ax
bun install --frozen-lockfile && bun run demo   # → http://127.0.0.1:19760 · alice / teamax-demo-1
```

Bun 1.3.12와 Go 1.27 이상이 필요해요. 실제 운영용 설치는 아니에요. [자세한 안내](docs/QUICKSTART.ko.md)

## 작동 방식

서버 하나에서 Claude Code와 Codex가 엔진으로 돌아요. 사람이든 그 사람의 AI든, 파일을 열 때마다 서버의 권한 확인 한 곳을 거쳐요. 리눅스 서버에서는 엔진이 전용 계정으로 bubblewrap, Landlock, seccomp 샌드박스 안에서 돌아요. 엔진의 셸과 내장 파일 도구는 꺼져 있어서, 파일은 트리나 도구로만 열어요. [보안과 권한](docs/security-and-permissions.ko.md)

트리나가 드리는 건 업무 공간이에요. AI는 용도에 맞게 허용된 Claude·OpenAI 계정이나 요금제를 연결해 쓰세요. AI 이용료는 연결한 계정으로 나가요.

<summary><b>데이터, 한계, 약속하지 않는 것</b></summary>

### 약속하지 않는 것

- 직접 설치해도 오프라인으로 도는 건 아니에요. 요청에 필요한 내용은 연결한 AI 회사로 가고, 설정한 외부 연동도 요청을 받아요. Codex 웹 검색은 할 때마다 그때까지의 대화를 OpenAI 검색 서비스로 보내요. 관리자가 음성 인식에 OpenRouter를 허용하면, 영상·오디오 파일의 소리가 OpenRouter로 가요. 서버는 30분마다 `updates.trina.app`에 자기 공인 주소를 물어요(`MYCEL_EXIT_ADDRESS_CHECK=off`로 끌 수 있어요). [자세히](docs/security-and-permissions.ko.md)
- 서버 운영자는 저장된 파일과 채팅을 볼 수 있어요. 트리나 호스팅이라면 트리나 운영자도 볼 수 있어요. 앱 관리자에게는 모두의 개인 대화를 보는 화면이 없어요.
- 폴더 권한을 빼도 예전 답은 지워지지 않아요. 더 많은 사람이 보게 될 때 뜨는 확인이 모든 유출을 막아 주지는 않아요.
- 보안 인증, 완벽한 답, 비용 절감, 법무·재무·인사 결정의 자동화는 약속하지 않아요. 결과와 운영 범위는 직접 검토해 주세요.
- 리눅스 서버에는 OCR이 없어요. AI는 사진과 스캔한 페이지를 이미지로 보지만, 글자로 검색되지는 않아요. 사무실 맥은 아직 영상을 읽지 못해요.
- HWP/HWPX 문서 내용은 어느 팀이든 읽을 수 있어요. [미리보기와 한글 문서 만들기](resources/hwp/README.md)에는 한글 문서 미리보기 플러그인(선택)이 필요해요(macOS, 또는 glibc 2.39 이상의 리눅스. Debian 12는 안 돼요).
- 연결은 본인이 쓸 수 있는 개인 연결부터 쓰고, 그다음 그 사람, 그룹, 팀 전체에 배정한 연결 순이에요. 새 트리나 팀은 회사 연결 하나를 팀 전체가 기본으로 쓸 수 있고, 이미 저장한 설정은 바뀌지 않아요. **이 설정을 했다고 Anthropic이나 OpenAI 약관에서 허용된다는 뜻은 아니에요.** [연결 방식 자세히](docs/FAQ.ko.md)
- 리눅스 직접 설치에는 Debian 12/13 또는 Ubuntu 24.04, systemd와 cgroup v2, amd64나 arm64, RAM 4 GB, 디스크 20 GB가 필요해요. 설치, 업데이트, 백업 복구는 회사 IT 담당자가 맡아요.

</details>
